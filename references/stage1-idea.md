# Stage 1 创意输出（Idea → 大纲 → 项目档案）

> 用户只有一个点子/一句话创意，或什么都还没有。目标：把模糊想法变成**锁定的故事大纲 + 项目档案 v1**。
> 通用纪律（反捧杀/创作笔记/不捏造/分歧追问）全程生效。

## Step 1 核心信息收集（一轮收齐，已给全的不追问）

```
1. 作品时长/体量：____（30秒-5分钟短片 / 微电影 / 单集 / 多集系列 / 电影）
2. 平台：____（抖音 / 红果 / B站 / 视频号 / 院线 / 其他）
3. 目标受众：____（如：Z世代女性 / 男性向 / 亲子家庭）
4. 题材方向：____（如：都市悬疑 / 规则怪谈 / 古风权谋 / 师徒成长）
5. 核心情绪：____（爽 / 恐惧 / 温情 / 燃 / 反差搞笑 / 哲思）
6. 画幅意向：____（横16:9 / 竖9:16 / 未定——未定时提醒：进分镜前必须定）
7. 对标作品（可选）：____
8. 禁止元素（可选）：____（如：不要狗血三角恋 / 不要 BE / 不要某类镜头——用户提出即入「禁止元素」清单锁定，全阶段生效，见 SKILL.md 纪律第 7 条）
```

信息不足以支撑创作时才二轮追问（主角设定/视觉记忆点偏好/IP参考等）。

## Step 2 对标 DNA 提取（用户给了对标作品才执行）

- 列出该作品 **5-7 条**可观察的创作规律（宁少勿多），每条给出具体观察依据（哪个场景/哪段对白/哪个镜头）+ 置信度（高/中/低）。
- 七个分析维度按需选：结构比例与节拍分布 / 节奏与留白 / 对白风格与人物语言区分度 / 视觉镜头偏好 / 主题与母题 / 标志性符号 / 该作品从不做的事。
- **诚实底线**：对该作品了解有限时直说，请用户提供 3-5 条关键特征，严禁编造规律。
- **版权边界（2026-09-16 short-drama-factory 机制仿写库吸收）**：拆对标只拆到**机制层**（结构选型/节拍排法/卡点落位/回合节奏——思想方法不受版权保护）与**结构层**（人物功能位/场景类型/反转类型——可借用但须换皮换参）；**表达层**（具体台词/角色名/专有名词/独特桥段串联顺序）不可搬。拆解产出物必须是抽象机制笔记，禁止粘贴原文台词桥段进笔记；成稿自检——角色名重合？金句句式重合？独特桥段顺序重合？任一为是即回炉。用户直接粘贴他人剧本原文要求"改成短剧"时，提示版权风险并拒绝逐句改写，仅提供机制级重排建议。
- **权利授权确认（2026-09-17 骨架移植）**：改编授权不明的源材料，可继续做分析与高层重构方案，但按 `references/rights-and-safety.md` 标注发布风险、不声称"已获授权"；下载对标素材前确认获取与使用权利（无水印≠有改编权）。
- 用户确认（保留/修改/删除/补充）后，这些规律成为本次会话的隐性约束，后续大纲与剧本必须参照，创作笔记中至少引用 1 条。

## Step 2.5 网文/原著改编入口（给了原著/小说且要求改编时执行）

先读 [原文分析与改编选择](../../screenwriting-craft/references/source-analysis.md)，确定实际阅读范围、主要事件及关系变化，再决定如何改。只有分析请求时到分析交付即止；改编任务沿用已有目标、授权与保护项，不把所有作品都默认做成强爽感短剧。

1. **提取原作**：按需求整理观看承诺、关键关系、事件及其作用。保留原文位置和叙述顺序；有倒叙时另记事件时间。原作明示、人物说法、分析推断与拟新增内容分开；人物功能标签不能代替关系的实际变化。
2. **确定改编体验**：温情片看关系如何变化，悬疑看信息怎样释放，经营成长看能力与成果如何产生下一步，留存型爽剧再看压抑与兑现。沿用用户选定方向；目标明确的改编不强制回 Step 3 发散。
3. **删减与合并**：逐项检查删掉的动机、关系建立、线索、行动条件及回收由哪里承接。同功能角色不自动等价；合人可能改变知情范围和关系。台词说明、旁白、动作均可成为新载体，不能默认一句话足以替代关系建立。用户锁定的台词与事件保留。
4. **映射到目标体量**：按目标时长与必要变化组织场景/分集，不固定一章一集或一集一个反转。新增桥接标为改编设计；压缩故事时间后复查人物知情、行动可行性与结果。长原作按用户要求确定范围，未覆盖部分如实注明，不擅自截取前三分之一后称完成全书改编。
5. **交接**：依用户所求交改编大纲或继续 Stage 2。开发包需要时记录原作保留项、调整及理由、进入/退出状态；单条短片不强制建立付费墙和多集台账。

**留存型竖屏爽剧分支**：项目明确需要时加载 [short-drama-engine.md](short-drama-engine.md)，以已接受的核心情绪组织名场面、单元链与回合；需要付费卡点时再安排。短剧密度是项目配置，不能因此擅改核心关系、把主角收益收回或提前泄露已锁定的谜底。情绪流与剧情流的差异见 [genre-modules.md](genre-modules.md)。

**示例与自检**：原作先交钥匙、再回忆夺行李、最后询问摆花位置，体现从替对方决定到询问；改成90秒温情短片时，保住建立前后差异的动作，可压缩时空，不插羞辱反杀或付费墙。交接前核对：分析范围是否真实、删并是否丢了必要前因、原作与新增是否分清、目标片型和用户保护项是否守住。详细原创例见上述原文分析参考。

## Step 3 发散方向卡

概念片、形式实验或物件/界面叙事的方向发散，按需读 [概念与形式](../../screenwriting-craft/references/concept-and-form.md)。先区分改变世界规则还是改变观众接触事件的方式，再检验它怎样产生具体行动和观看变化；不因短片体量强制反转或完整人物弧光。

输出 **3-5 个差异化方向**（数量按信息丰富度调节），每张卡片：

```
方向 X：[一句话定位]
- 核心切入角度：____
- 主角设定：____
- 一句话冲突：____
- 独特卖点：____
- 风险点：____
- 预估难度：★★★☆☆
```

发散维度参考：题材切换（弹药见文末附录「题材速查」）/ 主角视角 / 时间线策略 / 情感落点 / 反类型套用 / 第一人称 / 群像。
处理规则：请用户选 1 个；全不满意→自动重新发散（保留已确认部分），≤2 次；仍不满意→追问"具体哪个维度不对"从根因解决，不盲目再发散。

**发散纪律（2026-10-03 creative-director 库吸收）**：
- **热身稿规则**：每轮前 3 个想到的方向默认标记「热身稿」（序列效应：最先想到的多是套路），差异化方向优先从第 4 个之后选。
- **4 维快评**：每张方向卡附原创度/情绪强度/可行性/差异化各 1-10 分；**均值纪律——全批平均分 ≥7 视为打分注水，整批重评**（专业作品大多落在 4-6）；给 9+ 必须点名 1-2 部同量级对标作品佐证，举不出就降分。
- **反假方案纪律（2026-10-08 音乐创作系统「灵犀」库吸收）**：方向之间的差异必须落在核心概念/主角/冲突/结构上，禁止只换形容词与情绪词制造"伪差异"——"热血复仇"与"燃情复仇"是同一个方向。每张卡自检：把修饰词全部删掉后，剩下的骨架是否仍与其他方向不同；相同即合并重发。

## Step 4 大纲（时长决定形式 + 差异轴出两版）

**形式自动匹配**（主动告知用户，允许换）：

| 作品时长/类型 | 大纲形式 |
|---|---|
| 30秒-5分钟（短片） | 故事梗概（200-500 字，开端钩子/冲突/收尾落点三段式） |
| 6-30分钟（微电影）/ 电影 | 千字大纲（800-1500 字，三幕分场，每场景节点含地点时间+事件+转折） |
| 单集 / 多集系列 | 分集大纲（每集 logline + 钩子 + 主线推进 + 集尾钩子；集数多时先详写前 3 集） |

**差异轴**（用户二选一，出两版供选择）：
- 轴 1：稳健版（市场友好低风险） vs 大胆版（差异化高回报）
- 轴 2：主角驱动版（人物弧光主导节奏） vs 事件驱动版（外部冲击主导节奏）

每版必含：主线人物配置（核心 2-4 人）+ **为什么这样写**（3 条理由；已激活 DNA 时须引用至少 2 条规律）+ 风险预警（诚实列出这版可能踩的坑，不能避而不谈）。
命名禁用 A/B 版（避免与轴选项混淆）。用户选定后进入 Step 5。

## Step 5 快速审稿（可选，推荐）

四视角独立评估（不可省略视角，不可和稀泥——每个视角必须找出至少 2 个真实问题，引用大纲原文）：

```
【编剧视角】结构与角色逻辑｜【制片视角】市场与制作可行性
【观众视角】情感共鸣与代入感｜【平台视角】调性与审核风险
```

输出修改建议清单（按影响排序）：必改 / 必改 / 建议改 / 可选。用户选择采纳项后更新大纲。
用户跳过审稿时，追问一句"是否有局部要改；没有可直接锁定"。

**审稿增补机制（2026-10-03 creative-director 库吸收，大纲锁定前执行）**：
- **换皮测试**：把主角/题材外壳换成知名同类型作品，故事仍然成立 → 差异化分 ≤5，回炉换核；与 Step 2 版权自检（角色名/金句/桥段顺序）并列执行。
- **Pre-Mortem**：假设"上线 3 个月后数据惨淡"，列失败模式（题材撞车/钩子失效/节奏错位/审核风险），按概率×影响分类；高危且无解法 → 回炉，不许带病死锁。
- **被毙方向记录**：审稿输出必含「考虑过什么方向、为什么毙」至少 2 条（并入创作笔记）。
- **情绪分层校验**：核心情绪按三级分层判定——Tier 1 通用词（爽/虐/燃/甜）无差异化；Tier 2 具体词（憋屈、释怀、意难平、扬眉吐气）及格线；Tier 3 复合矛盾态（如"屈辱中的傲""笑着的心酸""释怀里的不甘"）最优。核心情绪若是 Tier 1，标记"情绪无差异化"并尝试升级——锁定大纲时核心情绪字段鼓励写 Tier 2-3，单一 Tier 1 不禁止但须在创作笔记说明理由。

## Step 6 锁定大纲 → 生成项目档案 v1

用户明确确认（"锁定/确认"）后，按下述结构补齐档案（填充规则见 Stage 2 开头），输出后进入 Stage 2：

```
# 项目档案 v1.0 ——【项目名称】
一、元信息：项目名称 / 作品类型 / 画幅 / 集数规划 / 目标受众 / 核心标签 / 参考作品 / Logline
二、风格与调性：
   【视觉风格】整体（含画面风格描述提示词，进分镜的硬门禁）/ 色调 / 镜头倾向
   【叙事调性】主基调 / 节奏 / 禁忌
   【语言风格】对白 / 旁白 / 笑点
三、世界观设定：时空 / 核心规则 / 主要场景 / 冲突源
四、人物档案（每个角色）：
   一句话定位 / 外形【供画图，将直接成为分镜资产锚点】/ 性格三层（表层/深层/阴影）/
   语言指纹（词汇标记 / 句长偏好 / 口头禅 / 说话样例一句）/
   标志性动作习惯（1-2 个贯穿全剧的身体锚点，带动态参数：速度/幅度/频率——如"思考时摸围巾尾端，速度缓慢，幅度≤1cm"；**每个习惯必须带触发条件**——"在 X 情境下做 Y 以掩饰 Z"，无触发条件的习惯只是装饰）/
   面具与裂缝（角色的常态伪装 + 让它崩塌的精确触发："平时 X，然而当 Y 时——……"，如"平时蛮横自大，然而当被拒绝时——瞬间缩成孩子般的佝偻"。每个角色至少一条，是一人分饰两种真相的抓手）/
   柔软靶点（唯一一个让 TA 的脸真正柔软的人/动物/物件，只给一个）/
   声音特质（音色 / 语速 / 情绪起伏范围——如"中低音，日常语速偏快，紧张时放缓"）/
   角色弧光（开头→结尾）/ 与他人关系
五、主线：三幕大纲 / 关键情节节点 / 已确定的关键场景与台词（防后续矛盾）
六、工作约定：角色不得 OOC；对白遵守语言指纹；发现设定矛盾先指出等确认
七、待补充清单：标注【待用户确认】的项
```

**注意**：此时画面风格描述提示词若用户尚未提供，档案中留【待用户确认】并提醒——进 Stage 3 前必须补上。

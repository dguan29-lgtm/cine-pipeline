# 从场景到镜头组：先组织观众发现，再选参数

用于一场戏需要多个镜头共同完成叙事，或出现“逐句配镜头、镜镜都有参数但连起来没戏”的问题。放在全片设定与逐镜设计之间。一个简单单镜头无需另建组表；本页不增加用户确认环节，不替代原版制作面板。

## 1. 把叙事任务翻译成观看过程

先确认这段让什么改变，再决定观众怎样看懂。内部可记：

~~~text
原文位置及保护项：
进入时：人物知道什么，观众知道什么？
本组完成的事：观众将发现、等待或重新理解什么？
可见/可听的依据：哪个动作、物件、声音或空间关系承载它？
注意顺序：先给什么，什么时候允许看见另一项？
退出时：留下什么结果或未完成问题，下一组怎样承接？
~~~

“表现人物失落”还不是执行方案；需要决定观众从哪项行为看出变化。意图可以描述推断，生成提示词则写支持推断的画面与声音，不把“象征疏离”当作可生成的实体。

事实、人物理解、观众理解分开。重排镜头可能改变知情顺序：先给反应再给原因可以延迟观众理解，但不能让角色在尚未获得信息时作出知情反应。对话、事件顺序、声音类型已锁定时，不借分镜设计改写；建议修改另列并按已有授权范围处理。

## 2. 选镜头间的关系，而非固定镜数

按当前段落选择即可：
- **累积**：不同画面共同建立规模、时间推移或一种惯例；避免每镜只重复已知结论。
- **递进**：后一镜改变观众对前一镜的理解，或增加使下一行动成立的信息。
- **因果**：行为引出可见结果，结果又成为下一行为的条件。
- **对照**：相似构图、动作或声音显露不同处境；空间相邻、交叉剪辑不自动意味着同时发生。

这些是组织关系，镜数与时长由阅读、表演及用户预算决定。不要配“70%常规/30%出彩”额度，不为每场必有亮点而加空洞意象。

**镜头组不等于生成段。** 一个组可以跨多个生成单元，一个生成段也可容纳多个简单镜头。先按叙事组织，再按已核验的模型能力、段长、资产和连续性拆执行单元。超出容量时调整拆分与节奏，不能删除锁定台词来适配工具。

## 3. 对白拍谁：看本拍的新信息在哪里

- 关键在说者如何说出：让说者可读。
- 关键在听者如何处理：保持原对白声源，画面可停在听者。
- 关键在双方的距离、阻挡或接近：用同框、走位或空间变化，不必逐话轮切正反打。
- 关键暂时不能给观众看：遮住或延后揭示，但留下足够可理解的线索。

环境、反射或空镜只有承载具体信息时才介入，不能用装饰性插镜遮掉必须看懂的反应。可采用同框发生、听到画外动作再看反应、延迟反应或有意省略；反应有作用不等于必须独立切一个特写。具体空间与切接仍查 [continuity-and-editing.md](continuity-and-editing.md)。

## 4. 小例子：同一段戏的不同观看顺序（原创）

原事件：甲想拿走桌上的合照，乙用手按住相框。甲说“我拿走了。”乙说“这张留下。”甲松手。原台词与事件不变。

若重点是关系争夺，可以让两双手与相框同框，保留按住、松开的全过程；对白不必一句一切。若重点是让观众晚些知道争夺的对象，可先看双手接触相框背板，再在甲松手后看清正面是合照。后一方案只在故事允许延后展示照片内容、且翻到正面的呈现不违背原动作与空间时采用；否则保持同框方案，不擅加翻框动作。

复查：观众能否看清谁先拿、谁阻止、谁退让；说话者是否仍正确；不能因为想拍听者就把其未说的话标成他的对白。镜头数少也可完整完成这次变化。

## 5. 交付与复查

组划分通常是内部组织工具，最终仍沿用 Stage 3 已定的可投喂提示词格式。用户要导演分析或拍摄表时才展开组表；不默认改成九列表格或额外交付 xlsx。

- 每个关键发现是否有看得见、听得到的依据？单凭文字知道的事是否真能被观众感知？
- 组内镜头是否互相补充，删掉某镜会缺什么，是否可以由同框完整表达？
- 画面、声源、人物所知与原文是否一致？时间同时性是否有依据？
- 张力变化是否来自行动和期待，而非只换景别或加速？
- 全片策略一致吗？特殊拍法是否服务此处，没有抢走重点？

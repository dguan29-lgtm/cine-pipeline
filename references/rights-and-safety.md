# Rights and safety gate

Run this gate before using source material, likeness, voice, private media, brands, or claims of fact. Record the answers; do not infer authorization from possession of a file or URL.

## Rights record

| Field | Record |
|---|---|
| source_type | original / licensed IP / public domain / user-owned / reference only |
| source_owner | person or organization, if known |
| permitted_use | analysis / adaptation / commercial release / internal prototype |
| evidence | user statement, license, contract, public-domain basis, or unknown |
| likeness_consent | subject and allowed uses |
| voice_consent | speaker and allowed uses |
| territory_term | region and duration, when relevant |
| unresolved_risk | exact missing authorization or claim |

## Decision rules

- **Original work:** proceed; distinguish user-supplied material from new proposals.
- **User-owned or licensed work:** proceed within the stated license. Do not silently broaden distribution or commercial use.
- **Reference study:** extract observable mechanisms and measurements. Do not copy distinctive dialogue, characters, branding, music, or scene sequences.
- **Unknown adaptation rights:** analysis and high-level transformation planning may continue, but label release risk and do not claim the project is cleared.
- **Voice or likeness:** cloning or identity-preserving generation requires explicit confirmation that the user is the subject or has permission. Public availability is not consent.
- **Minors:** do not sexualize young or ambiguously aged characters. For adult fashion/romance prompts, state an adult age.
- **True-event language:** use “based on true events” only when the factual basis is supplied and the wording is approved. Otherwise use truthful genre copy.
- **Platform policy:** treat platform and model rules as volatile; verify current requirements before publication or a costly batch run.

## Download and reference-media rule

Before downloading, ask only if rights/use are unclear. Record the intended use and keep attribution/source metadata. A watermark-free file is not proof of reuse rights.

## 广告宣传合规速查（中国大陆，2026-11-04 补，信息流素材高频踩点）

写商业广告分镜时，下列画面/措辞必须在 Stage 3 就拦下或改写，不能留到后期：

| 风险类型 | 典型画面/措辞 | 处理 |
|---|---|---|
| **虚构热销状况**（《广告法》第 28 条） | 门店排长队、抢购、售罄、虚构成交量与用户评价、伪造"热销榜" | 改为"人流经过／多组人群使用"，人数硬限、间距松散、全程虚焦剪影；不得聚集、排队、拥挤 |
| **虚构使用效果** | 未量产产品的 AI 图被当作真实产品展示；AI 演示画面被当作检测/功效证据 | 角标常驻且措辞要具体（"AI生成概念示意"重于"AI生成演示"）；交付物里写死素材用途边界 |
| **素材用途越界** | 概念期 AI 图用于商品详情页主图、预售页、众筹页商品位 | 实物未量产时充当商品实况＝"商品实际情况与宣传不符"，属明确违规；素材仅限信息流投放测试 |
| **绝对化用语** | 顶级／国家级／最佳／第一／唯一／100%／彻底 | 改可核验的中性表述（"电影级""明显提升""验证市场反应"） |
| **效果承诺** | 保证爆款／必火／一定转化／停留率拉满 | 改"验证市场反应""提升素材产能"等过程性表述 |
| **价格与优惠断言** | 具体金额、折扣、限时倒计时（无真实依据） | 只保留模糊量级（"大几千"），具体数字一律后期由客户提供并核验 |

**改写授权纪律**：合规改词属"改台词"，必须经用户明确授权并留痕（原文/改后/理由三列），不得静默替换。

## Escalation

If the missing answer materially changes legality, consent, safety, or release claims, stop that operation and request the missing authority. Continue with unaffected creative planning when possible.

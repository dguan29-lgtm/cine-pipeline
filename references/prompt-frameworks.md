## 框架 A：总要求 + 时间戳分镜（SD2.5 中文主流，打斗基准）

结构 = **【总要求段】+【场景复杂度声明】+【时间戳分镜】**，全部包在一个【】内。

### A1. 总要求段字段清单（按此顺序堆叠）

1. **画质风格锚**：高清4K + 风格（如"日本动画，MAPPA动画工作室风格，赛璐璐，很细的轮廓线，没有阴影"）
2. **负向风格**：不是3D / 不是游戏 / 不是三渲二 / 不要超过0.5s的慢镜头
3. **角色绑定**：角色外观严格按照@图片1、@图片2，不要出现多余肢体
4. **运镜纪律**：人物不要跟丢，运镜有逻辑，动作有气势
5. **构图纪律**：不要平衡构图，而是带有倾斜（左边近右边远），镜头有纵深感和景深
6. **永动纪律**：角色的动作不要定格和处于没有动作的状态，角色不要停留在原地
7. **音乐**：视频全程不要音乐（或逐镜标注变奏，见通用打法第 6 条）

### A2. 场景复杂度声明（打斗必写，独立一句）

```
场景复杂，是@场景 的一个区域，有墙面分隔，有台阶，有支撑结构，有水。
```
给打斗提供可交互物（掩体/台阶/水面），否则角色只能在空地上站桩。

### A3. 时间戳分镜（每 1-4 秒一拍）

```
第1-2秒：镜头跟随 @角色A 边快速跑动并半转身对 @角色B 展开射击……（动作不要停顿，马上到下一个镜头），
第3-4秒：@角色B （镜头平移并马上移回，模拟她的视野在搜寻的感觉）……（动作不要停顿，马上到下一个镜头），
```

**三条复读咒语**（SSS 每镜都在复读，是防事故的核心手段）：
- **防停顿**：每镜末尾「（动作不要停顿，马上到下一个镜头）」
- **消歧义**：易误解的道具每次提及都复读定义「（不是普通的枪，而是角色手上的重型机械装备武器）」
- **锁目标**：「不要对着镜头射击，而是要对着角色射击，对着对方射击」

### A4. 打斗专用补丁（合并进总要求段）

- **对手可见性**：镜头中至少能看到对手的局部，不要完全是只有1个角色的画面
- **非正面**：打斗中都不是正面镜头，构图要倾斜
- **禁站桩**：两人的姿势不要站着，而是有飞踢、旋转、肢体交叉的专业战斗动作
- **攻防转换**：两人气势切换，分别占据上风和不利
- **战损累积**：身上有擦伤、灰尘、磨损痕迹（在多个镜头中复读，状态延续）
- **环境互动**：巧妙利用周围事物来调整自己的动作
- **空间逻辑**：所躲藏位置要有距离，而不是躲在同一个掩体后面
- **击杀链写法**（终结镜头）：镜头快速拉近到眼睛特写 → 瞳孔收缩 → 画面颜色变为黑白 → 偏头 → 彻底昏厥无力
- **飞行道具物理**：子弹轮廓清晰但处于自转射飞状态；飞行路线不是垂直于镜头，而是要从人和障碍之间穿过；不要悬空，不要停留，要飞出画面
- **镜头表演化**：（镜头平移并马上移回，模拟她的视野在搜寻的感觉）（第一人称视角的天旋地转）
- **道具惯性**：装备掉落到地上因惯性自转而朝镜头滚来
- **招式专业注解**：剪刀脚（摔跤的专业动作：剪刀脚）——名词+括号注解

## 框架 B：句哥基底（CG 打斗强化版，三角色混战实测可用）

结构 = **【质感基底段】+【场景环境段】+【时间戳分镜（带构图名）】+【打斗要求段】+【负面限制段】**。
特色机制：**【】方括号=关键词高亮**（把最关键的受力词、机制词用【】框起来，模型权重更高）。

### B1. 质感基底段（整段开头，一口气声明）

```
整体采用 @图片1 中的高精度电影级CG质感：UE5级高模硬表面角色，Nanite级机械微结构，
光线追踪全局照明与反射，稳定环境接触阴影，具有真实遮蔽和层次。
高速运动中人物面部、武器轮廓和接触点保持锐利，【背景形成具有明确运动方向的拖影】；
特效、流体【始终连接各自物理来源，并在动作结束后快速衰减】。
扳机社动画美学与【爆发式倾斜构图】、【极端景别跳变】与【强烈前后景压迫】；
金田透视法 + 近大远小的纵深拉伸、武器冲向镜头的夸张透视；
【清楚呈现格挡、接触、受力、位移和反击关系】；
【在速度峰值形成画面边缘外弯的冲击压力】。
【镜头跟随当前主动进攻者】，【并在力量转移时交接给受力者】；
【身体遮挡、刀刃擦镜】、爆炸碎片和【高速交叉换位触发切镜】。
【快速剪辑始终维持战场轴线】、角色和攻击方向，【接触瞬间加入极短冲击停顿】，随后立即恢复高速运动。
【能量归属清晰】；刀刃接触、格挡角度、身体支撑、【受力位移】、【落脚制动】和机械关节反馈完整可读。
【保持攻防因果】，主体面部、武器轮廓与关键接触点保持清晰，【动作特效围绕真实接触路径】【生成并自然消散】。
```

六个可拆用的独立机制（不写整段也要逐条吸收）：
1. **冲击停顿（hit-stop）**：接触瞬间加入极短冲击停顿，随后立即恢复高速运动——打击感的第一来源
2. **镜头主动权交接**：镜头跟随当前主动进攻者，力量转移时交接给受力者
3. **切镜物理触发**：身体遮挡 / 刀刃擦镜 / 爆炸碎片 / 高速交叉换位 = 切镜时机，不是导演心情
4. **战场轴线维持**：快速剪辑始终维持战场轴线与攻击方向
5. **特效物理**：特效始终连接各自物理来源，动作结束后快速衰减；围绕真实接触路径生成
6. **速度峰值形变**：在速度峰值形成画面边缘外弯的冲击压力（FPV 畸变感）

### B2. 时间戳分镜格式（带连续性声明+构图名）

```
0–3秒（是上一个镜头的延续，倾斜构图）：【第一帧已经处于】近距离重击，@角色A 架住武器；@角色B 从 @角色C 右后侧，【迫使】@角色C 反击。
3–6秒（是上一个镜头的延续，俯视构图）：……
```
- 「是上一个镜头的延续」= 镜间连续性声明；「【第一帧已经处于】」= in medias res，**不开场对峙**
- 技能路径量化：「水流技能【分成三路】，第1路锁住脚踝，第2路缠绕手臂，第三路贴上肩甲」
- 终态留钩：「两人形成前后夹击终态与遮挡……@角色C 仍然抬头【锁定】二人，为下一轮战斗留下【持续威胁】」
- 第三方介入：「周围的小鱼群和水母（特写，子弹时间）时不时介入打斗中从两个角色的中间快速横穿而过」

### B3. 打斗要求段 + 负面限制段（段尾固定两块，可直接复用）

```
【打斗要求：接触点必须清楚，必须有身体被打后的结果，每次攻击都要形成结果，动作要有起势，爆发，收势，不要连续空挥。镜头必须证明移动路线和打击结果。每次切镜都必须服务：接触点、位移结果、空间推进、终结技起势。不要只拍角色美图，不要长时间平视中景，不要用特效遮住接触。不开场对峙。
负面限制：过曝白雾、全局泛光、塑料皮肤、塑料木头、镜面石头、纹理平铺、全局模糊、脸和手被运动模糊糊掉。】
```

## 框架 C：结构化 YAML 六段式（minimax H3 / 英文输出 / 多参考图模式）

适合需要英文 Prompt、或 minimax H3 这类吃结构化输入的模型。六段固定：

```yaml
subject_definitions:        # 主体定义：<Subject N> / <Picture N> 逐个定义外观与参考来源
summary:                    # 一行式故事概要，前缀 [keyframe completion]（图生视频）或 [reference generation]（多参考）
retention_analysis:         # 一致性锚定：每个主体列出 (appears in [Shot 1], [Shot 3]) + fully_preserved - 保留的具体外观点
detailed_description:       # 首段全局风格声明；然后逐镜 [Shot N] At 00:03.500, the shot cuts to ...
overall_soundscape:         # 环境音/动作音分层描述（无配乐也写）
non_diegetic_music:         # BGM：配器+动态+情绪走向；没有就写 N/A
```

关键写法：
- **时间码精确到 0.5s**：`At 00:03.500, the shot cuts to a POV shot...`
- **运镜双参数**：`The camera pushes in with small amplitude at fast speed` = 幅度(small/large) + 速度(slow/medium/fast)，比中文"快速推进"更可控
- **台词格式**：`<d>[Chinese] 台词内容</d>`，前面必须带**声线演技指导**：`says in a smooth, teasing male voice with theatrical delivery` / `in a low smooth male voice with an enigmatic measured cadence`
- **落地缓冲物理**：`her knees bend deeply, flesh and armor compressing with visible elasticity, not a rigid mechanical stop`
- **retention_analysis 是防崩脸核心**：显式声明每个主体在哪些镜头出现、哪些外观点 fully_preserved，瞬态特效注明 `transient VFX element restricted to S2's entrance moment only`

## 框架 D：wan3.0 模块化（真人剧/古装/情绪戏）

结构 = **【模块二·全局设定】+【模块三·时间戳戏剧分镜】**。

```
【模块二·全局设定】
视频全程：手持的镜头，呼吸感。
表演核心：表情克制但情绪饱满；
视频全程只有两个人物：@角色A 和 一个蒙面黑衣人。
剧情中所有的物品和道具要合理摆放。

【模块三·时间戳戏剧分镜】
【1-2秒】（视频直接从@图片1 这个镜头直接开始）……（之后她的嘴唇的蓝色要始终保持）。
【3秒】……
```

要点：
- **状态锁定话术**：变化的造型状态必须写「（之后 XX 要始终保持）」——否则模型下一秒就丢
- **情绪写在肢体微动作上**，不写情绪名词：「似乎有些梗咽，欲言又止，鼻子微酸」「突然用左手的手腕擦拭自己的眼泪」「头跟着低垂得很低又突然抬头似乎要止住泪水」
- **遮蔽规则**（悬念保持）：「全程不要拍到那个主角的正脸」「（始终是背后视角）」
- 台词直接内嵌在时间戳里：她说：「我有金牌还不速速退下！」

## 框架 E：情绪微表情相位法（单镜头情绪弧，特写长镜专用）

来源：小满 44s/15s 举枪对峙。一个镜头演完「警惕→惊喜→凝固→愤怒→质问→松动→崩溃→释然」8 个相位，每相位 1-2 秒。每个相位写四个通道：

| 通道 | 写法示例 |
|---|---|
| 眼神 | 瞳孔轻微收缩，眉心迅速蹙起又松开；目光短暂向右下方逃开，又强迫自己回到镜头 |
| 呼吸 | 吸气突然停住；呼吸由屏住变成一次柔软而颤抖的呼气；呼吸在胸口断成两次 |
| 嘴/颌 | 嘴唇不自觉张开一点；用力抿住嘴唇，下颌线明显绷起；咬紧后槽牙 |
| 道具外化 | 持枪手出现一次极细微的晃动；枪口第一次向下偏移极小角度；食指开始主动离开扳机 |

- **相位时长量化**：「笑意只持续约一秒，她随即意识到自己仍然举着枪」
- **台词带演技注解**：「'凭什么'带着明显怒意，'现在才回来'却逐渐发颤，暴露出被遗弃后的委屈」
- **道具=情绪进度条**：枪口的稳定→微颤→偏移→退出画面，就是人物心理的进度条
- 单镜头声明：「视频一镜到底，不要切镜，画面基本保持参考图片的初始状态。摄影机只有几乎不可察觉的手持呼吸感。」
- **口型同步写法（2026-09-12 FACS 表演库回写）**：相位内有台词时，写「嘴唇在 X 和 O 的口型之间切换，同时保持 Y 的表情张力」——口型变化与表情肌肉状态同时声明，防止张嘴说话冲掉微表情。掩饰性台词（"我没事""随便你"）必须先推导真实情绪再分配相位，不按字面情绪演。
- **眼神活性四则（2026-09-14 ACTING 库回写，限界版——必须在 stage3 防坑第 1 条眼睛禁忌的红线内使用）**：①**眨眼节奏绑状态**——紧张=快速连眨，掌控=缓慢从容，恍惚=眨眼后目光失焦一拍；②**视线先于头转**——眼睛先到达目标，头再跟上，思想在台词之前先从眼神里漏出来；③**凝视是选择不是僵死**——人物寄存器是"捕食者式的几乎不眨"时，写成"极少、缓慢、刻意的眨眼，视线仍带意图地缓慢移动"，禁止零眨眼死盯；④**禁区**——以上只写眨眼频率/视线方向/凝视意图，"眼底/眼中/反光/catchlight（眼神光）"仍是禁区词（防坑第 1 条实测事故），光只写在脸上不写进眼睛。
- **与 FACS 词库分工（2026-09-16 漫剧导演库吸收）**：本框架管**时间结构**（一个镜头内情绪拆相位、每相位时长量化）；每相位的**肌肉内容**（四区拆解/真假笑/强度档）按需查 `facs-lexicon.md`（触发条件：特写/微表情/口是心非/情绪关键拍）——相位法定节奏，FACS 定动作。情绪弧跨度大的高压对峙，用其「情绪六阶段生理递进」选相位内容。

## 框架 F：MV / 音乐节拍驱动

- **每秒一机位+歌词逐句绑定**：「第 1 秒：女人的斜侧面，女人唱：'…'，第 2 秒：男人的俯视角度，男人唱：'…'」
- **周期性事件复读**：每 2-3 秒重复一次的环境事件写成固定括号句逐段复读：「（@图片4 这样的大型恐龙冲着汽车跑过来然后向车后方跑走，让镜头画面剧烈震动）」

- 音乐直绑：「音乐直接使用@音频1」+ 歌词是"…"

## 框架 G：图片资产 / 设计类质感咒语库

### G1. UE5 写实系（文生图/图生图通用底座）

```
整合细碎的细节为更干净的面，电影分镜：高清化，去噪点，改为虚幻引擎5光线追踪质感，
真人摄影风格，高级感留白，PS5游戏大作，不是海报，不是photoshop的设计图PSD，不是素材图，
不是Cinema 4D（C4D）、不是Blender 和 Octane Render 渲染。流畅的线条，不是粗糙的草图。
有明显的明暗交界和投影，侧逆光，光影对比强烈，没有文字。
```

### G2. 赛璐璐动画系

```
整合细碎的细节为更干净的面，画风的黑线是很细很细的细线，不是粗黑线，高清化，去噪点，
赛璐璐平涂风格的日本动画风格，MAPPA动画工作室风格，精致风格，色彩靓丽。流畅的线条。
```

## 框架 H：H3 中文商用直出长文式（2026-09-16 AniShort×MiniMax H3 案例库吸收）

> 来源：AniShort 0910–0916 七天商用案例（MV/MG 动画/TVC/电商投流/手绘特效/游戏 UI/片头）逐条拆解。与框架 C（H3 YAML 六段式）互补：C 是英文结构化输入；H 是**中文长文直出**——一条提示词生成完整 15s 商用短片，靠分区块+全局纪律+负面清单控制模型。适合广告、MG 动画、文字包装、片头片尾类"包装片"。

**硬约束：MiniMax H3 单次生成时长上限 15 秒**——所有创意与时间轴按 ≤15s 单条规划；更长内容拆多条分段生成（分段处选章节边界）。

### H1. 结构（六段固定顺序）

```
【规格头】MiniMax H3｜分辨率=2K｜时长=15秒｜画幅=16:9｜主体类型=…｜主体模式=…｜画面处理=…｜文字语言=…｜音乐模式=…
【参考素材说明】@图片N 逐张声明维度（场景视觉/文字包装/人物形象/产品身份锚图），「只参考指定维度，不直接复制，不出现真实品牌、原参考图 logo/标题/可识别文字」
【核心创意】一句话概念 + 时长画幅 + 赛道定位（"不是静态海报，不是普通产品广告，不添加价格、卖点承诺、CTA"）
【时间轴章节化】0-2s/2-5s/5-8s…每段一个主题词，每段只有一个主要变化
【贯穿全片区块】▍影像风格/▍文字包装/▍律动规则/▍场景切换/▍景别切换/▍人物规则/▍重要限制——全局纪律与逐镜分离，逐区块声明
【负面清单】英文负面轰炸段 + 中文关键禁令复述 + 白名单文字拼写禁令收尾
```

### H2. 可复用表达技巧（每条都是案例实测手法）

1. **文字白名单独立成段**：「必须准确显示的文字」单独列出（品牌名/Slogan/片名/署名），声明"除以上文字外画面不得出现任何其他可读文字"，末尾复述「不得改变、遗漏或错误拼写」——文字类需求防乱码/防错拼/防文字泛滥的三重锁。
2. **字号画面高度百分比**：小字 6%-10% / 标准 15%-25% / 大字 35%-60% / 巨大字 70%-130%（可出血、可只显示笔画局部）——排版用比例说话，不写"大一点"。
3. **景别全局禁令规避模型弱点**：「不要全身镜头，不要多人全景，全片只用近景/中近景/面部特写/手部特写/肩颈特写/半身镜头」——把模型画不稳的（全身/群像/复杂大场面）全局禁掉，把画得稳的写成唯一白名单。
4. **律动规则绑定音乐部件**（MV/卡点类核心）：hi-hat roll → 快速微震/跳帧/文字细碎重组；snare → 文字猛然放大/画面硬切/人物肩膀下压；808 bass hit → 低频压屏/画面短暂变形/文字纵向拉伸或横向压缩；vocal 重音 → 嘴型同步/下颌动作/头部点拍/手势推进。「人物动作、文字动效、场景切换、景别切换必须共同卡点」。
5. **状态连续变形声明**：「五个状态必须是同一空间和同一元素的连续变形，不是五个互不相关的模板」——逐段变形写明继承关系，防段落各自为政。
6. **材料依附**：「材料必须依附具体纸页/照片/印刷层，不作为统一滤镜」——质感词（颗粒/网点/划痕/套印偏移）逐项绑定具体载体，不写整体滤镜式描述。
7. **图层关系声明**：文字有真实图层关系（前景/中景/背景之间），人物会遮挡文字、文字也可压过人物局部，**但不能遮挡眼睛和主要面部表情**。
8. **遮罩恒定纪律**：全程遮罩类元素（望远镜/取景框）「必须全程完全一致，保持同样形状、位置、大小，不要变形、漂移、缩放、消失或重新生成，像固定在镜头前的一层统一光学取景框」。
9. **相机动作逐段量化**：每段写焦段+运动（「0.0秒从略高于产品的24mm广角全貌开始…12.1-15.0秒回到约35mm中景终版海报」），一镜一主运动。
10. **声音三层**：BGM 结构化配器（禁词：明亮流行/EDM build-up 等风格禁区声明）+ 音效映射具体动作（文字碰撞→短促硬质 hit）+ 同步点列举（哪三个关键视听同步点）。
11. **氛围配比百分比**：风格混合用百分比锁比例（「60%悬疑、40%爵士」）+ 漂移禁区（"不要太欢快"）。
12. **负向收尾双写**：英文负面段（No spheres, no 3D balls, no orbs... 连续否定）+ 中文复述最关键的两三条禁令——中英各说一遍，英文管渲染质感，中文管语义红线（含"禁止复制 Google/Apple 等现有品牌"类合规禁令）。

## 跨板块通用打法（12 条）

1. **复读咒语**：关键约束（防停顿/消歧义/锁目标）在每个相关镜头末尾原句复读，不是说一次就完事。模型的注意力是逐镜分配的。
2. **变身/变形步骤化**：「融合过程分5个不同的步骤和阶段」「（2秒时间重点表现变身的自然过渡的过程：脸变成狐狸的脸，尾巴变成狐狸的尾巴，然后身体变成狐狸）」——变形必须拆步骤+给足秒数，否则跳变。
3. **材质复读**：跨镜头状态用整句复读维持：「角色的衣服始终是湿漉漉的」（在多个时间戳里各写一次）。
4. **穿镜运镜**：「镜头从后车窗玻璃穿越到车中再从车前挡风玻璃中穿过」「镜头从基地的闸门地下的缝隙中钻入」——一镜到底的空间穿越感靠"穿过什么"来写。
5. **滑轨擦镜**：「镜头从他的法杖武器一头滑到武器末端」「镜头从脚尖向上滑到他脸颊」——沿物体表面滑动是展示装备的标配运镜。
6. **音乐变奏标注**：逐镜末尾标「变奏为恐怖的音乐 / 变奏为战斗音乐 / 变奏为神圣感的音乐 / 变奏为哀愁的音乐」——音乐情绪跟着剧情档位走，不要全程一种。
7. **白屏/黑屏收尾**：「屏幕被蒸汽弥漫白屏结束」「箭射出一刹那，镜头白屏结束」「黑屏结束」——高潮帧直接用纯色吞没，比渐隐有力。
8. **第三方介入物**：固定频率横穿画面的环境物（鱼群/水母/恐龙/蝙蝠/蝴蝶），增加场景活度+提供切镜遮挡物。
9. **镜头震动声明**：「镜头运动模糊，大幅度运镜」「（镜头抖动）」「纪录片跟拍抖动运镜」——紧张感靠镜头状态词，不靠形容词。
10. **多角色上限实测（SD2.5，20260807）**：14 角色 / 1200 字 / 15s——人物没变形、冷门角色结构理解到位、指定的两两对打全部配对正确；**但阵营站位丢角色**（A 阵营 7 人丢 1 个、2 人跑到对面）；**15s 时长内小动作会被跳过，大动作无丢失**。结论：单条视频角色 ≤7 个稳妥；>7 必须接受站位漂移；小动作要放在关键拍上写。
11. **群像开战写法**：「阵营中角色的位置不要太整齐，错落，有前有后，有的在地面，有的浮空」「角色都摆出各自的战斗动作，不是僵硬的站立，姿势不是固定的，而是在蓄力，各自挥舞手中的武器（花式动作，不是摆拍）」「每个角色都有各自的表情和潜在的故事感，和旁边的角色的表情都不同」。
12. **情绪/心理一句话声明**（双人镜头）：「这两人的心理状态是暧昧，思念，暗场杀机。衣服和头发灵动随风飞舞。」——用一句话锁定关系基调，模型据此分配微表情。

# 片头片尾创意设计库（Opening Title / Brand Ending）

> 来源：2026-09-16 拆解《AniShort × MiniMax H3 案例分享》（0910–0916 七天商用案例，重点吸收 0916 影视质感片头两条完整案例 + 0911/0912/0913 片尾定版做法）。
> 定位：**独立成片的片头（title sequence）/ 片尾（brand ending）包装设计**，以及正片中的片头段/片尾段设计。单条直出（一次生成即完整片头片尾，不靠后期快剪组装）。
> 与 stage2-script.md 第 2 节 OP/ED 的分工：OP/ED 节管**季播短剧的每集片头片尾节目段**（复用正片素材+剪辑台快剪+档案卡）；本文件管**包装片本身的创意设计**（署名系统/字体系统/视觉母题/构建式片名/品牌定版）——15s 直出完整片头片尾时以本文件为准，两边的收尾纪律（定格时长/音乐终止式）通用。

## 硬约束：MiniMax H3 单次生成时长上限 15 秒

- **所有片头片尾创意按 ≤15s 单条规划**。片头基准时长 15s（案例实测值）；不足 15s 的需求（10s 片头/5s 片尾定版）从 15s 时间轴模板里砍章节，不硬凑。
- 15s 内装不下"世界建立 + 署名 + 证据升级 + 片名构建"全部四层时，砍署名卡数量，**不砍片名构建与定格**（片名稳定停留 <1.5s 的片头等于没做完）。
- 需要更长片头 = 拆多条 15s 分段生成 + 后期串接，单条内仍按本文件纪律设计；分段处选在"证据升级"章节边界，不在片名构建段中间切。

## 一、片头五层结构（15s 直出基准，2026-09-16 AniShort 0916 案例提炼）

| 层 | 时间占比 | 干什么 | 案例锚点 |
|---|---|---|---|
| ① 世界建立 | 前 10-20%（1.5-3s） | 黑场/纯底 + 第一个视觉母题元素入场；分屏线、色块、画格"逐块贴入"，不做铺垫叙事 | 0916-1：黑底+圆形唱片轮廓，分屏线快速划出，元素逐块贴入 |
| ② 署名卡系统 | 20-60%（每卡 0.8-1.2s） | 导演/主演/主创/职位卡逐镜绑定，每镜一卡一转场；**中前段必须有一张卡以中尺度参与构图**，不许把全部文字堆到片尾 | 0916-2：前 40% 建立世界并出现文字，角色卡分散在镜头 4/5/7/9 |
| ③ 证据/信息升级 | 40-80% | 视觉母题连续变形推进信息密度（档案翻页→轨迹生长→结构拆解），每镜只引入一个新信息 | 0916-2 镜头 6-10：折叠蓝图展开为多层空间、虫洞线稿、轨迹分叉 |
| ④ 片名构建 | 最后 2-3s | 片名由母题元素**构建**出来（轨迹沿轮廓聚合成字/冰蓝套印/声音冲出），不是淡入浮现；构建完成后**稳定停留 ≥1.5-1.8s** | 0916-2 镜头 12：Display A 由冰蓝轨迹沿准确轮廓构建成宽体工程字，稳定约 1.8s |
| ⑤ 定格收尾 | 最后 0.5s | 全元素同步定格（强片头收尾）或 hard cut to black；音乐在片名处到达最高点并以明确终止和弦结束 | 0916-1：最后 0.5 秒所有画格、人物和英文署名完全定格 |

**结构纪律（三条，违反即重排）**：
1. **每镜一个主运动、一个新信息**——每镜只揭示新媒介/新行动/新证据/新尺度/新文字之一，不叠罗汉。
2. **最后 5 秒必须有新信息再进入片名**——片名不是"前面演完了所以该出字了"，是信息升级链的终点站。
3. **人物以职业动作被认识，不以对白**——片头人物只做剪影/局部/职业动作（旋钮、推开关、奔跑），不对白不嘴型。

## 二、署名卡系统纪律

- **每组署名只完整出现一次**：不重复同一职位、不重复同一人名、不让一人挂多职——重复署名是 AI 片头最高频穿帮。
- **文字白名单独立成段**：「准确英文文字白名单，大小写拼写固定，每组只完整出现一次，不能生成乱码或临时补字」——片名/导演卡/角色卡（主层姓名+副层职位）全部列入白名单，投喂词末尾再复述一遍"不得改变、遗漏或错误拼写"。
- **可读停留量化**：每张角色卡完整可读 0.8-1.2s，片名最终稳定 1.5-1.8s——停留时长写进时间轴，不写"短暂停留"这类虚词。
- **署名动效构建链**（署名卡的标准入场语法）：细线框先画出 → 名字从框内滑入 → 字母逐个出现 → 被色块遮罩揭示 → 短暂停住。禁止逐字弹跳、故障拆字、巨大立体字。
- 副层职位（DIRECTED BY / MISSION PILOT）字高为主层姓名的 25%-32%，固定对齐边线，绑在纸条/蓝图注释栏/档案标签等**具体载体**上。

## 三、字体三级系统（量化参数，防随机换字体）

| 层级 | 承担 | 量化锚点 |
|---|---|---|
| Display A（主标题字） | 片名 / 终版主字 | 明确字族+字重+宽度（如"扩展几何无衬线宽体，约700字重，直端点，开放字腔"）；片名占最终画面 60%-85% 画宽 |
| Display B（姓名编辑字） | 角色/导演姓名 | 与 A 形成强对比（衬线↔无衬线、宽↔窄、稳定↔构建），细横粗竖、字面高 |
| Utility（工程注释字） | 职位/标签 | 等宽或半等宽，中等字重，略宽字距，小字号，绑定具体载体 |

- **禁止随机换字体**：全片只用这一套三级系统，两套 Display 之间要声明对比维度（如"衬线/无衬线、宽/窄、稳定/构建"）。
- **字号按画面高度百分比量化**（动态排版通用，0911 中文文字案例实测值）：小字 6%-10% / 标准字 15%-25% / 大字 35%-60% / 巨大字 70%-130%（可主动超出画面边界、允许只显示笔画局部）。

## 四、视觉母题与持续组件（片头的视觉 DNA）

- **四持续组件法**：全片指定 3-4 个持续组件反复出场（0916-2：圆形唱片/黑洞入口、冰蓝轨迹线、矩形档案纸片、细工程网格），每次出现都参与构图——组件是片头的"角色"，比场景切换更能建立统一感。
- **状态连续变形声明**（防"五个不相关的模板"）：「五个状态必须是同一空间和同一元素的连续变形，不是五个互不相关的模板」——逐段变形必须写明继承关系（谁变成谁、保留什么、改变什么）。
- **材料依附纪律**：「材料必须依附具体纸页、照片或印刷层，不作为统一滤镜」——颗粒/网点/划痕/套印偏移等质感必须绑在具体载体上逐项列举（纸纤维、折痕、毛边、Xerox 噪点、半色调网点、1-3 像素套印偏移、扫描拖影、胶片片孔、照片白边、胶带、翘角），不写"整体做旧"。
- **图层关系声明**（文字与人物/产品）：文字可出现在前景/中景/背景之间，人物会遮挡文字、文字也可压过人物局部，**但不能遮挡眼睛和主要面部表情**——文字是画面主体的一部分，不是字幕。

## 五、转场来源化（片头转场的唯一合法写法）

每个转场必须由**画面内元素触发**并声明继承关系——「所有转场写入可见来源、切点、继承方向/形状/颜色/速度和下一镜新落点」。

来源库（0916-1 实测转场清单）：
- 圆形元素遮罩扩张（黑胶唱片圆→下一镜同位置圆）
- 竖向关闭（车门/纸夹合拢形成黑色遮罩）
- 人物长影横扫擦屏
- 线条拉直成切割线（红线拉直→锋利擦屏）
- 巨大字母/色块遮罩
- 分屏边框重组、画格逐块贴入、色块硬切
- 前景纸边/照片遮挡（物理遮挡切）

禁：柔和溶解、流体转场、粒子万能擦屏、碎纸爆炸、照片同时随机旋转。
全部转场**跟随鼓点/音乐重音**。

## 六、音乐与声音结构（15s 片头短曲四段法）

15s 片头音乐写成**一支完整原创短曲**（不是环境床、不是音效堆），四段式：

| 段 | 时间 | 功能 |
|---|---|---|
| 建立 | 0-2s | 主题动机入场（低频+特征音色），与第一视觉元素同步 |
| 推进 | 2-8s | 加入律动/音型层，推动翻页、轨迹、文字、机械动作 |
| 增层 | 8-12s | 弦乐/和声增层，可在证据升级高点短暂抽空再推进 |
| 高潮终止 | 12-15s | 片名处到达最高点，**以清晰终止和弦收束**——音乐终止与画面定格同时完成 |

- **三个同步点必列**：挑三个关键视听同步点显式声明（如：唱针落下 / 机械开关触发 / 最终片名）。
- **氛围配比百分比**：风格混合时用百分比锁比例（「60%悬疑、40%爵士」），并声明漂移禁区（"不要太欢快"）——防模型把混合风格漂向单一端。
- 音效绑定具体动作（纸页翻动/机械卡扣/唱针摩擦），"不连续堆 whoosh，不遮盖 BGM"。

## 七、片尾（Brand Ending）设计法

三种定版模式（按片型选一，15s 内片尾占 2-5s）：

| 模式 | 写法 | 案例锚点 |
|---|---|---|
| A 极简字卡定版 | 纯白/纯黑底 + 品牌名居中 + 无其他元素；音乐在这里收住，形成利落品牌落点；可搭配一个极小的副标（LEATHER GOODS / Slogan） | 0912 Shot13「NOCTURNE」/ 0913 Shot08「NOIR VALE」 |
| B 元素汇聚构字 | 全片视觉元素（圆点/线条/轨迹）汇聚、磁性对齐，**构建成**品牌字标；强调色点亮（H3 信号蓝）→ 全元素同步呼吸 → 定格 ≥1.5s | 0911 品牌网格动效 13-15s BRAND REVEAL |
| C 动作收束切黑 | 最后一拍所有场景碎片/全部元素**同步冻结**，hard cut to black；或闪白/胶片烧蚀切出 | 0910 MV「最后一拍所有场景碎片同步冻结」/ 0912 Shot12 最后 0.3 秒闪白切出 |

**收尾纪律（片头片尾通用）**：
- 定格时长下限：片名/字标 ≥1.5s，高潮定格 0.5s——低于下限的收尾 = 没收住。
- 音乐必须有终止式（终止和弦/收束音），禁止音乐凭空渐弱没写完。
- 切出方式三选一并显式写明：切黑 / 闪白 / 胶片烧蚀（配 0.3-0.5s 时长）。
- 片尾文字进白名单：品牌名+Slogan 逐字列出，末尾复述「不得改变、遗漏或错误拼写」。
- 片尾前的最后一段正文镜收束要"留记忆点"（背影+空间变大+余韵），给字卡落点让出情绪空间。

## 九、交付前自检（片头片尾专项，附加在 stage3 自检之后）

- [ ] 全片时长 ≤15s（H3 单次生成上限），时间轴无跳段、无超限
- [ ] 五层结构齐备：世界建立 / 署名卡（中前段有卡参与构图）/ 证据升级 / 片名构建（稳定 ≥1.5s）/ 定格收尾
- [ ] 每组署名只出现一次；文字白名单独立成段且末尾复述拼写禁令
- [ ] 字体三级系统给出量化锚点；字号用画面高度百分比；无随机换字体
- [ ] 持续组件 3-4 个声明齐全；状态变形写明继承关系；质感材料依附具体载体
- [ ] 所有转场由画面内元素触发并声明继承四要素（方向/形状/颜色/速度），跟随音乐重音
- [ ] 音乐四段式 + 终止和弦；三个同步点显式列出；氛围配比有百分比
- [ ] 片尾三选一模式明确；定格时长 ≥下限；切出方式显式（切黑/闪白/烧蚀）
- [ ] 每镜一个主运动、一个新信息；人物以职业动作被认识，不对白不嘴型

# 视听语言词典（Camera Lexicon）

> 每个词条 = 可直接写进 Prompt 的表述 + 心理动机 + 使用时机。
> 铁律：查不到动机的词，不要写进 Prompt。SD2.5 通识词可直接写；标注【转写】的必须用「名词+描述性解释」。

## 一、景别阶梯（10 级，附心理距离）

| 景别 | 画面范围 | 心理效果 | 什么时候用 |
|---|---|---|---|
| 大远景 ELS | 人如蝼蚁，环境吞没人物 | 命运感、史诗、渺小孤独 | 开场定调、结尾抽离、大场面 |
| 远景 LS | 全身+大量环境 | 人物与环境的对抗/融合 | 场景建立、走位交代 |
| 全景 FS | 全身，动作完整 | 肢体语言、人物调度 | 动作戏、舞蹈、走位变化 |
| 中远景 MLS | 膝上 | 接近真实社交距离 | 日常行进、多人并行 |
| 中景 MS | 腰上 | 客观中立，肢体+表情兼顾 | 对话标准景别、信息交代 |
| 中近景 MCU | 胸上 | 情绪开始介入 | 对话升级、关系发生变化 |
| 近景 CU | 领口上 | 情绪表达主力，共情 | 内心戏、情感段落 |
| 特写 BCU | 面部 | 情绪放大器 | 爆点、隐瞒、察觉、决心 |
| 大特写 ECU | 眼/唇/手局部 | 极致情绪或关键信息 | 决定性瞬间、悬念道具 |
| 插入镜头 Insert | 手/道具细节 | 信息补丁 | 关键道具、动作细节（信物、颤抖的手、握紧的拳） |

**景别节奏原则（运镜之外的第二节奏系统）**：
- 远→近 递进收紧 = 蓄力、把观众拉进人物内心
- 近→远 抽离 = 客观化、失落、余韵
- 跨级跳切（远景直接切特写）= 震撼、对比、短剧转场利器
- 相邻景别渐变 = 平滑常规，铺垫段用
- 同景别连切 = 压迫感递增（三个特写连击砸情绪爆点）

## 二、机位角度

**垂直方向**：
| 角度 | 心理效果 | 时机 |
|---|---|---|
| 鸟瞰/顶摄 | 上帝视角、宿命、审判 | 大场面、结尾定格、命运感 |
| 俯拍 | 贬低、弱势、被审视 | 角色受挫、被压制时 |
| 平视 | 中立、纪实、平等 | 常规叙事、纪实风 |
| 仰拍 | 力量、崇高、威胁 | 大佬出场、爽点反击、压迫者入画 |
| 贴地虫视 | 极端、不安、弱者视角 | 恐惧段、儿童/动物视角 |

**水平方向**：正面=直白对峙/打破第四墙；45° 斜侧=立体、最常用；正侧面=轮廓、行进感、对切；背面=神秘、跟随代入、背影叙事（离开/孤独）。

**特殊机位**：
- 过肩 OTC：对话半主观，肩的朝向交代站位与关系亲疏
- 主观 POV：角色眼睛所见，代入+悬疑；常配轻微手持
- 斜角【转写】：如「镜头倾斜，画面地平线歪斜」→ 失衡、疯癫、世界颠倒，慎用（风格化强）
- 窥视机位：透过门缝/窗框/人群间隙拍摄 → 隔离、被注视、不安
- 低机位贴地：速度感、卑微视角

## 三、运镜库（按功能分组）

### 固定类
- **固定机位**：旁观、让表演呼吸。短片艺术片主力。
- **轻微手持呼吸感**：纪实感、生理贴近。写实戏、纪实风。写法（2026-09-14 CINEDANCE 库回写）：写摄影师的物理状态——「掌机者的呼吸起伏、微小沉降、重心转移、不完美的有机修正」，禁止「数码抖动/随机晃动/稳定器式顺滑」（除非明确要求）。
- **锁定+人物调度**：舞台感，人物走入走出的变化即内容。

### 推拉类（沿光轴）
- **缓推**：不动声色聚焦，情绪慢慢收紧。「发现」「入迷」「决心成形」时刻。
- **急推**【爆点标配】：强调、惊觉、决定瞬间。短剧爽点三件套之一。
- **缓拉**：抽离、揭示处境、孤独感放大。
- **后拉揭示**：从局部拉出，画面里逐渐暴露全局（脸→拉出→满屋债主）。悬念与黑色幽默利器。
- **希区柯克变焦**【转写】：如「镜头与人物距离变化同时反向变焦，人物大小不变而背景空间剧烈拉伸变形」→ 认知崩塌、恐惧、世界倾覆感。
- **双人同步推近**：缓慢推近双人全景至双人近景，压缩两人之间的视觉空间 → 关系拉近、共同命运、对峙升级。两人达成共识或共同面对威胁时用。

### 摇移类（机位转动/平移）
- **横摇 pan**：跟随视线、扫视环境、引入新主体。
- **上摇 tilt-up**：由下至上揭示（鞋→脸=人物出场定义镜头）；仰望感。
- **下摇 tilt-down**：由重要到次要、失落、视线跟随倒下。
- **横移 tracking**：行进感、旁观流动；配前景遮挡物穿过=节奏与层次。
- **升降**：升=脱离、格局打开、希望；降=进入、靠近、压抑。**角色占比量化写法**：升到角色只占画面 5% 以下=宿命感/渺小感（悲剧高潮、重大决定后的留白）；降到角色充满画幅=降临感/命运逼近（重要角色登场）。不写占比只写"升高"=模型随意发挥。

### 跟随类
- **斯坦尼康平滑跟拍**：沉浸行进、一镜到底的骨架。
- **手持跟拍**：紧迫、混乱、纪实。追逐战标配（配广角）。
- **环绕 orbit**：仪式感、时间停滞的高光时刻。配慢动作=人物弧光顶点。每部片子 ≤2 次。
- **弧形运镜**：立体揭示、关系变化（从两人分离到同框）。

### 特殊
- **甩镜 whip pan**【短剧转场利器】：快节奏、情绪爆发衔接。写明方向。
- **甩镜+冻结帧**：极速甩镜后瞬间定格在关键画面（锐度最高）→ 冲击后凝固、悬念极致。短剧/短剧集尾强悬念标配；冻结 ≤1s 且保留次级运动（同第十四节第 14 条定格陷阱纪律）。
- **螺旋环绕**：环绕同时持续上升或下降 → 上升=升华/力量觉醒，下降=压迫/危机逼近。反派登场、决战对峙用。
- **FPV 无人机**：空间奇观、宏观调度。
- **子弹时间**【转写】：决定性瞬间，风格化强慎用。
- **变速**：回弹变速/慢动作。慢动作留给爆发瞬间，配音效处理（骤停或放大）。**升格/降格转写**（2026-09-29 补，防写法漂移）：升格=「动作以慢于真实时间的速度展开，约为真实速度的 1/2-1/4，布料与碎片的运动轨迹清晰可辨」；降格=「动作跳动式加快，约真实速度的 2 倍，带轻微卡顿的抽帧感」。
- **监视器视角**【转写】：如「模拟监控摄像头的高位固定俯拍，画面带颗粒噪点与录像质感」→ 被监视感、客观冷峻。犯罪惊悚、角色被跟踪、反乌托邦。
- **水面下视角**【转写】：如「镜头从水面下向上拍摄，画面有水波折射扭曲、气泡与蓝绿色调」→ 窒息感、异世界感。落水、濒死体验、梦境。
- **延时/超延时**【转写】：如「时间加速，云层快速流动、光影快速变化」→ 时间流逝、场景建立；镜头在延时中持续移动=超延时，旅程感、城市穿越。
- **倒放**【转写】：如「所有运动反向播放，时间倒流」→ 回溯真相、命运感、超现实转场。
- **频闪**【转写，慎用】：如「画面以极短间隔在清晰与模糊间切换闪烁」→ 混乱、精神不稳定、灵异干扰。一段戏至多一次。

### 悬疑惊悚组（配 genre-modules 模块 D 使用，策略层纪律在那边，此处只收招式）
- **焦点呼吸**：焦点在主体与背景之间交替切换，每焦点停留 1-1.5 秒循环 → 不确定威胁、无法聚焦的恐惧。鬼魂将现、角色感到被注视时用。【转写】写法同第五节焦点三律的移焦句式。
- **幽灵轨道**【转写】：如「镜头以不自然的漂浮感移动，轨迹非直线带 S 形偏移，高度轻微浮动，速度忽快忽慢」→ 鬼魂视角、被注视的不适。
- **固定机位+画外入侵**：镜头完全固定 ≥3 秒建立安全感，然后恐怖元素从画框边缘缓慢或突然侵入 → 观众比角色先看到危险。与模块 D「负空间藏怪」配套。
- **天花板垂直俯拍**：镜头在天花板高度垂直向下，角色抬头看向镜头 → 被注视、压迫、无处可逃。
- **缓推+暗角渐强**：缓慢推入同时画面四周暗角逐渐加强，视野收窄 → 幽闭恐惧、危险逼近。
- **甩镜+鬼影残像**：极速甩镜的模糊帧中植入半透明人影残像，甩镜结束后画面空无一人 → 细思极恐，观众怀疑自己看错。一段戏至多一次。
- **荷兰角缓慢回正**：画面倾斜 15-30 度后极缓慢回正（5-8 秒）→ 心理失衡被"扶正"，比静止斜角更不安。世界动摇又恢复、悬疑揭示后用。
- **抽帧跳跃**【转写】：如「连续运动中人为抽掉几帧，动作产生不连贯的卡顿跳跃」→ 时间撕裂、灵异干扰、精神恍惚。与打斗抽帧（第十四节第 10 条）区分：那边是打击感骨骼，这边是时间异常。

### 转场选型决策表（2026-09-29 补——段头只枚举类型，本表管"什么叙事目的选什么"）

| 叙事目的 | 首选转场 | 写法要点 | 避用 |
|---|---|---|---|
| 同时刻同场景延续 | 硬切 / 帧链延续 | 跨段硬连贯用末帧截图绑首帧（stage3 防坑 12），段头标「同时刻同场景延续」 | 叠化（稀释连续感） |
| 隐含跳秒（同场景几秒后） | 硬切 + 道具状态延续 | 段头标「隐含跳秒」，道具/姿态具体值延续（"半杯奶茶"） | 空镜（拖节奏） |
| 明确跳时（小时/天级） | 空镜+声音先入 / 叠化 0.5-1.5s | 跳时必须给"光的理由"（天色/光源变化）；字卡只在信息不可替代时用 | 白闪（力度过大） |
| 长跨度跳时（隔年/时代） | 匹配剪辑+运镜延续 / 极简过渡帧 | 相似形状/构图衔接两个时空，运镜方向首尾承接 | 硬切（观众失锚） |
| 闪回/回忆 | 反射切入 / 叠化 / 双画质 | 闪回色卡与当下对立（0.5s 可辨时空）；感官碎片选材法（§14.9） | 字幕写"回忆" |
| 情绪断裂/震惊 | 黑帧闪断 / 白闪过曝（过渡帧三件套，§14.8） | 1-3 帧非叙事帧，配声音骤停 | 叠化（力度不够） |
| 场景缓冲/呼吸 | 空镜+声音先入 | 下一场环境音先于画面进入 0.5-1s | 连续硬切（无喘息） |
| 时空升维/意识流 | 同构图升维蒙太奇 / 时空转换三级桥（§8 组合公式） | 人不动、世界变；三级桥：行进远景→主观坠落→极简过渡帧→新时空大全景 | 逐一交代过程 |
| 快切蒙太奇内部 | 匹配切/动作连续切（切接六式，§12） | 切点由物理事件触发，卡鼓点 | 溶接（糊） |

**声音转场（J-cut / L-cut / 声音桥，2026-09-29 补——画面切点与声音切点解耦）**：

- **J-cut（声音先入）**：下一场的声音在本场画面末尾提前 0.3-1s 进入——场景切换的润滑剂，观众先"听见"再"看见"。写法：镜头层音效字段写「（0.5s 后画面才切换，下一场的教室喧闹声先入）」。
- **L-cut（声音拖尾）**：本场声音跨过切点延续 0.3-0.5s 进下一场画面——缝合跳切断层、保留情绪余震。写法：「（台词余音拖过切点 0.3s，画面已切至空荡走廊）」。跳切衔接处默认用 L-cut 声音桥（stage3 防坑 28 同族）。
- **声音桥（sound bridge）**：用同一声音元素（钟声/雨声/音乐动机）横跨两个时空的画面——时空跳跃时观众的听觉锚点。写法：在两段段头都声明该声音元素为「跨段声音桥：X 延续」。
- **纪律**：声音转场是剪辑台操作，生成端只需在音效字段标注意图（提前进/拖尾/桥接），实际执行在后期；设计性静默（如爆点前抽空）必须显式写时长与目的，不留"意外真空"（见防坑 28）。

### 转场与叙事组（招式库）
- **匹配剪辑+运镜延续**：两个时空通过相似形状/构图衔接，前镜头末尾运镜方向=后镜头起始运镜方向 → 时空跳跃、命运呼应。与第十二节同向衔接同源，跨场景使用。
- **空镜+声音先入**：先切无人环境空镜缓慢横摇，下一场的环境音先于画面进入 → 场景缓冲、呼吸感。每场开场与场景切换的润滑剂。
- **叠化**：前画面渐隐与后画面渐显重叠 0.5-1.5 秒 → 温柔过渡、时间流逝、回忆闪回。硬切太狠、闪白太炸时的中间档。
- **穿越墙体**【转写】：如「镜头穿过墙壁从一个空间无缝进入另一个空间，穿越瞬间画面轻微变暗或模糊」→ 空间关系揭示、两个空间无真正隔绝。
- **反射切入**：推近玻璃/水面等反射面，反射清晰后直接切入反射内容 → 虚实难辨、记忆交错、平行现实。闪回与内心世界专用。

### 运镜使用纪律
1. 一镜一主运镜，最多叠加一个辅助（如「低机位+缓慢环绕」）。
2. 运镜方向有语法：**推=进入/聚焦，拉=离开/揭示，升=希望/脱离，降=压抑/逼近，左移/右移=选择与对比**。
3. 短剧 80% 镜头只用固定/急推；炫技运镜（环绕、子弹时间）一集 ≤2 次。
4. 转场写清触发点与方式：「第 5s 快速向左横移转场（向左擦除+自然叠化）」。
5. **运镜时间曲线四要素（2026-09-29 补——治"等速=AI 感"，与 generation-qc 审美层第 4 维诊断闭环）**：文戏运镜默认带曲线写法，不是只写"缓推"两个字——
   - **启动时机**：运镜在镜内第几秒启动（「第 2s 开始缓推」——表演先立住，运镜再介入；开场即动=镜头在"等"内容）；
   - **到位时机**：运镜在镜内第几秒完成（「第 4s 推到位后停稳」——运镜必须有终点，推到剪点=观众没看清就切走）；
   - **缓入缓出**：起步慢、中途快、收尾慢（「缓起缓收，非匀速」——匀速运动是"运镜很 AI"的首要病灶，摄影机不该"预判"人物动作，跟随可带轻微延迟）；
   - **运镜占比**：单镜内运镜时长 ≤ 镜长 70%，其余时间让位给表演与留白；≤3s 短镜装不下完整曲线就写「固定」或「微手持」，不硬塞运镜。
   写法示例：「缓推（第 1s 缓起，第 2-4s 中段加速，第 5s 推到位停稳）」。
6. **运镜风险分级（2026-10-03 director-skills 库吸收——按首帧空间可达性选运镜，不是写完再说）**：
   - **A 级（低风险）**：固定、单轴推拉/升降/摇——图生视频默认优先；
   - **B 级（中风险）**：环绕、穿门/穿窗、摇臂——需首帧空间审计确认路径物理可达（见 stage3「空间与连续性纪律」）；
   - **C 级（高风险）**：360° 环绕、FPV 长距离穿梭——须首尾帧锁定或主动降级为 B 级方案。
   选 B/C 级运镜必须在镜头备注写明空间依据；无依据的高难运镜是生成事故高发区。
7. **运镜公式母版（同上）**：写运镜按此顺序——起点机位 + 明确轨迹 + 速度与稳定性 + 跟随对象 + 主体动作 + 依次揭示的已有空间 + 落点；先定运动，再配镜头光线情绪。

## 四、焦段语言（焦段=情绪，不是数字游戏）

| 焦段 | 视觉特性 | 心理效果 | 典型用途 |
|---|---|---|---|
| 14-24mm 广角 | 透视夸张、边缘畸变、空间放大 | 张力、速度、环境主宰人物 | 追逐、动作、宏大场面；**近拍脸会变形，慎用于面部** |
| 35mm | 环境与人物平衡 | 纪实之眼、生活流 | 街景、群像、日常铺垫 |
| 50mm | 接近人眼透视 | 中立自然、不抢戏 | 对话、常规叙事主力 |
| 85mm | 压缩+背景隔离 | 柔焦氛围、情绪聚焦 | 人像特写主力、情感戏 |
| 135mm+ 长焦 | 强压缩、前后景叠压 | 窥视、疏离、宿命感 | 隔着人群/车流看主角、远观孤独 |
| 微距 | 极近 | 物件叙事 | 信物、汗珠、颤抖的手（Insert 用） |

**焦段-景别联动（同景别不同焦段=不同情绪）**：
- 广角拍特写 = 夸张变形的疯狂/惊恐
- 长焦拍特写 = 扁平温柔的唯美/悲伤
- 广角拍远景 = 空间史诗；长焦拍远景 = 人群压缩的命运舞台

**焦段落地写法（2026-09-14 CINEDANCE 库回写——模型吃"可见光学结果"不吃器材元数据）**：
毫米/光圈值/镜头品牌名是导演语言，投喂时转写成可观察的光学结果。对角线视场角（FOV）+ 效果短语栈比 "85mm f/1.4" 管用：

| 导演语言 | FOV 写法 | 效果短语栈（按类取用 ≥3 条） |
|---|---|---|
| 大广角环境 | 107° diagonal field of view | 前景体量压迫性放大 / 环境铺展到画幅边缘 / 边缘到边缘深景深 / 直线保持笔直无鱼眼鼓包 |
| 广角 | 84° diagonal field of view | 前景身体存在感大于自然比例 / 主体四周环境保持可见 / 摄影机物理贴近主体 / 无长焦压缩感 |
| 标准 | 47° diagonal field of view | 接近人眼透视、零明显畸变 / 背景可读不夸张 |
| 中长焦人像 | 29° diagonal field of view | 主体锐利、背景开始压缩贴近 / 近靠构图由镜头焦距达成而非物理贴近 / 背景溶成奶油散景 |
| 长焦 | 18° diagonal field of view | 背景强压缩层叠在主体身后 / 焦平面薄如刀片只锁住眼睛 / 画面有远距离观察感 |
| 超长焦窥视 | 8° diagonal field of view | 背景压平成色块 / 前景虚化遮挡物占画面下部 30-45% 框住主体（强制） / 大气薄雾悬浮于镜头与主体之间 |

配套防漂移锁（一段一焦段性格，与本词典"一镜一主运镜"同级）：长焦段内任何更宽的取景靠"同焦段拉远机位"实现，不换镜头；不同焦段性格之间只硬切，无平滑变焦过渡。混合内容类别（脸+环境+微距挤在一拍）= 焦段漂移根源，拆成独立镜头各配焦段。

## 五、焦点变化三律（解决"随意变换"）

焦点变化只有三种合法动机，其余一律不写：

1. **注意力转移**：A 说完话 → 焦点从 A 移到 B 的反应。等于用焦点代替一次剪辑，对话戏核心技巧。
2. **信息揭示**：前景清晰→背景由虚变实，揭示关键人物/道具入画（身后的陌生人、桌上的刀）。
3. **情绪转换**：清晰→虚化 = 恍惚、失神、醉酒的主观状态；虚→实 = 苏醒、回忆结束、回到现实。

**写法【转写】**（SD2.5 对移焦类术语需要解释）：
「移焦，画面焦点发生平滑转变，前景的酒杯由清晰变模糊，背景中女子的脸由模糊逐渐变得清晰。」

**其他焦点状态**：跟焦（主体运动中保持清晰，行进戏）；开场先虚后实（揭示/苏醒）；失焦（主观眩晕、崩溃瞬间，电影级慎用一次）。

## 六、光圈/景深语言

| 光圈 | 景深 | 心理效果 | 用途 |
|---|---|---|---|
| f/1.4-2 | 极浅 | 世界只剩主体，私密、内心化 | 情感特写、孤独时刻 |
| f/2.8-4 | 中等 | 主体清楚、环境可辨 | 叙事常规档 |
| f/8-16 | 深 | 全员在焦、环境叙事 | 群像、前后景呼应、框架构图（母题用深景深） |

- 短剧竖屏特写常配大光圈（背景干净、脸突出）。
- 电影级群戏用深景深（人物关系在空间里并置，调度代替剪辑）。

## 七、光影与色卡速写

**光向**：顺光=平实纪实；侧光=立体、矛盾对立；逆光=轮廓、神圣/悲情；顶光=压迫审判；底光=恐怖扭曲。
**光质**：硬光=冲突锐利；柔光=温柔浪漫。
**经典人像布光**：伦勃朗光（戏剧人像）、蝴蝶光（魅力美颜）、分割光（内心分裂，一半亮一半暗）。
**色卡情绪表**（全片层选卡依据）：冷蓝=疏离忧郁；暖橙=温情怀旧；青绿=阴郁悬疑；金黄=辉煌欲望；红=危险情欲暴力；低饱和灰白=冷漠、医院、体制。
**色卡落地写法（2026-09-14 LIRA 库回写）**：色卡投喂用 60/30/10 百分比+真实色名——「60% 暖赭、30% 深炭、10% 锈红」；百分比从剧本情境/参考图推导，不凭空发明。

### 光影三层构词法（2026-09-12 抖音光影教程回写——治"光影写了但不突出"）

> 塑料感的根源不是没写光影，而是写了**泛化打光词**（"柔光""电影感打光"）——模型没有可执行的物理信息，只能渲染成均匀平光。光影字段按三层写，每层给物理实体：

| 层 | 写什么 | 示例（中文描述，必要处英文兜底） |
|---|---|---|
| ① 物理光源 | 具体光源+方向+时间/色温，不写"柔光"写"什么光从哪来" | 黄昏低角度侧后逆阳光（golden hour side-backlight）/ 阴天云层漫射顶光 / 左侧窗框透入的清晨斜光 |
| ② 介质透光 | 光与画面里具体材质的互动——穿透/折射/散射，光是"碰得到东西"的 | 阳光穿透发丝勾出金边（translucent backlit hair）；皮肤耳廓与鼻翼透光泛红（subsurface scattering）；肥皂泡/水珠折射出彩虹；光穿过烟雾/水汽/尘埃形成可见光路 |
| ③ 光学响应 | 镜头与大气的光学瑕疵——实拍感的来源，摆脱 3D 渲染味 | 强光源入画时的镜头眩光光斑（lens flare）；空气薄雾的体积光感（atmospheric haze）；背景光斑虚化成圆形散景；手持呼吸感的轻微晃动 |

**纪律**：
- **正面平光 = 塑料感**：人物主光禁止正面均匀平光（人物写真需求除外）；默认侧光/侧逆光起步，让脸上有线、有影。
- **②③层必须有画面内实体依托**：没有发丝/水汽/烟雾/透明物体就别硬写透光与体积光——光路需要介质。
- **可见光柱（丁达尔光路）要给强度词（2026-09-14 实测）**：只写"空气中漂浮微粒"通常只得到整体雾感，光柱出不来；要写成「一道道清晰的光柱从[光源方向]斜切进画面」并让介质浓度显性化（浓烟雾/大雨后的浓尘/香火浓烟），光路才有形状。
- **光学瑕疵是点缀不是基调**：眩光只在强光源真正入画时出现，一段戏至多 1-2 镜；滥用眩光/体积光 = 过曝白雾，与打斗段负面限制（禁全局泛光）同一红线。
- **风格适配**：写实/CG/真人感三层全用；赛璐璐/平涂动画风弱化②③（平涂逻辑不吃散射与镜头瑕疵），只保留①的光源方向。
- 手持呼吸感不重复定义——运镜侧写法见 prompt-frameworks 框架 D 全局设定模块。

**反面 → 正面对照**：
- ❌「柔光，电影感光影」→ ✅「黄昏低角度侧后逆阳光，穿透她的发丝勾出金边，空气薄雾中可见光路，镜头边缘一点眩光」
- ❌「明亮的室内光」→ ✅「左侧窗框透入的清晨斜光，照亮桌面漂浮的尘埃形成光柱，他耳廓透光泛红」

### 逆光曝光优先级锁（2026-09-14 CINEDANCE 库回写——治"逆光被自动提亮成平光"）

模型默认给脸补光，逆光/剪影需求不写曝光优先级就会被拉回平光。写法：
- 「整个镜头为逆光曝光，不为脸曝光。主体保持在摄影机与更亮的背景之间，摄影机位于主体的阴影面；面部允许沉进死黑，只有轮廓光、边缘光、湿面高光与环境反光交代细节。无正面主光、无美颜补光。」
- 剪影/轮廓光镜头（第八节"剪影对抗"、第十四节"弱者画底剪影"）投喂时此锁常驻。

## 九、对话戏基础（轴线与正反打）

- **180° 轴线**：对话段落所有机位保持在两人连线同一侧，否则空间左右横跳（AI 生成同样会乱）。写 prompt 时给空间锚点（「A 在左、B 在右，始终保持」）。
- **刻意越轴**：在对话或动作中突然切到轴线另一侧机位 = 混乱、失衡、关系破裂、局势突变——唯一合法动机是"关系在这一刻变了"，且一段对话至多越一次。无理由越轴=事故（打斗段纪律见第十四节第 17 条）。
- **正反打**：过肩互切是标准；用景别不对等制造权力关系（A 给近景、B 给中景 = A 压 B）。
- **反应镜头**：情绪的镜子，短剧的核心武器（决策规则见 stage3-storyboard.md）。

### 空间站位分级（S0~S4，按戏复杂度加载，2026-09-16 漫剧导演库吸收）

空间调度能力按复杂度分级，低等级不加载高等级规则，省 token 不省必要项；**判定不清按高一级处理**：

| 级 | 场景 | 要求 |
|---|---|---|
| S0 单人 | 独角戏 | 简版站位一行（位置+朝向+动作），免轴线、免位移链 |
| S1 双人静态 | 对话戏 | 一行式站位声明（每人：位置+朝向+依托+状态）+ 轴线行（左A右B·禁越轴） |
| S2 多人静态（3-4 人） | 群像文戏 | 站位声明全员具名（每人四要素）+ 轴线行 |
| S3 多人移动 | 调度戏 | S2 + 逐人位移因果链（起点→终点，每步有动作原因，禁瞬移） |
| S4 复杂战斗/多空间切换 | 武戏·群战 | 全量：顶视图机位调度（见下）+ 合法越轴 + 帧链延续（stage3 防坑 12） |

**机位编码（CAM1~CAM4，S4 顶视图调度用）**：先画空间俯视平面（角色位置、门窗障碍、光线入口、动作轴线），再部署机位表（编号·焦段·高度·镜头任务），所有机位布置在轴线同一侧：

- **CAM1 主建立/空间全景**：30°~60° 斜角俯拍或中远景，确立空间几何与左右朝向；
- **CAM2 正拍/双人交锋中景**：平视或微仰，承载对抗与动作发起；
- **CAM3 过肩反打/单人近景**：主观视点过肩，捕捉压迫感与生理反应；
- **CAM4 特写/顶视俯拍/动力学跟随**：微表情特写、要害接触俯拍或大招运镜。

**合法越轴的工程三手段**（与上文"刻意越轴"的艺术动机区分——那是叙事选择，这是不穿帮的技术路径；段头声明用哪种）：
1. **镜头内过轴**：摄像机在单个镜头内跟随角色走位连续旋转穿过轴线（运动中过，不是硬切过）；
2. **中立镜头过渡**：中间插正面正对两人的中立镜头或特写细节（cutaway），下镜再切反侧；
3. **重击重建轴线**：角色受重大物理打击翻滚位移后，重新建立新轴线（打斗越轴的标准做法）。

- **90° 侧拍禁令（中全景）**：中景/全景严禁 90° 侧面正拍（街机横版平面感），必须 30°~60° 斜角借前后遮挡与背景纵深；仅近景/特写（胸部以上/手部对招）允许 90° 侧拍。

## 十、视听转译表（抽象 → 具象，剧本进分镜的硬门槛）

> 核心拷问："这句话摄影机拍得到吗？麦克风录得到吗？拍不到的必须转译。"
> 转译四步：①识别抽象 → ②演员用身体哪部分演（眼/手指/肩/呼吸/步伐）→ ③摄影机用什么拍到（景别/焦段/角度）→ ④声音/光线/物件要不要辅助。

**心理状态类**：
| 抽象描述 | 表演（具象） | 镜头 | 辅助 |
|---|---|---|---|
| 内心崩溃 | 手指在桌下捏紧另一只手；呼吸短促但表情维持平静 | 桌下手部超特写（微距+大光圈） | 环境音下沉 |

| 心一横（决心） | 握紧拳头；咬肌跳动；瞳孔收缩 | 急推特写 | 动作音放大成"标点声" |

**关系状态类**：

|---|---|---|---|

| 试探/鼓起勇气 | 动作慢一拍；眼神短暂上抬再下移 | 搅拌动作手部特写+眼神特写 | 吸管碰杯壁声放大 |

**戏剧动作/氛围类**：

## 十一、运镜中英对照（中文歧义时加英文兜底，无歧义不加）

| 只写中文（无歧义） | 中文+英文（易识别错） |
|---|---|
| 推 / 拉 / 摇 / 移 / 跟 / 升 / 降 | 滑轨（Slider）｜轨道推/拉（Dolly In / Dolly Out）｜升降（Crane / Jib）｜斯坦尼康（Steadicam）｜变焦推/拉（Zoom In / Zoom Out）｜希区柯克变焦（Dolly Zoom）｜鱼眼跟拍（Fisheye Tracking）｜微移（Micro Move）｜360°环绕（360° Orbit）｜子弹时间（Bullet Time）｜鸟瞰（Bird's Eye / Top-Down）｜快切（Cut In）｜甩镜（Whip Pan） |

## 十二、运镜衔接 5 模式（镜头之间的能量传递）

| 模式 | 组合 | 效果 | 适用 |
|---|---|---|---|
| 同向衔接 | 上镜推→下镜继续推 | 能量累积、情绪升温 | 揭示真相 / 情感升温 / 恐惧累积 |
| 反向衔接 | 上镜推→下镜拉 | 心理拉扯、抽离孤独 | 决断后孤独 / 高潮后余韵 |
| 静切动 | 上镜固定→下镜运动 | 情绪从凝固被激活 | 决断瞬间 / 转折点 |
| 动切静 | 上镜运动→下镜固定 | 情绪沉淀 | 动作完成后的静默余味 |
| 同质叠加 | 多个同性质运镜连用 | 形成作者风格 | 手持×N=焦虑纪实；固定×N=仪式克制；快切×N=节奏暴烈 |

**红线**：❌ 一段戏内运镜方式过多（摇+推+拉+升+摇=风格混乱）；❌ 大角度奇技运镜（希区柯克变焦/子弹时间）连续 ≥2 次；❌ 同向衔接超 4 镜（能量过载）；❌ 三个连续手持后突然固定（除非戏剧动作要求）。
**剧本气质决定组合**：冷静克制=固定为主+少量手持+1-2 个反向；紧张焦虑=大量手持+快切+静切动；浪漫梦幻=滑轨长镜+同向+慢速推拉；悬疑揭示=同向推进+揭示瞬间反向拉远。

### 切接六式（5 模式的细化执行层，2026-09-16 漫剧导演库吸收）

> 5 模式管运镜能量传递；六式管**切点落在哪**——切镜不是拼贴，是视线引导与动力学传递。段内受控多镜的切镜类型声明见 stage3 防坑第 7 条，两处配合使用。

| 式 | 衔接方式 | 视听原理 | 适用 |
|---|---|---|---|
| 一式·动作连续切 | 动作发起在中景，击中瞬间切近景/特写 | 视线顺肢体运动方向自然过渡 | 重拳冲锋、腾空下劈、兵器劈砍 |
| 二式·反应镜头切 | 重击命中瞬间切防守方瞳孔骤缩/队友惊呼 | 借他人视线与情绪放大危险 | 破防绝杀、杀招初现（与反应镜头决策①同源） |
| 三式·景别跳切 | 极近景微距（滴血/眼神）骤切大全景（地裂/烟尘） | 尺度极大反差=戏剧冲击 | 终结技爆发、蓄力后瞬间释放 |
| 四式·视线引导切 | 上镜运动末端焦点在右侧，下镜入画点严格承接右侧 | 观众视线不搜索，极度流畅 | 高速连环对招、多目标穿插追击 |
| 五式·遮挡过渡切 | 躯干/障碍物/武器快速擦过镜头切入下镜 | 运动模糊+暗影无痕转场 | 巷道追逐、室内外切换 |
| 六式·动势匹配切 | 上镜向右翻滚的惯性，由下镜向右滑步的冲势承接 | 物理动量在切点间守恒 | 被击飞撞墙、借力打力反击 |

**视听省略法则（高级留白）**：
- **省略冗余过程**：拔刀动作发起后直接切刀尖染血归鞘，略去中间无戏剧价值的挥砍（stage3 防坑 22「写状态不写过程」的剪辑版）；
- **环境代击打**：用震落的落叶、震碎的窗玻璃、水面波纹表现隔空劲力——高手过招不拍接触，拍后果。

## 十三、构图雷区（B 类永不保留，A 类默认禁 + 白名单解锁）

## 十四、权力、觉醒与登场的视觉系统（对抗/燃向题材实战提炼）

> 来源：一部 100 秒 AI 神话对抗短片（凡人之怒 vs 漫天神佛 vs 大圣救场，44 镜）的逐帧拆解。
> 每条可独立使用；组合使用即构成「权力翻转」的完整视觉叙事。

### 1. 碎片开场（Detail-first Cold Open）

开场不给脸、不给全景：用 2-4 个极近的身体/物件宏观（血衣纹理、锁链手腕、滴血的嘴角）建立质感与悬念，观众被迫先"猜处境"；4-6 秒后才拉到大全景揭示。
- 心理动机：信息缺口=注意力钩子；苦难先被"摸到"再被"看到"。
- 写法：每个碎片 1-1.5s，全部微距/大特写；最后的大全景揭示停顿 ≥3s。
- 适用：复仇/审判/囚禁/战败等"开局即绝境"的题材。

### 2. 权力比例构图（体型压制系统）

权力关系不用台词说，用画面里的体型比说：

| 比例档 | 画面处理 | 心理效果 |
|---|---|---|
| 蚍蜉档 | 弱者=画底约 5% 的深色剪影，强者/阵营占满上半幅 | 蚍蜉撼树、悬殊绝望 |
| 对峙档 | 双强同画幅等高对峙，弱者退到画边 | 权力平权、谈判感 |
| 三级阶梯 | 同画面排出 凡人→巨神→更强者 三级体量 | 救场者的量级一目了然 |

- 配套机位：看强者用「过弱者肩的极端仰视+广角」；强者看弱者用「高机位俯拍/透过道具俯视」。
- 即第九节"景别不对等=权力不对等"的极端化。

### 3. 环中窥世（道具内框的权力取景器）

透过掌权者身上的环形物（佛光、项圈、扳指）俯拍下方世界——权力者的"注视"被器材化：他看世界就像透过瞄准镜。
- 是窥视机位的权力变体：门缝窗框=被注视的不安；环形圣物=被审判的宿命。
- 写法：前景环形物占画面约 1/3、失焦带柔光；环内下方世界清晰而渺小。

### 4. 宏观特写的人物分化（特写美学三分法）

同是大特写，三种人三种拍法——特写美学=人物状态的镜像：

| 人物状态 | 特写处理 |
|---|---|
| 破碎者（愤怒/受苦） | 脏乱血污、不对称构图、分割光半明半暗、生理细节（滴血/咬肌/充血/颤抖） |
| 掌权者（傲慢/伪善） | 正面居中对称、金光洁净、无表情或微表情、稳如神像 |
| 超然者（救场/破局） | 半侧脸、余烬/漂浮物环绕、眼神松弛、几乎不动的微表情 |

- 掌权者走 A 类构图「正面居中/死压中线」的仪式感白名单（第十三节）；破碎者反而避开对称。

### 5. 发光权转移（谁发光，谁掌权）

全片追踪"光源归属"：开局光只属于权力（圣白光晕、逆光金边），凡人只被照亮甚至只是剪影；转折处凡人自身成为光源（发光瞳孔、燃烧符文、体内迸火）；结尾破局者的光色吞噬全场。
- 给"换色必须有光的理由"升一级：**光的归属变化=权力转移的视觉等价物**。设计色彩系统时先定"每阶段谁发光"。
- 瞳孔发光配身体静止——身体越静，光越喧宾夺主。
- **与 stage3 防坑清单第 1 条（眼睛禁忌）的关系**：该条防的是写实题材里 AI 误生成的发光眼；神魔/觉醒题材的发光瞳是刻意设计——prompt 中显式声明「双目泛起金色光芒（刻意的神性/觉醒效果）」，且该镜否定控制中**移除**「不发光」一项。

### 6. 色彩占领（同构图换色=江山易主）

结尾用与中段完全相同的全景构图，只整体替换色卡（如白金天庭→血红天庭），一帧说尽权力易主。
- 母题变奏的色彩版：构图不变=世界还是那个世界；颜色变了=主人换了。
- 执行：同一资产、同一机位做图生图换色（与 stage3「同场景变体锁机位」纪律一致），禁止重新构图。

### 7. 揭示式登场四步（强者入画的标准流程）

不给脸，按「能量→局部→眼→全景」爬升：
1. **能量先行**：火柱/光柱/冲击波先砸进画面（人未到，力场先到）；
2. **局部宏观**：战靴踏地、甲片细节，火星/余烬四溅（贴地机位+微距）；
3. **眼部特写**：发光眼+松弛表情（力量认证与性格声明同时完成）；
4. **全景定位**：与对峙双方同框，用比例档宣告量级。

- 即「tilt-up 出场定义镜头」的燃向升级版；可压缩为三步，顺序不可颠倒——先给脸=力量贬值。

### 8. 过渡帧三件套（快切段的标点）

- **黑帧闪断**【转写：「画面骤然全黑一帧」】：记忆/闪回内部的句号，切割时空；
- **白闪过曝**【转写：「画面骤然过曝为全白一帧，边缘带镜头光晕」】：时空切换回当下、神迹/能量爆发的转场；
- **径向模糊冲击帧**【转写：「画面以中心为轴产生剧烈径向放射模糊」】：砸落/冲击波/巨物入画的瞬间。

三者都是 1-3 帧的"非叙事帧"。没有它们，快切是糊的；有了它们，快切是疼的。

### 9. 快切闪回的感官碎片选材法

闪回不复述剧情，只给感官碎片：脚步、草席上的血滴、倒下的身影、砂石的宏观、一只伸出的手。
- 机位纪律：全部贴地/低机位+手持晃动+运动模糊——记忆是碎的、低的、站不稳的；
- 色彩纪律：闪回用与当下对立的色卡（当下冷金 ↔ 闪回暖土），观众 0.5 秒内分辨时空，不需要字幕提示；
- 单镜 0.3-1.3s，黑帧闪断做句号。

### 10. 碰撞三级配方（打击感制度化，实战对照回写 2026-09-11）

打击感不能逐镜即兴描述——在**段头**定义三级碰撞的固定特效配方，每镜只写「【碰撞等级】：X」引用，模型输出才稳定：

| 等级 | 固定配方（数值即打击感的剂量） |
|---|---|
| 轻碰撞（格挡/擦边/拆招） | 冲击帧 + 0.05s 抽帧 + 局部负片 + 镜头轴向微震 + 粒子飞溅 |
| 重碰撞（实命中） | 放射冲击帧 + 0.1s 抽帧 + 中心负片 + 镜头沿受力方向猛沉/横甩回弹 + 三层粒子爆炸 |
| 终结爆发（大招/镇压） | 全屏冲击帧 + 0.15s 定格抽帧 + 全屏负片闪白 + 径向剧烈震动 + 中心鱼眼畸变 + 环形冲击波扩散 |

- **抽帧=打击感的骨骼**（0.05/0.1/0.15s 随等级递增）；负片=冲击的白热化；镜头震动必须沿受力方向（Z 轴沉降/横甩回弹）。
- 换皮：水墨武侠=水墨冲击帧+专属粒子（骨粉/血焰）；写实 CG=火花/碎石粒子。机制不变，皮肤随风格。
- 配套【环境反馈】随等级分级：轻=碎石尘土、重=地面凹陷龟裂/积水震碎成雾、终结=环形气浪+区域塌陷。

### 11. ACT 追尾机位体系（打斗专用，区别于影视旁观机位）

影视固定机位拍打斗=旁观；ACT（动作游戏第三人称）追尾机位=参与。段头统一声明「ACT 第三人称动态追尾机位体系，无匀速影视慢推拉」，按功能选机位：

| 机位 | 功能 |
|---|---|
| 低机位越肩待机位 | 开场蓄势、对峙、断链类起手 |
| 垂直俯冲坠落追尾 | 跟随下坠攻击，相撞瞬间沿 Z 轴沉降骤停 |
| 横向同步高速跟拍 | 残影瞬闪拆招，随换位轨迹极速横摇 |
| 倒置翻转同步跟拍 | 腾空/盘旋动作，镜头随角色同步翻转 |
| 局部微距升格机位 | 命中瞬间硬切受击部位特写 + 0.5s 升格慢动作 |
| 高空俯冲俯拍 | 巨物/法相下压，空间透视拉伸到极限 |
| 贴地后拉被吞没机位 | 大招落地冲击波扑面盖过镜头（收黑） |

- 禁令随体系一起写进段头：零站桩、无长时间蓄力、无隔空对波、重击必击飞、击飞后无停顿瞬间追击。

### 12. 位移量化与换位频率（打斗不"飘"的数值纪律）

高速打斗的位移必须给具体数值，否则模型默认影视慢速漂移、缠斗变太极：
- 写法：「0.1s 内瞬闪横跨 40% 画面逼近」「受力向后 0.3s 内横向滑退 50% 画面距离」——**秒数 + 画面横向占比**；
- 数值=速度体感声明（0.1s 读作"瞬闪"、0.3s 读作"疾退"），模型按强度执行而非秒表；
- 换位频率：近身缠斗段每 0.2-0.3s 完成一次横向换位/闪转，快进快出绝不原地僵持；
- 追击纪律：重击必击飞 + 击飞后无停顿瞬间追击（追击动作自带下一镜的因果链）。

### 13. 色彩追踪与残影（高速动作的可读性系统）

AI 默认动态模糊=糊成一片。可读的高速打斗靠三件：
1. **双色气场**：每个角色绑定一种能量色（青 vs 红 / 金 vs 紫），气场随动作强度动态漾动——观众靠颜色追踪走位，糊也是两种颜色的糊，敌我永远可辨；
2. **残影/速度线**：瞬闪/突进时拉出半透明残影与速度线，把"快"画出来而不是糊出来；
3. **双方正面出镜**：拆招间隙周期给 0.3s 面部可读帧（脸=打斗中的情绪），并在段头声明「双方均可正面出镜」。

**双实体整套锚定（混战防混淆升级，2026-09-16 漫剧导演库吸收）**：双色气场只给颜色还不够——多人/远景对撞时观众要靠**整套锚定**分清谁是谁。每个参战角色 = 粒子色/光效 + 护甲材质 + 招式轨迹形态，三件成体系贯穿全程；双方锚点**互补对冲**（冷色 vs 暖色、光系 vs 暗系），极速混战与远景对撞中视线才清晰。示例：黑发剑客=冷银剑气/水墨黑白/月牙弧光与霜刃拖尾（极速穿透）；白发神将=金红烈火/熔岩重铠/战戟犁地火线（重击霸体）——对冲时金红流火拖尾 vs 银白霜刃拖尾，左右分流。**能量贴附物理载体**：特效必须贴附在刀刃/手臂/服装边缘/运动轨迹/骨甲上，禁无附着物的悬浮光团；频率分层（高频短电弧贴刃缘指尖 + 低频脉冲贯注臂膀躯干）叠加出能量"活性"。法术流整套选型见 `xuanhuan-combat.md` 第二节。

### 14. 打斗定格陷阱（2026-09-11 实测事故回写）

「定格 ≥3s」类指令在打斗段=事故：实测模型生成 3 秒完全冻结画面（画面能量归零），高潮直接泄气。
- 死寂/留白 **≤0.5-1s**，且必须保留次级运动（烟尘滚落/余烬飘落/气场漾动/发丝飘动）；
- 死寂的最佳位置在**最大一击之前**（暴风雨前的屏息），不在打斗结束之后；
- 收尾要"慢下来"而不是"冻住"：升格飘落的碎片+缓推，远比静止帧有力。

### 15. 打击感因果链与镜头主动权（SSS 句哥基底提炼 2026-09-11）

打击感不是特效堆料，是**因果链的可读性**。六条机制（完整模板见 prompt-frameworks.md 框架 B）：
1. **冲击停顿（hit-stop）**：接触瞬间加入极短冲击停顿，随后立即恢复高速运动——打击感第一来源，与本节第 10 条抽帧配方配套使用；
2. **镜头主动权交接**：镜头跟随当前**主动进攻者**，力量转移时**交接给受力者**——镜头语言服从攻防关系，不是随便跟；
3. **切镜物理触发**：切镜时机由物理事件决定——身体遮挡 / 刀刃擦镜 / 爆炸碎片 / 高速交叉换位，不是导演心情；
4. **受力链完整可读**：格挡角度、接触点、受力位移、落脚制动、机械关节反馈——每一环都要"看得见"，缺一环打击感就泄；
5. **特效物理**：特效/流体始终连接各自物理来源，围绕真实接触路径生成，动作结束后快速衰减；
6. **速度峰值形变**：在速度峰值形成画面边缘外弯的冲击压力（FPV 畸变）。

配套段尾话术（可直接复用）：「每次攻击都要形成结果，动作要有起势、爆发、收势，不要连续空挥。镜头必须证明移动路线和打击结果。不要只拍角色美图，不要长时间平视中景，不要用特效遮住接触。不开场对峙。」

### 16. 身体微动力学条款（打斗身体的物理可信度，SSS 2026-09-11）

AI 打斗"假"的根源是身体没有质量。段头声明这套条款，让身体按物理运动：
- **蓄力**：身体蓄力时会震颤压缩肢体；
- **发力**：发力时会后倾反弹；
- **折返**：加速后的折返带有惯性侧倾；
- **受伤**：受伤时会侧翻扭转；
- **进攻变形**：进攻时身形伴有微微拉长的大幅度微距变形（背景处于运动模糊）；
- **动作衔接**：镜头伴随甩镜失焦；
- **情绪外挂**：启动攻击和结束攻击时都带有不同的情绪微表情（蓄力皱眉，发力呵声，受伤疼痛感）；
- **待机纪律**：没有战斗时要伴随身体的小幅度移动和观察敌人的动作（绝不静止）；
- **禁滑行**：角色不要出现滑行位移或溜冰一样的滑行动作——位移必须有脚步驱动。

### 17. 对手可见性与打斗空间纪律（SSS 枪斗术提炼 2026-09-11）

- **对手可见性**：镜头中至少能看到对手的局部，不要完全是只有1个角色的画面——打斗是关系，单人耍帅=广播体操；
- **非正面铁律**：打斗中都不是正面镜头，构图要倾斜，左边近右边远，镜头有纵深感和景深；
- **镜头清单**：近景 / 中景 / 过肩视角 / 贴地仰视角 / 俯视角 / 肢体之间的缝隙视角（遮挡镜头）轮替；
- **空间逻辑**：掩体位置要有距离（不是躲在同一个掩体后面）；跑位写"跑了很长一段距离"；
- **越轴禁随意**：快速剪辑始终维持战场轴线、角色和攻击方向（句哥基底）；
- **镜头下方穿越**：对战时镜头会从角色下方穿过仰视角色之间的接触；对峙时镜头迅速拉升到俯视角后加速向下斜摆到近身、扭转到对手后方。

### 18. 打斗关键词弹药库（SSS 雷哥测试词+全文件高频词，直接取用）

**冲击/突进**：低机位中全景、大幅快速推近并伴随剧烈震动开场、超音速冲刺突进、被气流拉直、合围贴脸、多轴穿梭避障、强烈的后坐力位移。
**招式链**：接连发动横斩、上挑、回身瞬杀三连招（三连招写法=招式1+招式2+终结，一口气）；将周围敌军瞬间清场。
**接触**：特写视角锁定接触点、显微镜级别的特写重点表现1秒（微距受击特写+时长量化）。
**气势曲线**：杀意攀升、在最强临界点戛然而止（高潮不收尾，直接切断=余震）。
**镜头状态**：镜头动态跟随、镜头剧烈震动、甩镜失焦、子弹时间特写0.5秒。
**击杀链**：瞳孔收缩 → 画面变黑白 → 偏头 → 彻底昏厥（终结镜头的视觉链，按序写）。
**收尾**：白屏结束 / 黑屏结束 / 屏幕被蒸汽弥漫白屏结束（高潮帧纯色吞没）。

## 十五、大招与终结技体系（燃向/打斗高潮段专用，2026-09-16 漫剧导演库吸收）

> 视觉巅峰（大招命中瞬间）五要素必须**同一时间窗口齐爆**：大幅动作 + 快节奏 + 全景/中景空间 + 特效生长 + 三段运镜——缺任何一条视觉降级（缺大幅动作=全景空洞；缺快节奏=拖沓；缺全景=张力不可见；缺特效生长=无爆点；缺三段运镜=舞台剧摆拍）。法术流大招另见 `xuanhuan-combat.md`。

### 1. 终结技三幕（破局 → 绽放 → 余震，禁一击直接结束）

- **第一幕·破局（0.5-1.0s）**：打破攻防平衡制造绝对破绽——化劲借力弹开格挡 / 重击砸开防御架 / 贴地扫腿毁支撑 / 入身绕背入死角 / 时空截击（对方起招瞬间以更快速度截断前臂）；
- **第二幕·绽放（1.5-2.5s）**：大招全力输出——凌空下劈/踏空暴扣（重力加持）、贯穿式寸劲直击（劲力聚一点、空气被击穿成音爆气穴）、多段旋风连斩（离心力叠加成风暴）、神兵绝杀（巨型满月剑光波/万剑自虚空下坠/居合一闪撕裂空间）；
- **第三幕·余震（1.0-1.5s）**：命中点地面蛛网状放射性龟裂、碎石滞空；环形冲击波以接触点为圆心扩散掀尘；受击者弓成虾形倒飞嵌入墙体；终帧停在冲击波扩散/嵌墙/刀光定格的**最高潮瞬间，严禁 0.5s 平静收势**（与"气势曲线：在最强临界点戛然而止"同源）。

### 3. 特效生长三段论（时间维度，禁"啪"地满屏）

1. **萌芽期（0.3-0.5s，攻击启动）**：出招点（指尖/拳面/刀格）泛起微弱但清晰的高亮星芒或气旋——预告大招，拉满期待；
2. **生长期（0.5-1.0s，位移推进）**：能量沿攻击轨迹膨胀壮大，密度与亮度梯度倍增，向攻击部位核心收束压缩；
3. **绽放期（0.2-0.5s，命中瞬间）**：接触点彻底引爆——巨型环形冲击波/满月光刃/地裂气浪，释放全部张力；
4. **余韵层（0.3-0.5s，环境留痕）**：地面焦痕冒烟、冰晶碎屑飘散、空气热扭曲久久不散。

### 4. 急停弹射法则（终结技前的呼吸帧）

**前置高速密集对攻（≥1.5s）→ 瞬间极慢/呼吸帧（0.3-0.5s）→ 绝杀爆发**。没有高速铺垫的定格是无聊停顿；高速后突然插入 0.3s 极慢（汗珠滞空/眼神精光一闪/发丝悬停），速度差形成情绪弹簧，把观众心理预期弹射进绝杀。——与第 14 条打斗定格陷阱、stage3「静止蓄力帧」同一家族：**死寂必须短、必须带次级运动、必须在最大一击之前**。

## 十六、第一人称 POV 物理约束（人眼不是相机，2026-10-08 POV 分镜架构师库吸收）

> 适用：第一人称/主观视角镜头（恐怖沉浸、POV 叙事、小说改第一人称项目）。与 seedance-case-templates「POV 一镜到底」分工：那是**挂载相机**的 UGC 真实感（写挂载位置与视场角），本节是**人眼生理 POV**——人眼不是相机，身体不是稳定器。全片主视角为 POV 时整节加载；仅个别 POV 镜时按需取条目。

**1. 相机术语禁令**：POV 段禁用推/拉/摇/移/跟/环绕/变焦/滑轨/稳定器一切相机词——全部转译为人体动作：视线转移（有方向/速度/时长）、眼球转动、头部微转、身体前倾/后退/转身、眼睑闭合、焦点从 A 移到 B。

**2. 人眼生理三件套**（可执行写法）：
- **眨眼频率表**（每 10-12s 镜 1-2 次，高紧张最多 3 次，禁每 1-2s 一眨）：自然 5-8s/次闭合 0.1-0.15s｜轻紧张 4-5s｜高紧张 3-4s｜专注 8-10s｜疲惫 6-8s 闭合 0.2s｜悲伤 5-6s 闭合后黑场 0.2-0.3s｜震惊定住 2-3s 后快眨 1 次。眨眼=画面短暂黑场/眼睑遮挡+轻微闭眼湿润声。
- **呼吸微晃**：写频率与吸/呼时长、胸腔或肩起伏幅度——画面随之轻微起伏，非稳定器锁定。
- **焦点拟真**：视线快速转移带 0.1s 方向性拖影；手入画时焦点从远景延迟约 0.3s 切近（手先模糊后清晰）；视野边缘自然模糊、强光下泪膜光晕。

**3. 主体可见性白名单**：画面中**禁出现主体自己的头/脸/头发/后脑/肩/脖/耳/下巴**，禁越肩与第三人称。允许可见：手/手指/腕/前臂、腿脚鞋（向下看时）、胸口腹部（向下看时）、袖口前襟裤腿鞋面、自己的影子与倒影。**看自己必须经媒介**（镜子/窗玻璃/水面/屏幕），标注媒介类型与位置；倒影与主体动作同步，倒影中同样禁头部矛盾（无头倒影=事故）。

**4. 视线纪律**：视线高度=主体身高（成人眼平约 1.5-1.7m，儿童/坐姿相应降）；视线转动受颈部限制、有方向速度时长，禁天花板瞬跳地板、禁穿墙；高度变化必须有身体动作依据（蹲下/弯腰/抬头）。

**5. 注意过滤机制**（写法纪律）：POV 画面不是全景扫描——当前焦点内细节拉满，余光区域简写（有但不聚焦），大脑过滤区域不写。每镜声明：当前焦点 / 余光区 / 过滤区 / 焦点何时因何以何速度转移。

**6. 负向追加（POV 段段尾并入既有负向控制）**：不要出现主体头部/面部/头发/肩膀/脖子，不要越肩视角/第三人称视角，不要完整躯干/背影/侧面全身，不要视线瞬跳/视线穿墙，不要倒影中出现主体头部或倒影与主体不同步，不要每 1-2 秒频繁眨眼，不要稳定器式完全静止画面。

**7. 心理描写三方式**（POV 项目接 stage2 OS/VO 硬区分的执行层）：A 纯生理外化（呼吸/心跳/吞咽/视线/手，默认首选）｜B 主观旁白（主体声线、低音量、贴耳混响、无字幕=OS 性质）｜C 画面文字（手写感、下三分之一、随呼吸微浮——慎用）。每镜标注用哪种。

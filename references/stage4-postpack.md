# Stage 4 后期制作包（Post-Pack · 触发式交付 · 两阶段）

> ⚠️ **本阶段不默认执行**。分镜提示词通常要改很多轮，若每轮都产出后期物料极费 Token——**只有用户明确触发时才进入本阶段**。
> **触发词（任一即可）**：「我需要后期制作了」「后期制作」「出后期」「后期制作包」「Post-Pack」，或其他明确表达"进入后期剪辑"的说法。

## 两阶段定位（2026-09-29 定，消除"分镜锁定即出 vs 粗剪锁定后才做"的口径矛盾）

| 子阶段 | 进入时机 | 干什么 | 时间码基准 |
|---|---|---|---|
| **Stage 4a 制作期包** | 分镜锁定 + 用户触发（生成前/生成中均可） | 交付四件套（§1）：画面文字清单 + 字体/音乐参考 + 字幕 SRT + 发布物料——指导生成端制作与后期备料 | 分镜设计值 |
| **Stage 4b 成片期落地** | 粗剪锁定后（生成执行环产出：锁定镜头清单 + 锁定粗剪） | 按实际素材切点微调 SRT/字卡时间码、贴字、混音、调色统一、主版 QC（§1.5）与学习环 | 实际素材切点 |

分镜提示词 → 直接跳到 4b 成片落地是被禁止的：分镜只是设计意图，只有通过 QC 的生成素材才能进剪辑。4a 先行不违反此纪律——4a 的时间码本就是设计值，用途是指导生成与备料。

## 0. 门禁（缺哪项先要哪项）

**4a 制作期包**：

1. **锁定版分镜脚本**（Stage 3 产出；还在改动中的分镜不做后期包，先锁定——否则时间码与台词全白做）。
2. **剧本**（Stage 2 产出；OP/ED 设计与台词原文以它为准）。
3. **投放平台与画幅**（决定字幕排布：抖音竖屏大字双行 vs 横屏常规位）。

**4b 成片期落地**（在 4a 基础上追加）：

4. **锁定粗剪**（生成执行环产出：镜头已逐条锁定、粗剪六扫描已过，见 generation-qc.md「Shot lock」）。

## 1. 交付物（4a 固定四件套：一个 .md 包 + 一个 .srt 文件）

文件命名：`{项目名}_EP{n}后期制作包_v{m}.md` + `{项目名}_EP{n}字幕_中英双语.srt`。
分镜每次大改后**只重跑本包**、版本号 +1，不动剧本与分镜。

### ① 画面文字信息清单（按时间顺序列表）

穷尽全片**所有需要后期添加的文字**，每项给出：时间点 / 内容（中英）/ 形态 / 备注。必查四类：

- **OP 剧名卡**（含投放版可选的 0.5s 钩子闪帧，注明"仅投放版用"）；
- **画面内嵌可读文字**（路牌/招牌/档案/信件/手机屏幕）——**AI 生成画面里的文字必崩，凡需要可读的一律后期贴字**，清单注明贴字质感、位置与是否随镜头透视；
- **剧情字卡**（时间跳跃卡/档案卡等黑底白字卡，含音效提示）；
- **ED 卡组**（系列法则卡 / 金句小字卡 / NEXT EPISODE 预告卡——预告卡必须标 "NEXT EPISODE" 字样，防切片传播被当正片穿帮；**末尾加作者卡**：黑底署名"XX 作品"——个人 IP 品牌建设，爆款对标验证，系列剧每集必带）。

### ② 字体推荐 + 音乐参考

- **字体**：先一句话定整体调性（年代/地域/气质），再按用途分行——剧名 OP / 档案字卡 / ED 卡 / 对白字幕，每途给英文+中文各一（含备选）。字幕规范随字体给出（如：英文在上小一号、中文在下大一号——抖音阅读习惯；白字 + 2px 黑描边）。
- **音乐**：按 cue 点列（OP / 每场一 cue / ED），每 cue 给设计描述 + 参考曲目（可锚定年代的热单或原声）。写清类型适配原则（例：恐怖片——音乐只在"日常"与"异常"间切换状态，恐怖段落的配乐是**被掐掉**而不是加进去）。
- **静音重锤**（爆款验证）：不只恐怖点，**关键台词重锤同样掐音乐**——台词前 0.5s 全静音，让台词落在无声里，说完再进音乐（对标案例：RMS=0.00 全静音 1.5s 压在"我的妻子不能是一个花瓶"上）。
- **声音三层电平（2026-09-16 漫剧导演库吸收，混音交付必附）**：对白（0dB 相对优先）＞ 动作物理音效 SFX（约 -6dB）＞ 环境声与 BGM（约 -14 ~ -18dB）。对白永远最高清晰度优先，骨裂/破风/撞击类 SFX 不得遮人声；对白爆发与激烈打斗段 BGM 自动避让（Ducking）。电平表随音乐 cue 表一并列出，供剪辑/混音直接对照。
- **音乐版权红线**：参考曲目只作方向锚定——年代热单直接入片商用投放有版权风险，正片须走平台正版曲库或原创；剧中哼唱/leitmotif 一律原创（可全季复用，且常是角色/怪物的声音资产），可先合成出原型，再决定是否真人重录。

**音乐 spotting 工作法（2026-10-03 配乐混音库吸收，②音乐参考的底层方法）**：
- **音乐是叙事结构不是墙纸**：每条 cue 必须承担叙事职能——"拿掉这条 cue 如果什么都没变，重新设计或删掉"。
- **Spotting 表按音乐相位而非镜头分行**：`时间 | 画面/声音证据 | 戏剧功能 | 音乐动作 | 同步/过渡方式 | 对白优先级`，必含 cue-in/out、no-music zones（明确哪些段落**不要**音乐）、选择性 hit points、结尾类型（hard button / 衰减 / 悬空延音 / ring-out / 静默）。
- **Cue 边界纪律**：cue 只在戏剧命题、视角、地点、时间或主动权变化处进出——"一个剪辑点本身不是进音乐的理由"；每条 cue 走 进入理由→发展→结构转折→后果→退出理由。
- **情绪→多参数转译**：禁写"悲伤的钢琴"——转成 脉冲/和声节奏/音区/织体密度/混响距离 的组合（例：潜行恐惧=稀疏不稳脉冲+半音摩擦+低中频 drone+隐瞒终止式）；一次只变 1-2 个参数，保留一个身份参数不动。
- **对白下编曲**：先削 1-4kHz 中频、旋律避开语音音区、减打击密度与长混响尾；**编曲避让优先，音量侧链避让其次**。
- **表演戏反直觉规则**：第一滴泪/第一次发怒默认不配乐——在"忍住""认出""事后"处进音乐；动作戏决定性接触瞬间把音乐抽薄，让物理音效证明重量（音乐管预期，音效管接触）。
- **AI 音乐验收顺序**（生成 BGM 回来时按此序检查）：戏剧理解 → 曲式/ timing → 动机 → 对白安全编曲 → 结尾 → 伪影 → 可剪辑性；理解/曲式/结尾错=重新生成，仅局部 timing 错=剪辑修。
- **Suno AI 作曲投喂规范（2026-09-12 Suno 提示词库回写——用户要 AI 生成 BGM/歌曲时按此出提示词）**：按 Suno 界面三框分别输出，各用独立代码块——
  1. **Lyrics 框**：纯音乐（Instrumental 开启）时**必须完全留空**，输出空白代码块（填入任何文字都会导致乱生成歌词）；带歌词模式输出歌词正文（主歌/副歌/桥段分段），并在代码块外标注「需关闭 Instrumental」。
  2. **Styles 框**：长串风格标签逗号分隔——流派 + 乐器 + BPM + 情绪 + 速度（如 `Cinematic, Piano, Rain Sounds, Melancholy, 60 BPM, Slow, Emotional, No Vocals`）；带歌词模式必须注入人声类型（Female vocal / Male vocal / Duet / Choir）。
  3. **Song Title 框**：必出，默认中英双语（如 雨夜 / Rainy Night）。
  禁忌：伤感主题禁止出现 Pop Punk、欢快类违和标签；乐器与节奏不做突兀断层。 cue 点设计仍按本节上文——Suno 提示词只是把每个 cue 落到可执行。

### ③ 字幕文件（SRT，可直接导入剪映）

- **只收对白**。字卡与画面贴字是内嵌设计字，不进 SRT（已在第①节单独交付）。
- **中英双行：观众阅读的语言在上、且字号大**——海外剧英文原声时**中文在上（大）、英文在下（小）**（2026-09-14 两条抖音爆款对标验证均为"主信息行在上且大"；早期"英上中下"方案作废）。白字 + 2px 黑描边。
- 时间码取分镜脚本设计值，包内注明"剪辑时以实际素材切点微调"。**SRT 时间轴总长以时长门禁锁定值为界**（见 stage3-storyboard.md「时长门禁」节——锁定值是全片总预算，4a 全物料同基准）。
- 长台词断行以演员一口气为限。

### ④ 发布物料（封面提示词 + 发布文案 + Tag）

- **封面提示词**：按用户给的平台画幅出（如红果/抖音 3:4 竖版），给 2-3 个差异化构图方向（人物向优先——短剧封面人脸点击率最高；氛围向/概念向备选）。构图必须**预留剧名位置**（上/下三分之一）；**剧名默认直接写进提示词由 AI 生成**——文字内容、位置、字体风格、颜色、中英排版全部在提示词里锁死（三汉字+一单词类短词组成功率高；若模型仍写崩则多抽或后期贴字兜底，以用户选择为准）；恐怖题材用"负空间藏怪"（剪影不超过画面一成、不露五官）。可绑人物定妆图参考。**封面提示词的具体写法 SSOT 在 `poster-cover-prompts` skill**（六段公式/色值硬编码/参考图编号引用/电影海报级排版）——本节管发布物料的交付项与时机，封面提示词的生成规范走那边。
- **发布文案**：给 3 条候选（推荐 1 条），每条标注字数与钩子方向；默认 ≤25 字（用户另有要求从其要求）；优先与 ED 法则卡同句式，全季可复用。
- **Tag 分组**：流量池 / 题材精准 / 制作属性 / 自有 IP（剧名 tag 每集必带），注明投放时挑 5-8 个。

## 1.5 Stage 4b：主版 QC 与学习环（粗剪锁定、成片导出后执行，2026-09-17 骨架移植；2026-09-29 归入 4b）

**主版 QC（Master Lock）**——对实际导出文件从头到尾过一遍，不是对时间线抽查：

- 时长、分辨率、画幅、帧率、编码正确；**成片总时长按用户指定值及其明确允许的误差验收；超出时先在原约束内调整剪辑或重排，仍不能满足则报告实测差异，禁止静默交付或自行按通用百分比放宽（见 stage3「台词时长校验」）**；
- 无缺帧/重复帧/冻帧（除非有意为之）；
- 对白同步、响度、削波、静音与声道布局；
- 字幕时间、错别字、安全区与语序（对照第③节规范）；
- 可读图形、法律文案与署名；
- 剪辑未引入新的连续性缺陷；
- 封面、文件名、集数/版本与平台变体正确。

**学习环**——发布后把观察到的留存掉点、复看峰值、评论反馈与制作缺陷**分开记录**（事实与创作观点不混）。一条经验要成为可复用规则，须有多项目或对照比较的证据支撑因果机制；否则按假设记入对话，不回写规则。

## 1.6 调色与画质统一（4b 专属工序，2026-09-29 补）

多段独立生成 = 色调/对比/颗粒/锐度逐段漂移是结构性的，4b 先统一再贴字混音：

1. **锚定基准段**：选全片曝光最正、最重要的一段为基准；
2. **逐段匹配**：色温/对比/黑位/饱和度四项对照基准段调，不靠肉眼记忆；
3. **轻 LUT 收口**：全片一道强度 ≤50% 的 LUT 只做粘合，不做风格重造——风格已在生成端色卡 60/30/10 里，后期重造=两头打架；
4. **画质规格对齐**：颗粒/锐度/动态范围向中间档收；帧率/分辨率不一致的段先转规格再剪；
5. **修屏检查**：逐段过 AI 残留（边缘闪烁/纹理爬行/文字乱码残留）——能修的局部修，修不了的按 generation-qc 返修成本阶梯处置（剪辑规避/重生成）。

## 2. 纪律

- **不触发不产出**：分镜多轮修改期间，绝不主动生成或更新后期包。
- **4b 不自动跟随 4a**：粗剪锁定前只交付 4a；用户拿 4a 去生成与剪辑，粗剪锁定后用户说"出成片/导出前检查/主版 QC"才进 4b。
- **OP/ED 只做归拢不新创画面**：OP/ED 的钩子画面段已在 Stage 3 作为正式生成段产出（S0/末段，见 stage2-script.md 第 2 节 2026-09-15 新规）；后期包首次把它们集中归拢为字卡贴片清单（压在生成画面切黑后，每卡 0.5-1s）与音乐 cue 表——后期只做贴字与混音，不再承担画面。
- **时间码两套基准**：4a 一律用分镜设计值；4b 以实际素材切点微调并回写 SRT 与字卡清单（版本号 +1）。
- 每集一包，随触发词逐集交付。

# 资产图提示词平台适配器

本文件只负责把 Stage 3 已确定的角色、场景、道具设计编译成目标图像平台可直接投喂的提示词。角色设计内容仍以 `character-sheet-prompts` 为准；本适配器只改变表述结构、参数语法和长度预算，不得删掉锁定的身份、外观、构图、材质、光线、空间或 PRESERVE 约束。

## 共同规则

- 读取制作门禁字段「资产图提示词平台」，只允许 `ChatGPT` 或 `Midjourney`。该字段是无文字资产的主平台；未选择不得生成资产提示词。需要准确可读文字的资产按下文「文字资产自动路由」覆盖主平台。
- 每个资产仍是一条独立代码块，块外小标题、资产名、变体引用关系及三步法保持 Stage 3 原规则。
- 下列字符数是 **cine-pipeline 的交付预算**，用于控制可用性，不冒充平台永久硬上限；按 Unicode 字符计，含空格与参数。平台规则变化时优先遵循当前平台实际校验。
- 先完整写出语义清单，再编译到目标平台；压缩只能删重复修辞，不能删锁定信息。超预算时先合并同义词和重复风格词，再缩短低优先级氛围形容词；仍超预算则在块外标注，不得静默截断。

## 文字资产自动路由（硬规则）

Midjourney 对准确可读文字，尤其中文品牌名、产品名、包装标签、招牌、证书、信件、屏幕 UI 与片名，容易生成错字、伪字或乱码。制作门禁即使选择 `Midjourney`，凡资产图要求画面内出现**必须准确可读的文字**，该资产的整条提示词必须自动改用 `ChatGPT` 格式；人物、无字场景和无字道具继续使用 Midjourney。允许按资产混合平台，但同一条资产提示词不得混用两套语法。

文字资产的 ChatGPT 提示词必须：

1. 把允许出现的准确文字逐项放进引号，声明不得增字、减字、改字、拆字或生成其他可读文字。
2. 明确“若无法准确生成，宁可将对应区域保持纯净留白，也不要生成乱码或伪文字”。
3. 包装或道具存在状态变体时，先生成一张文字准确的 ChatGPT 母版；后续状态图上传该母版，以 CHANGE/PRESERVE 方式续做并锁定文字、版式、颜色与品牌图形。
4. 在资产小标题旁标注 `平台：ChatGPT（文字资产自动切换）`，让用户知道该资产与门禁主平台不同。

**失效边界**：若文字明确计划后期贴入、当前资产只需预留无字净区，则它不属于“必须准确可读文字”的资产，可继续使用门禁主平台；若 ChatGPT 仍写错，改为无字净底后期贴字，不得回退到 Midjourney 继续赌文字准确率。该规则只约束资产图提示词，不保证视频模型在动态画面中原样保留文字，成片仍按 Stage 4 检查与贴字。

## ChatGPT 提示词

**交付预算：每个资产 ≤4000 字符。**

写成自然语言指令，可用短段落和清晰标签表达主体、构图、布局、材质、光线、文字、参考图变更与保留项。明确空间关系与数量；需要图片内文字时把准确文字放进引号。不要使用 Midjourney 的 `--ar`、`--no`、`::`、图片 URL 前缀或参数串；比例用自然语言写进构图要求。语言默认跟随用户，专业材质、镜头与服装词可保留必要英文，避免为全英文而牺牲准确性。

模板：

```text
请生成一张【比例】的【资产类型】图片。
主体与身份：【唯一主体、年龄/性别/身份、锁定外观或物件结构】。
构图与布局：【画面分区、视角、主体位置、数量、空间关系】。
材质与细节：【材质、表面、服装、状态、可读文字】。
光线与色彩：【物理光源、色温、主辅色、背景】。
风格：【本片风格基座】。
必须保持：【参考图 PRESERVE 项；首版文生图则省略】。
不要出现：【只列当前资产直接相关的排除项】。
```

含准确文字的资产在“材质与细节”后追加：

```text
准确文字白名单：只允许出现“【文字1】”“【文字2】”。必须逐字清晰、完整、笔画正确，不得增字、减字、改字、拆字或生成任何其他可读文字。若无法准确生成，宁可将相应区域保持纯净留白，也不要生成乱码或伪文字。
```

## Midjourney 提示词

**交付预算：每个资产 ≤1200 字符。**

使用简洁英文名词短语，不写聊天式请求、解释段落、Markdown 标签或长句指令。顺序固定为：主体与身份 → 关键外观/材质 → 构图与布局 → 光线色彩 → 风格 → 参数。重要概念前置；具体数量直接写数字。排除项只用末尾 `--no`，画幅只用末尾 `--ar`；所有 `--` 参数集中在最后，参数后不再追加正文。仅在确有权重需求时用 `::`，不要把整条提示词切成大量权重碎片。参考图 URL 或平台引用若由用户提供，置于最前；未提供时不得虚构。

模板：

```text
[subject and identity], [locked appearance/material], [composition and panel layout], [lighting and color], [style base] --no [current-asset exclusions] --ar [ratio]
```

图生图变体保留 Stage 3 的 CHANGE/PRESERVE 语义，但压成英文短语：

```text
[reference image], CHANGE: [one change], PRESERVE: [identity, geometry, camera, layout, materials, lighting that must stay fixed] --no [exclusions] --ar [ratio]
```

## 最小行为案例

案例 A 输入：同一角色资产需要「左侧胸像特写，右侧正/侧/背全身三视图，纯灰背景，16:9」，制作门禁分别选择两种平台。

- ChatGPT：输出可分段的自然语言指令，明确左右区域与各自占比，用“16:9 横版”写进正文，不出现 `--ar`、`--no` 或 `::`，总长不超过 4000 字符。
- Midjourney：输出一行英文短语，主体与身份前置，布局压成 `character sheet, left 40% headshot, right 60% front side back full-body views`，结尾统一放 `--no ... --ar 16:9`，总长不超过 1200 字符。

案例 B 输入：制作门禁选择 Midjourney；资产表含人物、山谷场景，以及包装正面必须准确显示“馒头牌”“自热火锅”的产品。

- 预期路由：人物和山谷仍输出 Midjourney 英文短语；产品资产标注 `平台：ChatGPT（文字资产自动切换）`，输出 ChatGPT 自然语言指令，逐项锁定“馒头牌”“自热火锅”，禁止额外文字，并加入“写不准则留白、不得乱码”的降级条件。产品状态变体以上一张文字准确的入选图为母版续做。

## 自检

- [ ] 无文字资产的平台与制作门禁主平台一致；需要准确可读文字的资产已自动切换并标注为 ChatGPT；同一条提示词没有混用两套语法。
- [ ] 字符数在对应交付预算内；若确实超预算，已块外说明且未截断锁定信息。
- [ ] ChatGPT 版无 Midjourney 参数；Midjourney 版为英文短语且所有参数置尾。
- [ ] 文字资产已列准确文字白名单、禁止额外文字，并包含“写不准则留白、不得乱码”的降级条件；状态变体已从文字准确母版续做。
- [ ] 角色设计、场景空间、道具三视图、变体 CHANGE/PRESERVE 等 Stage 3 必需语义均保留。
- [ ] 同一资产只有一条可复制代码块，块内没有流程解释或 QA 备注。

## 时长门禁（Duration Gate，2026-09-29 新增）

> 治"时长默认、缺少用户确认"的旧病：此前全片总时长是分镜排完才浮出来的计算结果，用户到后期才发现平台装不下或节奏不对。本门禁把时长从"结果"提前为"用户锁定的输入参数"——**先定总预算，再排分镜**。

**触发时机**：分镜排期前确认总时长。用户已在聊天、面板或项目档案明确给出目标时长，即视为选定自定义方案，直接继承；同时记录其明确允许的误差，不重复要求三选一。仅缺少时长选择时展示下列选项。台词与时长的完整规则以本文件「台词时长校验」为单一事实来源。

### 三选项定义

| 选项 | 口径 | 预估方法 | 适用 |
|---|---|---|---|
| **① 正常语速版** | 角色自然表达，保留必要反应与留白 | 优先参考片、桌读或实际音轨；缺少音频时给带假设的估算区间，动作与对白可并行，不机械逐项相加 | 时长未定的叙事片 |
| **② 快节奏版** | 依角色声口与参考片组织紧凑对白、声画并行与切点 | 重新编排时间轴并试读；不以固定字速封顶，不把正常版机械乘压缩系数，不删原台词 | 节奏紧凑的内容 |
| **③ 自定义时长** | 用户指定目标及允许误差是排期约束 | 在该预算内安排完整原台词、动作、片头片尾；先设计和校准，不能凭字数公式判定装不下 | 已选片长、参考片复现或平台时长要求 |

### 锁定结果的传递（贯穿后续全流程）

- **Stage 3 分镜**：记录目标、允许范围、参考依据与本版设计总长；优先靠近目标，若使用允许误差须说明本版值，不能把上限自动当新目标。未授权误差时按指定值排期。各段连续覆盖全片，片头、片尾、字幕停留均计入预算。
- **试产/批量生成**：分镜设计时间与素材实测时间分别记录；逐段校准，在用户预算内重分配镜长、切点与声画关系，不静默改全片目标。
- **Stage 4a 制作期包**：字幕设计值、音乐与画面文字使用同一时间轴。
- **Stage 4b 成片期落地**：实测总长按用户指定值及允许误差验收，不能自行以 ±10% 等通用阈值放宽用户约束。

### 红线

见「台词时长校验」：原台词逐字保留，用户时长优先于经验估算；指定时长不等于授权删词，估算字速不等于模型限制。用户后续明确改时长时直接更新并联动复验，无须重复确认已明确的选择。

### 时间标注置信度门

区分**设计预算**与**实测时间**。即使尚无音轨，也应按用户指定总时长给出完整分镜设计排期，并注明待音轨校准；不得把设计值说成实测结果，也不得因缺音轨拒绝排镜。具体动作发生点的精度随证据决定：有参考音轨或音乐锚点可标实测时间；缺少依据时写近似位置或先后关系，不编造亚秒级实测精度。

## Workflow

1. **定片型 + 定模型**：片型（短剧 / 短片 / 电影级 / MV / 预告片 / 广告）→ 加载 `genre-modules.md` 对应模块；目标模型（SD2.5 / MiniMax H3 / 其他）→ 决定段长上限（SD2.5 ≤12s / H3 ≤15s）、提示词格式（默认中文竖排模板 / 框架 C YAML 六段式 / 框架 H 长文直出）与适配器（`model-adapters/` 对应文件，未核验模型走 generic）。用户未说明模型时按 SD2.5 默认推进并在生成建议中注明；H3 项目必须显式确认（硬约束见题材框架合并节）。
2. **定声音策略**（2026-09-29 补，排期前必做）：按 `dialogue-and-sound.md` 四选一——模型原生对白 / 后期配音 / 混合 / 静默。它决定台词字段写法、语速校验口径、音效字段密度与口型要求，不定不排期。用户无偏好时按片型给默认建议：短剧/对白驱动→后期配音或混合；动态漫→后期配音；MV→静默+歌词；氛围短片→可静默。
3. **写故事内容**（交付物第一部分）：忠实梗概剧本（按时间顺序：场景、事件、人物动作、台词要点、情绪线、结尾钩子），**不改写不增删剧情**；剧本→压缩为结构化梗概，一句话梗概→扩写后先回用户确认。
4. **建资产表**（交付物第二部分）：从剧本穷举全部场景/角色/道具 → @实体清单（宁多勿漏），按下文模板产出总览表 + 每资产的生成提示词。先读取制作门禁「资产图提示词主平台」并加载 `image-prompt-adapters.md`；先扫描每项资产是否要求准确可读文字，再按适配器决定沿用主平台或自动切换 ChatGPT。资产表含任何角色时，再完整加载 `character-sheet-prompts/SKILL.md`。角色的审美设计与三步法以该 Skill 为准，最终可复制提示词的语言、结构、参数和字符预算以平台适配器为准；不得用本文件的通用三视图字段替代人物审美设计，也不得在同一条提示词中混用 ChatGPT/Midjourney 语法。
5. **建全片设定层**：视觉母题 / 色彩影调系统 / 视点策略 / 节奏曲线 + 人物锚点（优先继承项目档案「外形」字段）。
   - 按下节「视听技法库调用」读取 `av-techniques` 入口，按本片叙事意图选取相关方法，落实到全片策略和后续镜头设计。
   - 一个叙事任务需要多镜共同完成时，先按 `shot-groups.md` 在内部组织观众发现的顺序、动作与反应，再拆单镜；简单单镜跳过。镜头组与模型生成段分开规划，不增加确认步骤或改换交付格式。
6. **逐镜头过「一镜四问」**，用答案查 `camera-lexicon.md` 选参数（词典词条带心理动机，禁止盲选）。
7. **组装交付物**并过自检清单。

## 视听技法库调用（Stage 3 正式接入）

**调用时机**：输入门禁确认后，在 Workflow 第 5 步建立全片设定层时，先读取 [av-techniques 主入口](../../av-techniques/SKILL.md) 的意图路由，再按需读取关联参考文件；继续执行本阶段「一镜四问」与参数选择。直接修改已有分镜时，在用户指定范围内调用，不重启已确认门禁或重做全片。

- **先选目的，再选方法**：从已定剧本找本段需要的呼应、悬念、信息揭示、反应、时间压缩或情绪停留，依据技法库的适用条件选择；不全量加载 66 条，不规定每镜必须用招式，普通硬切或连续表演同样可以成立。技法不能擅改锁定剧情、原台词、用户时长及禁止元素。
- **分工明确**：技法库回答“为何这样组织声画”；`shot-groups.md` 组织多镜的信息与行动；`camera-lexicon.md` 将意图落为构图、焦点、运镜等参数；`continuity-and-editing.md` 检查动作、空间和切接。具体技法只维护在共享库，不复制条目到本文件。
- **必须转成可执行描述**：所选方法落实到既有字段中的可见动作、构图关系、声音安排和相邻镜头接续。涉及接合时明确 A 结束状态、B 开始状态及画面/声音怎样连接；不只写“用 T62”“高级蒙太奇”“库里肖夫效应”。T 编号和选择理由可留在块外推演，不能替代可复制提示词中的实际描述。
- **生成与剪辑分开交代**：生成提示词负责各段应出现的声画；后期切点、J/L-cut、声音匹配和混音等操作写入现有「生成建议」的声音执行标注/特殊生成方式声明，必要时在全片设定层说明。遵守既有段内连续性和模型路由，不为转场把不同场景强塞进一个生成单元；不另加交付字段、确认步骤或自动启动 Stage 4。没有音频/成片时是设计方案，不能声称已验证无缝。

**最小行为案例（原创设计，仅验证路由与交付意图）**：输入“门禁已确认；只设计母亲缝纫→女儿打字的两个段落，原台词不动，希望劳动形成呼应”→ 读取技法库入口，按需读 `editing-foundations.md` T63；在两段现有声音字段分别写缝纫机节律与键盘敲击，在生成建议写试听后选择声音交接点，无法匹配时可用声音桥；保留原台词与段落模板，不声称听过素材。输入“同样门禁已确认；只要人物读完信后的一个固定长镜，不加音乐转场”→ 查入口后可直接选择连续表演，不为调用技法库强行加切镜或声效。

## 一镜四问（每个镜头先回答，任何参数写不出动机就删掉或换掉）

| 问 | 回答什么 | 决定哪些参数 |
|---|---|---|
| ① 叙事功能 | 这个镜头为什么存在？（推进/传递信息/铺垫/揭示/纯氛围） | 景别、构图、插镜内容 |
| ② 情绪目标 | 观众此刻该感受什么？ | 运镜速度方向、焦段、光圈、光影 |
| ③ 视点归属 | 谁在看？（客观全知 / 角色主观 / 过肩半主观） | 机位角度、焦段、景深、遮挡前景 |
| ④ 节奏位置 | 处于节奏曲线哪段？（铺垫/蓄力/爆发/余韵） | 镜时长、剪辑密度、是否慢动作 |

## 视听转译（剧本进分镜的硬门槛）

**"这句话摄影机拍得到吗？麦克风录得到吗？拍不到的必须转译。"** 抽象/心理/文学描述不允许直接进入分镜——转译四步：
① 识别抽象描述 → ② 演员会用身体哪部分演（眼/手指/肩/呼吸）→ ③ 摄影机用什么景别焦段拍到 → ④ 要不要声音/光线/物件辅助。
完整转译表（心理类/关系类/戏剧动作类）见 `camera-lexicon.md` 第十节。
剧本出现无法转译的抽象（如"他感受到宇宙的孤独"）→ 停下问用户要身体表演或具象画面，不硬拍。

**情绪断点处理**：分镜过程中发现剧本情绪逻辑断点（角色从 A 情绪跳到 B 无铺垫）→ 停下给用户两个选项：硬拍（加过渡镜头如低头深呼吸特写，标注为分镜补写）/ 回 Stage 2 修剧本再来。

## 空间与连续性纪律（2026-10-03 director-skills 库吸收——把资产可得性变成分镜硬约束）

1. **首帧空间审计**（有首帧/场景参考图的镜头必过，六层）：空间层次（前中后景与遮挡）→ 主体位置与进入路径 → 摄影机状态（机位高度/俯仰/焦段）→ 光源与天气依据 → **内容许可三栏** → 时间预算（动作+运镜在镜长内物理可完成）。
2. **内容许可三栏**：`已存在`（可直接运动）/ `可进入`（有可见物理路径）/ `禁止新增`（不存在且无路径——不许让模型凭空生成）。主体不在首帧时，只有画面里存在可见入口才允许其入场。
3. **缺首帧处置**：没有场景参考图时输出「待补场景图清单」请用户补图或先生成场景资产——**禁止用大段文字强迫模型虚构未知空间**（文字描述的空间必然与下一镜打架）。
4. **分时段写法**：镜头的分时段描述（0-3s/3-6s…）必须写**同一连续空间中的状态变化**，禁用剪辑语言——`切到`/`突然出现`/`独立段落`/`转为另一地点`/`硬切特写`——段内要换空间就拆成两个镜头。
5. **运镜可达性**：运镜按 camera-lexicon「风险分级」选型；B/C 级运镜需首帧审计确认路径可达，每镜只许一个主运镜（衔接动作 ≤1 且方向连续）。
6. **信息密度预算（2026-10-03 h3 库吸收）**：单段（≤15s）装 7-9 个简单信息节点或 7-8 个富节点为上限，10-11 是冲顶不是默认；**数信息状态不只数切点**——精确文字、每句台词、UI 状态变化、材质转化都吃同一份时间预算。超预算先砍节点，不靠加速硬塞。
7. **多段生成的续段纪律（指针，所有片型通用）**：分段生成时续段的"三无"纪律（无会话措辞/无硬匹配尾帧/首帧自包含形态锁）与素材段定位，SSOT 在 `short-drama-engine.md`「连载生成段纪律」——名字带"短剧"但规则对所有多段生成项目（MV/广告/电影级短片分段）通用，多段项目排期时按需加载该节。

## 全片设定层（那根线）

1. **视觉母题（Motif）**：1-2 个贯穿的视觉元素/构图逻辑，最后关头做一次变奏 = 主题落点（例：全片门框困住女主→结尾走出画框）。
2. **色彩影调系统**：每场景一张主色卡 + 情绪映射；同场景色调统一；换色必须给"光的理由"（日落、开灯、雷雨）。
3. **视点策略**：全片以谁的视点为主，观众就代入谁；反派/威胁窥视镜头穿插制造不安。
4. **节奏曲线**：标注铺垫/蓄力/爆发/余韵四段及占比；每镜的"问④"答案来自这条曲线。**四段时长分配以时长门禁锁定的全片总时长为总预算**（输入门禁第 5 项），各段时长合计 = 锁定时长。
   - **心电图型参考曲线**（对抗/觉醒/燃向实测：100s/44 镜样片逐帧测得）：慢板长镜开场（4-7s/镜，能量压低）→ 快切闪回（0.3-1.3s/镜，约 6-8 镜）→ **静止蓄力帧**（2-3s 画面近乎无运动、声音抽空）→ 爆点冲击 → 对白长镜喘息（5-8s/镜）→ 第二次快切（能量高于第一次）→ 8-10s 渐强 → 砸落/爆发 → 快速揭示蒙太奇（峰值）→ 定格对峙（≥3s）→ 尾帧变奏。
   - **静止蓄力帧**：大爆点前必须有 2-3s 近乎静止的画面+抽空的声音（"静默是爆炸的引信"，与 genre-modules 模块 D 温子仁规则 3 同源）。观众心率压到最低，爆点才有落差——实测样片中静止段画面帧间能量接近 0，随后单帧冲击能量跳升 60 倍。
   - **快切双脉冲**：全片快切段出现两次而非一次——第一次讲过去（闪回/委屈），第二次讲现在（觉醒/反击）；第二次能量必须高于第一次，否则情绪塌方。
   - **BGM 反转先行**（写进生成建议的后期提示）：音乐风格反转（如史诗交响→硬核节奏）先于视觉爆点 8-10s 启动，音乐做预告、画面随后追上；快切蒙太奇的切点卡鼓点。
   - **时长配比纪律（2026-09-14 实测事故：12s 打斗段机械套用心电图，对峙 2s+余韵 2s 吃掉 40% 时长，成片交锋稀疏、节奏塌方）**：心电图四段配比是 **≥60s 长片**的工具，短片直接套用=灾难。按时长重新配比——
     | 打斗段时长 | 交锋主体占比 | 开场对峙 | 死寂蓄力 | 余韵 |
     |---|---|---|---|---|
     | ≤15s | ≥70% | ≤1s（或 in medias res 直接开打） | ≤0.5s | ≤1.5s |
     | 15-60s | ≥55% | ≤3s | ≤1.5s | ≤3s |
     | ≥60s | 按心电图曲线 | 按曲线 | 2-3s | 按曲线 |
     **设计打斗段先数交锋次数**：有效交锋（有接触、有结果的攻防回合）每 10s ≥4-5 次，达不到就砍铺垫——交锋密度不达标，其他全对也是慢动作MV。且段尾写了"不开场对峙"就必须从第一帧进入动作状态，禁止自己破自己的规矩。
5. **人物锚点**：每角色一句外观锚点（服装/发型/特征），每段【段头】必带——优先继承项目档案。

|---|---|---|---|

**资产生成提示词规则**（每资产一条，代码块交付，可直接投喂图像模型）：
- **逐条带小标题，禁止匿名堆叠（2026-09-12 试产回写；2026-10-08 角色单块化）**：每条资产生成提示词的代码块**正上方**必须有一行独立小标题，格式为 `类型·@资产全名（必要说明）：`，如 `角色·@林修（三视图定妆）：`、`角色变体·@林修淋湿状态（以@林修定妆图为参考图图生图）：`、`场景·@老宅客厅停电夜：`、`道具·@打火机：`。**角色为一 asset 一条整块提示词**（内含定脸→身材穿搭→多视图排版三段，禁止拆成多条代码块——用户要一整块复制投喂，2026-10-08 二爷确认）。一个代码块只装一条提示词，禁止"场景空镜：""道具特写："这类分组标题下连排多个匿名代码块。小标题中的资产名必须与资产表、段头、镜头层使用的 @全名（含变体后缀）逐字一致。
- **平台编译（SSOT）**：先保留本节模板中的全部语义，再按制作门禁加载 `image-prompt-adapters.md` 编译。平台自动路由、准确文字白名单与失败降级均以该文件为单一事实来源；本文件不复制规则。ChatGPT 版用自然语言指令、比例写进正文、≤4000 字符，禁止 `--ar`/`--no`/`::`；Midjourney 版用简洁英文短语、参数集中置尾、≤1200 字符。字符数是交付预算，不冒充平台硬限制；超预算不得静默截断锁定信息。
- **共同基座**：用户风格描述提示词**原样开头，不改写核心措辞**——资产与分镜共用同一风格基座。
- **角色（强制子 Skill 路由，2026-10-08《好像有哪里不对》资产路人化事故回写；同日单块化）**：角色的审美定向、脸型骨相、五官、发型、头身比、肩颈腰线、服装版型/材质、配饰和多视图排版，以 `character-sheet-prompts/SKILL.md` 为单一事实来源；先写角色在剧情中的吸引力功能与第一眼气质，再写可见设计，禁止只用"年龄＋发型＋衣服名＋普通三视图"交差。**交付形态为单条整块提示词**：第一段定脸信息、第二段身材穿搭、第三段多视图排版与负向控制，三段连成一条，方便整段复制投喂；生成走三步法——①截取第一段抽胸像选脸（可多次），②以入选脸为参考加第二段出全身定妆，③双参考（胸像＋全身）用整条提示词出多视图锁定。**性别锚点**：每段主体描述必须明确 X~Y 岁男性/女性及身份，下游性别指向与资产板一致。**真人人脸参考图红线**：Seedance 系（2.5/2.0）不支持上传含真人人脸的参考图——目标平台不接收写实人脸参考时，把同一审美设计转为半写实 CG/绘画角色资产再绑定，不拿真人照片绕过。**亲缘推导**：亲缘角色以基准角色参考图图生图，共享 40%~60% 骨相与 1-2 项五官关联，同时用发型/年龄纹理/服装拉开。**写实措辞**：需要真人摄影感时用 `film character sheet / studio photographs`，不以 `painterly` 触发插画漂移。

**资产命名规则（2026-09-28 二爷定：画布强制二选一；取代旧「@命名规范」）**：实体全片同名同物，名即 R2V 素材绑定锚点；**变体命名直接紧跟资产名之后，禁止用 '-' 等任何连接符号**（如 @张雁夜、@老宅客厅停电夜、@林修淋湿状态；旧格式 @张雁-夜 / @老宅客厅-停电夜 已废弃）。**分镜段落投喂代码块内的资产引用格式，按用户选定的画布二选一（输入门禁第 5 项，未选定必须先问），整份交付物代码块内全程统一、禁止混用**：

- **方式一（ShuoCanvas 画布）**：`@资产名＋空格`——@ 引用整体后接一个空格再接画面描述（如「人物空间位置：@张雁夜 主观视角在画外，视线沿铁轨向前"走"；画内无她本人」「画面情节：@张远舟梦境 的背影在雾里静止，衣摆下缘的沙粒一粒一粒无声掉落」）；
- **方式二（即梦画布）**：`资产名＋空格`——去 @ 前缀，资产名后接一个空格再接画面描述（如「人物空间位置：张雁夜 主观视角在画外，视线沿铁轨向前"走"；画内无她本人」「画面情节：张远舟梦境 的背影在雾里静止，衣摆下缘的沙粒一粒一粒无声掉落」）。

**作用范围严格限定**：本规则只约束**分镜段落投喂代码块内部**（段落标题行、【段头】、【镜头层】、【段尾负向控制】）。资产表、资产提示词小标题等**代码块外的管理视图不受本规则影响**，统一按「@资产名」书写（@ 作为实体标识便于全文检索与双向核对）；故事内容/全片设定层/生成建议等叙述文字、段落 S# 标题、镜头层「音效」「同期声」「台词」字段、资产生成提示词代码块内部，两种模式下均不带 @（见下方作用域表）。

## Prompt 组装模板

段落标题格式：`S#｜Xs-Ys 场景/事件名（镜 N-M，时长 Zs）`，时长 Zs=Y-X 标在标题末尾（对照生成时长参数；每段 ≤12s）。

**交付格式（作者约束，2026-09-14 修订；2026-09-28 增补目录结构纪律）**：每个分镜段落的可投喂提示词——**段落标题行**+【段头】+【镜头层】+【段尾负向控制】——必须**整体包裹在代码块中交付**；段落标题行（`S#｜Xs-Ys 场景/事件名（镜 N-M，时长 Zs）`）作为代码块内**第一行**，让投喂时模型先拿到本段时间码与镜号范围的上下文；块外同时保留一份同标题与四问推演做阅读导航。保证用户可一键整段复制投喂，不用手动拼凑。

**目录结构纪律（2026-09-28 二爷事故回写——历史项目多次出现编辑器右侧目录里 S 段标题全部缺失，只能看到"四、分镜段落"，下一个标题直接跳到"五、生成建议"）**：分镜交付物（.md）的目录导航依赖块外标题——
1. **块外导航标题必须用规范 markdown 标题语法**：`### S#｜Xs-Ys 场景/事件名（镜 N-M，时长 Zs）`（与「四、分镜段落」的 `##` 构成父子层级），禁止用 `**加粗**` 或纯文本充当分段标题——加粗伪标题不进任何编辑器的目录树；
2. **块外标题与代码块内第一行逐字一致**（同一份 S# 标题，一份给目录、一份给投喂模型）；
3. **层级连续不跳级**：`# 片名` → `## 一至七章` → `### S# 分段 / 资产分组`，禁止 ## 直接跳 #### 或反向嵌套；
4. **标题不被代码块/引用块吞掉**：所有目录依赖标题（章标题、S# 段标题、资产分组标题）必须位于代码块与引用块之外；
5. **交付后自查（强制）**：生成 .md 后跑 `python scripts/check_deliverable_toc.py <交付物.md>` 模拟目录提取，确认 S1~S末段全部在列、层级序列无跳级；缺任何一段即修正后再交付。

**画布规则适配（2026-09-28）**：模板以方式一（ShuoCanvas，`@资产名＋空格`）书写为默认形式；若用户选定方式二（即梦），代码块内所有实体引用的 @ 前缀一律去除（「@沈孤鸿 侧身让过爪锋」→「沈孤鸿 侧身让过爪锋」，段头同理），其余字段结构不变。全片代码块只允许一种形式，禁止混用（作用域与反例见上文「@ 的作用域」）。

**竖排规则（作者约束 2026-09-10）**：镜头层每个字段独占一行（字段名：内容），段落标题与镜头编号行（`镜头 N（Xs-Ys）`）单独成行；字段顺序固定如上，方便逐字段阅读与局部修改。

**机位防模糊模板**（机位字段禁止只写"仰拍近景"类抽象词）：
`机位：摄影机位于 [主体] 的 [正面/背后/左前45°/过肩谁拍谁/主观POV]，高度在 [眼平/胸口/腰部/地面]，以 [平视/仰拍/俯拍] 拍摄 [主体部位/动作]，景别为 [X]。`

**跨段衔接要点**（抵御逐段独立生成的状态漂移）：每段【段头】除常规内容外，延续上一段末镜状态——轴线侧 / 角色服装与姿态 / 关键道具状态（具体值，如"半杯奶茶"）/ 光线与时间感 / 情绪余韵；并声明转场类型（同时刻同场景延续 / 隐含跳秒 / 明确跳时 / 跨场景硬切 / 闪回 / 白闪过渡 / 黑帧闪断——后两者写法见词典第十四节过渡帧三件套；**"什么叙事目的选什么转场"查 camera-lexicon「转场选型决策表」，声音转场 J-cut/L-cut/声音桥在镜头层音效字段标注意图**）。跳时与闪回允许重置部分状态，但必须明示"重置+理由"，不允许自由漂移。文字衔接只是下限手段——同场景连续动作、人物位置延续这类**硬连贯需求，用「帧链延续」：上段生成结果的末帧截图作为下段首镜参考图**（R2V 首帧绑定），见防坑清单第 12 条。

**运镜纪律**：一镜一主运镜（最多叠加一个辅助）；运镜方向有语法（推=进入/聚焦，拉=离开/揭示，升=希望，降=压抑）；相邻镜头运镜衔接落在 5 模式内（同向/反向/静切动/动切静/同质叠加，见词典第十二节）；一段戏内运镜方式过多 = 风格混乱；**文戏运镜带时间曲线写法**（启动时机/到位时机/缓入缓出/运镜占比 ≤70%，见 camera-lexicon 运镜使用纪律第 5 条——"等速运动"是 QC 审美层判"运镜很 AI"的首要病灶，分镜端先开处方）。

**维度组合纪律：单主/多选/成组 + 主辅微 + 镜头级数量预算（2026-10-08 外部《影视AI创作语言库·调用规则》吸收——把"一镜一主运镜"推广到全维度）**：逐镜组装时所有维度按三类对待——

- **单主维度**（同维度"主"只能一个）：运镜（既有纪律）、构图、景别、主光、主色调、主表情、主视点、风格基座。允许加 1-2 个"辅"（辅不抢主），禁止同维度两主——不能既"主运镜=急推"又"主运镜=环绕"，可"主=环绕 + 辅=缓推"。辅/微项并入对应字段同行标注（如「构图：对称构图（辅：三分法留白）」），**不新增模板字段、字段顺序不变**。
- **多选增强层**（可同时多个，但必须分层标记 主/辅/微/环境）：特效、声音、材质、微动作、服装/发型动态、文化符号。不分层的多选 = 堆砌。
- **成组套件**（调用即成套，缺项 = 事故）：角色三件套（面部+发型+服装）、法术流（法宝媒介+属性双色+攻防循环，见 xuanhuan-combat.md）、打戏（强度定档+阶段+武器，见 fight-lexicon.md 第八章）。

**镜头级数量预算**（超预算先砍后写，不靠长提示词硬塞）：

| 维度 | 预算 |
|---|---|
| 运镜 | 主1 + 辅≤1（既有纪律，见上） |
| 构图 | 主1 + 辅≤1 |
| 光线 | 主光1 + 辅光≤2（轮廓光/环境光计入） |
| 色彩 | 主色1 + 辅色1，辅色占比 <30% |
| 特效 | 常规镜 2-4 个且分层（主特效1 + 辅1-2 + 环境粒子≤1）；大招镜 5-6 封顶、必须分层 |
| 声音 | 2-4 层（对白/主音效/环境音/配乐/重音同时存在也按层数计） |
| 表情/微动作 | 主表情1 + 微表情/微动作 ≤3 |

**创作期冲突解决优先级链**：叙事逻辑 ＞ 角色/资产一致性 ＞ 空间连续性 ＞ 情绪目标 ＞ 视觉风格 ＞ 技术炫技——两条规则打架时砍低位保高位（与 generation-qc.md「修复优先级链 identity→action→camera→aesthetic→material→rhythm」分工：那条管已生成素材的返修顺序，本条管分镜写作期的取舍）。**属性/风格对冲需叙事解释**：火与冰同场、佛光与魔气同场、水墨与赛博朋克同片，必须有叙事理由（对立阵营/主题对照），否则只保留一个主属性/主风格（法术流执行细则见 xuanhuan-combat.md 第二节末）。

**最小行为案例**：输入"大招镜：环绕+急推+航拍三运镜、剑气+弹幕+粒子+风暴+光柱五特效、丁达尔+轮廓+冷光+金光四光源"→ 预期输出：运镜砍为 主=航拍环绕 + 辅=缓推；特效分层为 主=剑气弹幕、辅=斩击闪光、环境=风与尘埃（光柱按去水转化表改写或砍）；光线 主=丁达尔、辅=轮廓光（冷光并入色卡、金光砍）——总量落入预算表，辅项在字段内标注"辅"。

**镜头收尾纪律（2026-10-08 POV 分镜架构师库吸收）**：每镜结尾动作必须处于**完成态**——禁手伸到一半、门推到一半、视线移到一半就结束；动作必须跨镜延续时在画面情节末尾显式标注「动作延续：具体状态」（如"手已伸至门把手但尚未转动"），下一镜从该状态起笔。段末镜尾帧必须静止可读（主体/物体/光源/影子可独立描述），既是帧链延续的绑定基准，也是 QC 验收锚点。

**POV 词库加载（2026-10-08 新增）**：含第一人称/主观视角镜头时加载 `camera-lexicon.md` 第十六节（人眼生理 POV：眨眼频率表/呼吸微晃/焦点延迟/主体可见性白名单/注意过滤）——全片主视角 POV 整节加载，个别 POV 镜按需取条目；UGC 挂载相机式 POV 走 seedance-case-templates「真实感三件套」，两套不混用。

**镜长呼吸纪律（2026-09-16 漫剧导演库吸收）**：镜长由剧情倒推，**禁机械等分**——正确顺序 = 剧情 → 情绪节拍 → 时长（台词镜按语速速算+情绪停顿定长，无台词镜按情绪节拍定长）；错误顺序 = 先算「段长÷镜数」再往里填。全篇镜长须**快慢交替呼吸**，覆盖 ≥3 个取值（如 {3,4,5}s）；爆发/爆点镜快切、金句/高潮镜长镜留白（最高张力点给足时间压住）。「全篇镜长雷同、无快慢节奏」本身是结构缺陷信号——平滑来源于情绪，不来源于算术均分。

**题材框架合并（2026-09-11 SSS 框架库回写）**：默认模板是本 pipeline 的交付骨架；遇到对应题材时，把 `references/prompt-frameworks.md` 中该题材框架的字段纪律合并进来——打斗段合并框架 A/B（总要求段补丁 + 句哥打斗要求/负面限制两块段尾）、英文/H3 输出改用框架 C 的 YAML 六段式、真人情绪戏合并框架 D（全局设定+状态锁定）、单镜头情绪弧用框架 E 相位法、MV 用框架 F。防停顿/消歧义/锁目标三条复读咒语在打斗段强制启用。**包装片路由（2026-09-16 AniShort H3 案例库吸收）**：无剧情的商用直出片（广告/MG 动画/文字包装/游戏 UI）改用框架 H 中文商用直出长文式整条写；**独立片头（title sequence）/品牌片尾（brand ending）走 `references/title-design.md` 专项纪律**（片头五层结构/署名卡/字体三级/转场来源化/15s 时间轴模板+专项自检）。**模型时长上限约束**：MiniMax H3 单次生成 ≤15s——H3 项目的段落时长与整条直出时长一律按 ≤15s 规划（默认模板"每段 ≤12s"面向 SD2.5，H3 上限 15s 但建议留 0-1s 安全余量）；文字包装、卡点、质感层需求可从框架 H 抽取字段纪律（文字白名单/百分比字号/律动绑定/材料依附）合并进叙事片分镜段。

**打斗/特效词库加载（2026-09-12 新增；2026-09-16 漫剧导演库扩容；2026-09-16 运动原理接入）**：写武戏/打斗段时加载 `references/fight-lexicon.md`（108 条：流派/武侠动作/战斗原则/武器/打斗阶段/阵型 + **第八章打戏分镜规格：R1/R2/R3 强度定档/完播评分/机枪对招三模式/防守三态与闪避大幅化**）——打斗段节奏骨架用其第五章（对峙→试探→升级→绝招→分胜负→余波），招式内容按其「执行」描述转写；涉及能量/法术/元素/科幻特效场面时加载 `references/vfx-lexicon.md`（118 条），特效描述按词条「执行」栏物理化转写，禁止把「情绪」栏抽象词写进提示词；**法术流战斗（仙侠/玄幻法术对轰、法宝、对军清场）改走 `references/xuanhuan-combat.md`**（法宝媒介/属性双色/术法攻防/能量去水转化/5 段式模板），禁套物理肉搏语法；**动画向项目（2D/3D/CG/动态漫）与一切打斗/动作/追逐段加载 `references/motion-lexicon.md`**（迪士尼 12 法则×牛顿动力学：重量感四原理/打击感七要素装配/12 法则提示词转写/姿态动势三原则/动作→镜头映射）——动作设计的原理层，与 fight-lexicon 执行层叠加使用；**特写/大特写、微表情、口是心非、隐忍克制、情绪转折关键拍**加载 `references/facs-lexicon.md`（FACS 微表情：四区拆解/强度三档/真假笑/情绪配方表）——简单文戏不加载，用正常影视表演语言。纯文戏且无特写时这些词库都不加载。

**构图雷区**：B 类工程性错误（物体穿身/服装突变/比例失调/道具状态突变）永不保留，写入否定控制规避；A 类艺术性构图（正面居中/头顶贴边/死压中线/背景过亮）默认禁用，仅特定情境白名单解锁（详见词典第十三节）。

## 负向槽卫生与可复制块纯净（2026-10-03 防污染库吸收，组装 Prompt 时逐段过）

1. **负向槽不是旧失败的纪念册**：不在负向块里提名旧项目/上一版翻车的具体道具、角色、颜色、场景——**提到即招到**，被否定的名词仍会吸引模型联想。只写与**本镜头当前内容**直接相关的排除项；先问"应该出现什么"，优先写正向期望状态，必须写 `no X` 时保持泛化（no extra fingers），不写项目特定名词。
2. **负向转正向**：能写成正向约束的一律转正（`no blur` → 「主体轮廓锐利，景深层次清晰」）；负向块只保留无法正向表达的硬禁令，独立成块放段尾。
3. **可复制块纯净**：交付给用户的可复制提示词代码块里**只含生成指令**——剔除内部 QA 语言、流程解释、字段名注释（"这是为了防 XX"这类话进不了块内）；块外解释随便写，块内一字不多。

## 反应镜头决策（对话戏必做）

四类位置优先检查反应如何承载信息：爆点台词之后、情绪转折、关键信息揭示、视点切换。先找这一拍的新信息在说者、听者还是双方关系中，再决定拍谁。
反应可以独立成镜，也可以同框发生、在原声持续时拍听者、延迟到后续动作，或因有意留白而省略；不要求逢关键台词必切特写。具体组织见 `shot-groups.md`，声音身份和原台词继续按下节保真。

## 台词时长校验（台词与用户时长优先，2026-10-10 修订）

本节为台词保真与时长排期的单一事实来源；经验字速、句长、反应拍等创作建议不得覆盖用户指令。

1. **台词是红线**：用户提供或已锁定的台词，文字、数字、标点、说话人、话轮顺序逐一保留。未经用户明确授权，不删减、精简、改写、合并省略或同义替换；不能用字幕、梗概或新增旁白替代原角色应说出的台词。原句可以跨镜连续承载，重新拼接必须与原文一致；切镜不等于改词。
2. **按用户指定时长完成设计**：记录目标及其明确允许的误差，完整片头片尾也在预算内。选片长、要求加快节奏、允许 ±10秒，都不构成删改对白的授权；不得擅自延长到自己认为更合适的时长。用户已明确的要求直接执行，不因估算反复要求重新选择。
3. **每秒5字不是标准或上限**：字数÷假设字速仅作初步估算，不能证明「装不下」、触发删词、拒绝排镜或要求延长。语速随语言、角色、情绪、表演及参考片变化；不规定超过5字/秒只能持续3秒，也不另造普遍封顶值。中文字符、英文单词不能直接互换计量；标点停顿不能机械逐个累加。
4. **证据优先**：已有参考片及实际音轨优先于公式，结合桌读或代表段试产校准。用户指出同样对白已在参考片目标时长内完成，应先沿其节奏和声画组织设计；可访问参考片时测话轮、停顿与切点。只有用户描述而无视频时，说明依据来自用户，不冒称已观看或测量。只有文本时仍交付指定时长内的设计方案，清楚标注尚未实际音轨验证。
5. **先解决时间轴组织**：对白可覆盖听者反应、插镜、转场与同步动作；保持原说话人和顺序，用声画错位、跨镜连续对白、缩短非必要空白、段间重分配承载完整原文。听者反应与对白同时发生时只计一次时间；不把所有动作、反应、转场机械叠加到口播之后。对白超过某个字数不自动强制拆镜，按叙事和实际表演决定。
6. **核对真实结果，不虚报可行性**：实际制作时核对完整发声、可懂度、表演和总时长。若实测失败，先在原约束内调整镜头与声音安排；仍无法满足时呈报具体证据、缺口和已尝试办法，不能把未完成说成完成。只有真实且未能解决的执行冲突才需要用户决策；粗算超时不构成这种冲突，不能借它反复把删词或延长推给用户。
7. **交付校验**：保存原台词底稿和话轮编号，从最终交付文本提取实际对白，拆镜片段按原话轮拼接后逐字比对，同时核对说话人与顺序；不能只比较总字数。核验连续时间轴、段合计、片头片尾及用户允许范围。交付注明「设计时长」或「实测时长」，不混淆。

**适用边界**：用户明确授权创作新台词或修改指定原句时，仅该范围允许修改；其余仍锁定。用户后续明确改变时长才更新预算。本规则约束创作执行，不保证任何生成模型一次成功；试产失败须据实反馈，不能据此自创语速硬上限。

**反应与表演**：必要气口按角色与参考片安排，可在听者反应画面承载；不以统一的强制留白秒数挤占原对白或突破用户预算。

**叙事驱动拆镜四触发（2026-09-18 镜头设计库吸收——台词拆镜之外的第二个判据，任一触发即拆）**：出现以下任一结构才按叙事拆多镜，否则默认单镜头（一镜只保留一个主要动作变化，不加额外揭示/人物反应/结果）：
1. **发现—反应—行动**：角色看到威胁→作出反应→行动（镜1 建立/揭示 → 镜2 反应/准备 → 镜3 行动/余波；两镜时合并后两段）；
2. **人物对峙**：需同时交代双方位置、反应或权力变化；
3. **环境揭示**：环境本身含关键规模、信息或危险，且人物反应同样重要；
4. **地点或时间变化**：新的空间或时间必须清楚建立。

不因"有动作"就拆镜；单生成单元最多 3 镜，切镜类型与内切连续性约束照防坑清单第 7 条执行；每镜须有不同叙事任务与足够不同的景别/角度/构图（避免近似画面跳切）。

## 台词口型同步纪律（2026-09-29 事故回写——多次实测"有台词但角色不开口"，台词变画外音）

> 根因定性：规范缺陷。既有条款全是台词文本/语速/音频卫生的**负向约束**（不说话的别动嘴），独缺"说话者必须张嘴"的**正向锚点**——模型在肢体动作密集时优先做动作、牺牲口型；负向的"嘴唇保持不动"若主语不清还会一刀切全员封嘴。本节是台词镜的硬约束，与「台词时长校验」同级，不过不交付。

**口型触发三件套（台词镜缺一不可）**：
1. **情节写开口**：画面情节必须显式包含说话动作（「开口说道」「张嘴吼出」），说话瞬间的嘴部动作要出现在情节描述里——只写在台词字段、情节里没张嘴，口型不会被触发。
2. **面部可读**：说话期间说话者面部/嘴部在画面内清晰可见（景别 ≤MS 或面部占比足够）。背身说话、被遮挡、大远景念台词 = 口型必然丢失——要么升景别，要么显式声明画外音（voice off），不许暧昧。
3. **正向口型字段**：镜头层「口型」字段逐镜正向声明（模板已列字段）——说话者嘴唇随台词开合、逐句同步；负向只约束"未点名说话的其他角色"，正向负向必须成对出现。

**配套三律**：
4. **先张嘴后出声**：说话动作在台词出声前 0.2-0.3s 启动——段首台词在既有"台词在段首 0.3 秒内开始"基础上补「说话者嘴唇在出声前已张开」，避免静默帧吃掉口型窗口。
5. **动作竞争避让**：台词出声窗口内不给说话者排大肢体动作（拍车/敲键盘/蹦跳/举杯）——模型优先做肢体就牺牲口型；出现口型竞争时优先把大动作交给听者或插镜承载，或在既定预算内调整先后；不把所有动作时长机械加在对白之后。
6. **多角色对话**：每句台词说话者唯一且与视线/焦点匹配；A 说时 B 只给表情/肢体反应，嘴唇不动（负向限定主语写法见防坑清单第 24 条）。

**最小行为案例**：输入=台词镜「KTV中年男人跪着举杯谄媚问话 4s」→ 预期：画面情节含「仰起脸开口说道」、景别 MS 面部可读、口型字段写「KTV中年男人 的嘴唇随台词开合同步，王总 与陪酒人群嘴唇保持不动」、举杯动作停在台词出声前（出声窗口内不再举更高）。反例=情节只写"高举酒杯说台词"、口型字段缺失、负向裸写"所有人嘴唇不动"——三者任一即返工。

## 生成建议模板（交付物第五部分，2026-09-29 补——此前该部分无字段规范，靠即兴）

固定五块，按需裁剪但顺序不变：

1. **生成顺序**：按依赖与风险排序，不按剧本顺序——身份/场景锚点段 → 反复出现的对白表演段 → 高难度动作/VFX 段 → 常规覆盖段 → 过渡/插入/修补镜（与 generation-qc 批量顺序同源）。
2. **逐段参数表**：S# → 时长（Xs，对照模型上限）+ 画幅 + 参考图绑定清单（绑哪几张资产图/末帧截图）+ 模型路由（T2V / R2V / 首尾帧 / 图生视频）。**各段时长合计 = 时长门禁锁定值。**
3. **帧链延续计划**：列出所有硬连贯需求段对——「Sx 末帧截图 → Sy 首镜参考图」，无硬连贯需求则显式写"无"。
4. **声音执行标注**：按 Workflow 第 2 步定下的声音策略逐段标注——生成端原生台词 / 生成端只出动作音效与环境音 / 全后期配音（静音生成）。
5. **特殊生成方式声明**：微切 burst 段、严格切镜段、文字包装段等需「单镜逐一生成 + 剪辑台组装」的段落逐条点名（防坑清单第 7 条保底方案）。

## 其他注意

- **提示词语言路由（2026-11-02 平台化修订）**：判断标准只有一条——**投喂给模型的部分用该模型吃得最稳的语言，给人看的部分用中文**。①资产图提示词按制作门禁加载 `image-prompt-adapters.md`：ChatGPT 默认跟随用户语言，以自然语言指令表达并保留必要英文专业词；Midjourney 用简洁英文短语和置尾参数。旧的「资产图一律英文」不再覆盖平台选择；②视频生成分镜提示词以中文叙述字段为主体（SD2.5/即梦系中文原生），但**锚定词保持英文**：风格基座、影视级色卡、怪物/道具资产锁定词、运镜术语（中英对照写法如「极缓前推 slow push-in」）——锚定词与资产图提示词共用同一语义基座，保证图文同源；③人在环内容（四问推演/创作笔记/质检意见）用中文。
- 时间戳支持整数秒区间、时间点、相对时间；**不要用时间戳控制频率**（"一秒摇头3次"）。
- 小众术语（移焦/希区柯克变焦/子弹时间）必须"名词+描述性解释"转写；易歧义运镜加英文兜底（对照表见词典第十一节）。
- 情绪/表情用描述性语句，不用成语（"脸上带着满足的笑容，大口地吃饭"而非"津津有味"）。
- **日景防冷光（2026-09-16 漫剧导演库吸收）**：日景/白天场景的光影字段**禁直接写「冷白光/冰冷蓝光/刺眼冷光」**——棚拍假冷光是质感杀手。要表达白天肃杀/凄清，转译为「低饱和影调，青灰色自然漫射阴影，背光面与高光处自然明暗阶梯，逆光边缘光勾勒轮廓」；阴影禁死黑或全脸漂白，须带环境漫反射色阶。与光影三层构词法叠加生效（物理光源仍须有画面内实体依托）。
- 拍摄风格与色卡语义重复时二选一。
- 单镜信息量与时长匹配（约 3-5 秒一个动作单元）。

## 生成防坑清单（生成实战回写 2026-09-09 / 2026-09-10 两轮——以下每条都是真实生成事故换来的）

1. **眼睛禁忌（最高频事故）**：禁止写"眼中反光""眼珠斜向/转动方向""瞳孔里的反光"类描述——AI 会生成**发光眼**或**翻白眼**。眼睛只写视线方向与表情（"视线朝向地面，眼神平静"）；否定控制常驻：「眼睛自然、虹膜正常颜色、不发光、不翻白眼、眼白比例正常」。**2026-09-11 追加事故：「烛光在她眼底晃了一下」同样触发发光眼（特写+浅景深+锁定面部，眼底反光描述权重压过否定控制）——"眼底/眼中"是禁区词，光只能写在脸上（"烛光照亮半边脸"），永远不写进眼睛。**
2. **段头人物锚点三件套**：面部特征 + 发型 + 服装，缺一不可。只写服装 → 发型与脸跨段漂移（实测：角色在四个段落里是四张脸，发型决策完全没生效）。
3. **面部一致性靠图不靠字**：每段生成必须绑定三视图定妆图；文字锚点是辅助。不绑图 = 每段换脸。
4. **动作描述到身体部位级**：「坐下」会被自由发挥成弯腰驼背；要写「把包从肩上取下挂在椅背、自然落座，动作幅度小」。并常驻否定：「不要弯腰驼背、不要夸张肢体语言」。情绪的身体表演（站姿/手势/步态/距离）查 body-lexicon.md 选条目，不在本清单展开。
5. **情绪表演写死幅度**：「嘴角一点弧度」会被放大成暖男微笑、人设漂移；写「嘴角只有一丝几乎看不出的弧度，表情整体平淡」，否定常驻：「不要露齿微笑、表情幅度极小」。**2026-09-11 追加：「自己被逗笑」直接生成露齿大笑——「笑」字本身就会被放大，自嘲/无奈类微表情要写成「嘴角只有一丝自嘲的弧度」，否定控制写「表情幅度极小」不够，必须点名「不要露齿微笑、不要大笑」。**
6. **恐怖表情必须拆解，禁止概括词**：「咧嘴笑」会生成成普通微笑。要拆成：裂开的幅度（到耳根）+ 边缘质感（纸纤维毛边）+ 内部内容（纯黑/渗红墨）。且恐怖主体必须注明「清晰锐利」——AI 默认把"诡异"渲染成"模糊"，模糊=不恐怖。
7. **镜头密度预期管理**：模型对"段内时间戳切镜"执行不稳定，会把 2-3 镜吃成连续运镜。严格切镜需求 → 单镜逐一生成 + 剪辑台组装（保底方案）。**补充（2026-09-14 CINEDANCE 库回写）：若必须用段内受控多镜——每个切镜显式声明类型与连续性**：切镜类型白名单（硬切 / 猛切 smash cut / 匹配切 / 插入切 / 反打切 / 甩镜切），默认硬切，禁溶接/叠化类过渡（除非剧本明确要求，叠化的正向定义见 camera-lexicon 转场与叙事组）；每次内切后服装/伤势/道具/手部状态/视线目标/银幕方向/光源方向逐项不变，禁止切后人物瞬移或距离重置。模型不得发明未指定的切镜。
8. **群众演员显式点名**：背景需要人时写「背景有 N 名学生在做 X」，不写「人群」；关键群像镜（如集体低头）建议在段头单独强调。
9. **背景文字不可控**：编号、标牌等背景文字 AI 会生成乱码或错误数字——不需要读字的地方写否定「背景不要出现清晰可读的编号/文字」。
10. **时间/天色双层锁死（2026-09-10 事故：段头写夜、生成出大白天）**：段头必须有「时间/天色」中英双语硬字段（night, blackout / dusk, golden hour），且镜头层色卡带时间词（"冷青灰夜景 cold blue-grey night"）双层锁死。风格基座的暖调词（warm muted tones, sepia undertones）会对抗夜晚语义，必须靠显式时间词压过去。
11. **动作因果链完整（2026-09-10 事故：玻璃"莫名"碎裂、人物"突然"出现在主角身旁）**：人物入画必须写空间来源与动作链——从哪来（从窗外黑暗中冲出）→ 做什么（侧肩猛撞玻璃）→ 结果如何（玻璃从外向内炸开、收肩翻入落地、手抓向目标手腕）。"突然出现""莫名发生"类零因果描述 = AI 生成鬼畜瞬移画面。
12. **跨段连贯靠图不靠字（帧链延续）**：模型以段为独立投喂单位，段头文字衔接写得再细也不保证执行。跨段硬连贯需求（同场景连续动作、人物位置延续、天色延续）→ 用上段生成结果的末帧截图作为下段首镜参考图（R2V 首帧绑定），文字衔接只是辅助。
13. **载具运动必须写朝向（2026-09-11 事故：搬家卡车倒着开出画）**：「卡车驶出画面左缘」模型不知道车头朝哪，直接倒行。载具镜头必须写「车尾朝向镜头、向左驶出、尾灯渐远」或「车头朝右驶入」，否定常驻：「车头朝运动方向行驶、不要倒车」。
14. **视线对象与机位必须自洽（2026-09-11 事故：独白戏人物对着镜头说台词）**：「面对镜头方向站定」+「摄影机位于正面」+「望着房子」= 矛盾指令，模型必选最省事的——面对镜头演讲。独白/眺望/对话戏，「人物空间位置」「机位角度」「画面情节」三个字段的视线对象必须写同一个目标（如：侧身朝向画面右侧的房子 + 摄影机在侧前方 45 度 + 望着画面右侧的房子）。视线有对象，表演才有支点。**补充（2026-09-14 CINEDANCE 库回写）：躯干朝向与视线方向是两个独立字段，关系戏必须分开写**——「躯干朝向 X」+「视线锁定 Y」；只写一个，模型会让头身同向，错失"身体对着 A、眼睛瞟着 B"这类关系表演。
15. **打斗定格陷阱（2026-09-11 事故：段尾"对峙定格 ≥3s"生成 3 秒完全冻结画面，高潮泄气）**：打斗段的停顿指令必须带时长上限与次级运动——写「0.5s 死寂，烟尘与余烬持续飘落」，禁止裸写「定格 ≥Xs」。死寂放在最大一击之前，不放在打斗结束之后；收尾用升格飘落碎片+缓推"慢下来"，不用静止帧"冻住"。**恐怖静物余韵镜同理（2026-09-17 ED 实测：镜面写了"固定机位（一帧不动）+零动作+定格四秒"，成片除一道光线扫过外=完全静帧）**——静物/余韵镜的"静"必须拆成次级运动清单（极缓推近、光源节律性明暗、焰苗拉长压低、浮尘），且否定控制里**禁止出现"定格/静止/一帧不动"字眼**（会被字面执行成死帧）；"它是活的"的错觉由光与运镜承担，禁止让模型直接变形恐怖主体。
16. **打击目标歧义（2026-09-11 事故："右拳收于腰侧后直线击出"被渲染成拳打巨锤）**：招式必须写明接触目标与部位（「踹中天将胸口甲面中心」「砸向面门」），只写运动轨迹模型会自选最近物体当目标。
17. **打斗位移无量化=慢速漂移**：高速打斗的每次位移写「Xs 内横跨画面 Y%」（如「0.1s 内瞬闪横跨 40% 画面」），并在段头声明 ACT 追尾机位体系+零站桩；否则模型默认影视慢速，缠斗变太极（对照实验：无量化版本 12s 仅 1.5 次有效交锋，量化版本 20s 达 8-10 次）。
18. **预动信号与受击响应（2026-09-12 物理分镜库回写——防"发愣"与"僵尸受击"）**：每个攻击动作前补 0.1s 内的预动描述（重心预移方向+关键部位肌肉蓄力/震颤+视线锁定目标），如「重心下沉右移、右肩肌肉绷紧、视线锁定对方胸口，随即右拳直线击出」；受击方反应必须在 0.1s 内接续（头后仰/踉跄/格挡手抬起），禁止攻击命中后对方静止一拍才反应。预动与受击写在同一时间戳区间内，不单独占拍。完整动作原理（预备/跟随重叠/弧线/缓入缓出/惯性质量感/姿态动势三原则）见 `motion-lexicon.md`——动画向与打斗段按需加载。
19. **道具状态约束必须进否定控制（2026-09-14 实测事故：画面情节写"刀不出鞘，连鞘刀横砸"，两镜后模型自行拔刀——"终于握住刀柄"的蓄力悬念被提前泄掉）**：「不出鞘/不摘面具/不解开衣扣/不放下手中物」这类**状态禁止型约束**，模型在画面情节里的遵守度极弱——它对"剑客"这类角色的先验就是"早晚要拔剑"。写法：画面情节照常描述行为，同时在本镜否定控制里点名状态——「刀始终收在鞘中、不要拔刀」「面具始终戴好、不要摘下」，后续镜若需维持同一状态，逐镜复读（与跨板块通用打法第 3 条"材质复读"同源）。
20. **首帧占位锁（2026-09-14 CINEDANCE 库回写——模型爱用空定场镜开场，角色第 2-3 秒才入画，短剧节奏直接垮）**：需要角色开场即在画的段落，段头显式声明「第一个可见帧已包含全部所需角色且位置正确，无空定场帧、无延迟入画、空间关系第一帧即可读」。空镜开场只允许剧本明确要求时使用（如"空镜+声音先入"转场，见 camera-lexicon 转场与叙事组）。
21. **上下文隔离·封档纪律（2026-09-14 CINEDANCE 库回写）**：每段投喂 Prompt 是一份"密封的当前段文档"——只写本段可见可听的内容；禁止携带：场号/剧本场标、上一段剧情摘要、"同上""继续""如前所述"类衔接词、本段不出场的角色与 @实体、上一段用过的道具描述。模型没有上下文，携带物只会变成污染源（多余角色入画、道具状态错乱）。跨段连贯走第 12 条帧链延续（末帧截图），不走文字携带。
22. **写状态不写过程（2026-09-14 LIRA/ACTING 库回写——模型拍得好"状态"拍不好"过渡"）**：动作写进行中的状态，不写到达状态的过程链。「手伸进包里、掏出、抡起来」会垮；「抡到一半，手臂已完全展开」能成。逐节拍串联状态快照，不叙述连续过程。与第 11 条动作因果链不矛盾——因果链管"从哪来→做什么→结果"的空间逻辑，本条管单个动作的时间切片写法。
23. **空间锚点禁弱词（2026-09-14 CINEDANCE 库回写）**：人物与地标/他人的空间关系禁止写「附近」「旁边」「周围」「不远处」——一律换成物理锚点：「1 米以内」「手搭在引擎盖上」「背抵着墙」「站在招牌正下方」「出租车后车门正前方」。弱词=模型自由摆放，走位全乱。
24. **台词音频卫生（2026-09-14 CINEDANCE 库回写；2026-09-29 主语限定修订）**：有台词的段落——只念引号内的台词，不加词不即兴；**「嘴唇保持不动」必须限定主语为「未点名说话的其他角色」，并与镜头层「口型」字段的正向声明成对出现**——只写负向不写正向 = 全员封嘴（含说话者），口型直接消失；每句台词前后各留 ≥1 秒静默（需要紧跟时显式声明"台词在段首 0.3 秒内开始"）；环境音在台词期间让位压低。无字幕、无旁白（除非剧本写明）。
25. **验收必须做"对标对比"，禁止只对规范清单打勾（2026-09-14 实测事故：打斗分镜规范项全过，成片交锋稀疏节奏塌方，自评虚高 85 分、用户实测 30-40 分）**：分镜交付前与成片验收时，只要存在对标参考，必须对比三个硬指标——**交锋/事件次数、切点密度（cuts/分钟）、有效动作时长占比**，与对标同一量级才算过；规范清单管"不翻车"，对标对比管"好不好看"，两个都要。无对标时按时长配比纪律的交锋次数下限（每 10s ≥4-5 次）验收。
26. **写实角色的受控实拍锚点（2026-10-08 路人化事故修订）**：当风格基座含 `smooth skin texture / soft focus background / gentle highlights` 导致塑料感时，先确认 A 定脸选角已经锁定上镜级骨相与气质，再做最小校正：加入 85mm 人像镜头/胶片颗粒等 1 组摄影锚点，并从鼻翼轻微毛孔、自然肤色起伏、一颗小痣、个体发丝中选 1-2 项微纹理。禁止再堆叠"毛孔＋绒毛＋油光＋细纹＋血丝＋脸部不对称"的完整缺陷清单；它会把审美权重挤掉并使人物路人化。验收顺序固定为：①角色魅力与身份辨识度；②五官/身体比例；③妆发与服装层级；④最后才是皮肤真实度。塑料感仍严重时，单变量调整摄影锚点或降低磨皮，不同时改脸、身材和服装。

27. **怪物镜头禁用"定妆姿势图+保持姿态"做图生视频（2026-09-15 OP04 实测事故：反关节跨步定妆图绑 R2V，模型把冻结姿势做成木偶式挪动，"僵硬死板毫无表现力"）**：人形怪物的正常步态（走/跑）是 AI 视频的死穴——越"像人一样走"越假。怪物表现力一律改用**姿态违背短镜语法**（《雾山精神病院》四集逐帧对标验证）：①每镜一个姿态违背的单一瞬间——四肢着地蜘蛛爬、倒挂、贴墙、躯干拧转、向镜头扑（charge at camera）、局部肢体特写（膝盖/手/脚），画面情节写"瞬间姿态+动势"（mid-lunge / crawling fast toward camera / motion blur），不写"行走过程"；②怪物位移用微切跳位（0.2-0.6s 一切、每切近一步）或扑镜构图变化，不让模型连续位移；③怪物镜**不绑定妆姿势图**（姿势图会锁死姿态对抗动作描述），改用文字锚定特征+文生视频；微切 burst 段（0.2-0.3s/帧）可用姿态静帧+推拉抖动效拼装；④人怪冲突优先"怪+人同框"一镜成立（人前景正常动作、怪纵深姿态违背），比正反打省力且更炸。
28. **音效真空事故（2026-09-16 OP05 实测：OP 后半段音频 RMS 0.01 死寂，"音效严重缺失"被打回重做）**：「声音全后期」纪律的正确含义是**歌/音乐/台词走后期**，**动作音效（怪物嘶吼/尖叫/爆灯/脚步/电火花滋滋/摔落）必须在生成端逐镜写进「音效」字段**——生成端全静音 + 后期音频没做 = 两头落空，画面再对也是"图片展"（静音的恐怖片不恐怖）。分镜「音效」字段禁止写"无（生成端静音）"，一律写具体动作音效描述（质感+来源，如"低频非人嘶吼，倒放人声混金属摩擦"）；段尾负向控制同步改成"不要 bgm（歌为后期）；生成端只出动作音效与环境音"。**成片验收必须加音频验收**：逐段过耳，禁止 0.5s 以上声音真空（设计性切黑除外）；怪物嘶吼/爆点音效必须全片最大声压级；跳切衔接处用 L-cut 声音桥（前一镜的声音跨切点延续 0.3s）缝合画面断层。

29. **群像在场声明与单实例（2026-09-16 漫剧导演库吸收——防丢人/防分身的实测体系）**：AI 视频模型每段独立生成、零记忆——谁在画里完全取决于本镜提示词写了谁：
    - **在场声明**：同场景多镜的每一镜必须点名本镜全部在场角色（动作主角+静止配角全列：身份+位置+状态）；只听不说的听话者也物理在场，不写模型就会自行删人加人；画外角色明写「×不入画」——画内一个不漏、画外一个不混；
    - **第二人四件套**：远景/背景人必须「具名+具象+定位+状态」（如「@B（远景·灰袍老者·断桥尽头·背身而立）」），严禁"远处站着个人"类弱指令；被主体视线/动作连接到的配角不会被省略；
    - **单实例铁律**：每个点名角色全程只有一个身体——否定控制必含「每个点名角色全程只有一个身体，禁止同角色分身、复制人、同框重影」；「仅 X 人」的人数锁定只防陌生人，防不了点名人自己变两个，两条都要写；
    - **位移当前态锚点**：站位声明里登记过位移的角色，其后每一镜点名必须带当前位置（「保持镜2进言位：帅案前半步·拱手而立」），禁止悬空点名——只写名字不给位置，模型会把起点和终点各渲染一次；位移注明「单实例迁移，旧位不得残留」；
    - **景别×取景半径匹配（分身根因）**：点名做可见表情/动作的角色必须在该镜景别框得住的物理距离内（中近景≈1 人、中景≈相邻 2-3 人、全景≈同屋全员）。让取景半径外的角色做可见反应，模型只能把他位移过来或复制分身。三种合法处理：①升全景全场同框反应；②拆反应镜（主体镜明确"其余角色不入画"+ 反应镜众人归位）；③降级为画外音/声音反应。"缓慢拉镜拉出全员"不合法（拉镜改不了物理距离）。

30. **跨段蒙太奇默认与锚点钩子（2026-09-16 漫剧导演库吸收）**：段与段是**各自独立生成的剪辑关系，不是连续拍摄关系**——跨段位置/场景不一致时，默认蒙太奇直切（前段终态→后段开场，剪辑点自然衔接），接续状态标「跨段蒙太奇衔接」即可；**严禁为凑连续性把两个场景塞进同一个生成单元**表现"连续走位"（双场景穿梭是穿帮高发源）。判定口诀：**跨段切、同段连**——同段内才讲走位连续性（同场景内"过渡走位不拍摄"合法，场景资产唯一）。但蒙太奇省了走位，**前段收尾必须为后段核心登场元素埋钩子**——后段要登场的人/物/景，在前段尾拍以远景剪影、视线指向、声音预告提前入画（段3尾拍远处高台敌将剪影→段4开战），否则后段登场元素无来由；同时前段否定控制为该钩子元素开单例豁免（唯一豁免条件：何时/何处/剪影级/静止/仅一人，收窄到不会引发人数失控）。

31. **追逐/逃跑镜的威胁方位事故（2026-09-16 OP07/OP08 两轮实测）**：模型对"夜街+奔跑+喘息"场景有强先验——威胁必须可见、且在画面上。两轮失败升级的**三级处置阶梯**：①第一级（正向构图写死，OP07 后采用）：空间锁定/机位/画面情节写"威胁在正后方、前方空无一人"——**OP08 实测仍败**：只要提示词任何位置出现实体名词（哪怕在否定控制里写"禁止人形轮廓"、在音效里写"身后刮擦声"），实体就被召唤进画面；②第二级（零实体词）：全篇删除"威胁/身后/逃/怪物/人形/追逐"一切字眼，连否定控制都不含实体名词（改为"不引入任何新元素"），氛围词中性化（"你在逃"→"灯在一盏一盏灭"），威胁音效移到后期铺底；③第三级（终极手段，与②同用）：**文生图出空场景静帧→图生视频绑首帧**——模型从"没有人的几何"起步动画，实体无从入场（空街静帧文生图一次即可过，静帧没有追逐先验）。**同条救场经验**：方位反了的素材不一定是废片——OP07 里"镜头逼近爬行怪"的段落直接改作"回头见它在身后爬"的回头镜（C1b），完美成立；验收时先想"这段素材能改作哪一镜"，再决定重投。

32. **怼脸嘶吼的失焦红线（2026-09-16 OP07 实测：贴脸嘶吼镜整脸动态模糊成蜡团，签名裂口不可读）**：怼镜/扑镜镜的动势模糊只允许在画面边缘，恐怖主体（裂口/面部特征）必须清晰锐利——否定控制常驻「面部主体不糊、裂口边缘锐利可读，动势模糊只允许在画面边缘与背景」（与第 6 条"模糊=不恐怖"同源）。救场：同批录制的 crisp 嘶吼素片做剪辑台推近顶替，不必重投。

33. **英文台词语速套用事故（2026-09-16 EP2 S1-S4 实测）**：该项目曾因对白与镜长安排不当生成过快、变形的念白。历史失败证明需要实际音轨校准，不证明存在通用于所有角色或模型的字速上限。中英文计量不能混用；完整排期与冲突处理见「台词时长校验」。保持原台词，在用户预算内用跨镜对白、反应插镜和代表段试产调整；不可从单次事故推出「中文5字/秒、英文3.8词/秒封顶」。

34. **动作时长也是物理量+多镜段内模型自主再分配镜长（2026-09-16 EP2 S1-S3 语速重制版实测）**：dialogue-first 只算了台词账，没算动作账——镜1"推门→走过半间店→落座→摆蜡烛"动作链排 2.5s，模型按动作真实时长跑了 7.5s（一镜到底），挤占同段后续台词镜（4.5s→3.1s、4.5s→2.2s），台词再次被赶成 4-6 词/秒。**两段教训**：①动作耗时要按具体表演和场面校准，不能把本案秒数当所有项目的物理下限。先在用户总预算内重分配镜长，或用同步对白、插镜承载动作；不能为此删除用户锁定的事件或擅自延长全片；②多镜段内模型会自主再分配各镜时长（时间码只是建议值），保动作就挤台词、保台词就赶动作——**生成后必须逐镜对表**（实测时长 vs 排期），单镜偏差 >40% 即触发重排或单镜重投；关键台词镜/动作链镜若反复被挤，拆成单镜独立生成（一镜一投喂，时长参数直接钉死）。**另附本案空间合成事故**：低机位贴桌面拍特写时，若后景人物与桌面之间没有可见地面间隔，桌面平面会在视觉上直连人物躯干=“桌子长到人脖子高”——桌面前景特写+后景人物路过的组合，机位必须写死俯角（≥30-45° top-down）露出桌沿与地面的分界，或在否定控制写「后景人物与前景桌之间保持可见地面间隔，人物不得贴身站在桌沿正后方」。

35. **对照蒙太奇必须设计成"构图镜像对"，否则匹配转场全丢（2026-09-29 《少年傲骨》试产打回事故——16 镜各自精彩、剪起来 15 个普通硬切，原片第一卖点落差感归零）**：少年vs成年/理想vs现实/过去vs现在类一比一对剪片，对照蒙太奇的对照**不在剧本里，在两镜的构图关系里**。分镜层必须把每对暖冷镜设计为镜像对——**同景别量级、同机位高度与角度、同主体画面位置、同姿态轴线、同焦段、对照对内运镜同型**；只翻转"世界"（色调/服装/场景/光源/年龄），不翻转"形式"。落地三步：①全片设定层建**逐对镜像锚点表**（每对一个显式锚点：俯身姿态/手拍车身同手势/仰脸居上三分之一/中轴单人/碗杯居画面中心/同机位街道/额头贴布同位/张臂轮廓），两镜的镜头层逐字段对照着写；②**对照对内禁止花哨运镜**（环绕/上摇/横摇/缓推/移焦炫技一律砍掉）——一推一固、一摇一固 = 匹配报废，运镜不同型比对错景别更致命；③匹配切不走末帧截图帧链（匹配切是"形式相同世界翻转"，靠两镜各自生成保证），剪辑台交接切点清单：暖→冷切点卡在暖段末帧姿态极值帧，冷段从姿态对应帧起播。反例实录：S2 缓推+移焦酒杯、S3 环绕上摇、S5 从靴子上摇、S11 横摇跟拍、S12 贴地虫视——单看每镜都是"好镜头"，配对全毁。**试产纪律：匹配对必须成对试产，两段都过才收。**

36. **同色彩组跨段色调漂移（2026-09-29 二爷回写——多段生成"一段一个色调"的质量事故）**：色彩影调系统锁的是"场景×时间×情绪"的换色合法性，管不住同组内漂移——同属一个色彩组的各段（同场景同时段，或对照蒙太奇的暖组/冷组内部）生成时色温/饱和度/对比度互相跑偏，剪起来"一段一个色调"。**生成端预防三条**：①**组内色卡措辞逐字锁定**——同一色彩组各段的「影视级色卡」字段 60/30/10 比例与色名逐字一致，只允许场景本色项（30% 那档）随场景变化，主色与强调色不许改写、不许同义换词；②**组内首段即基准段**——试产选定组内基准段（如暖组标尺/冷组标尺，见生成建议试产条款），后续同组段落以色卡逐字复读对齐基准，不重新发挥；③**时间词同组一致**——同组各段「时间/天色」硬字段与色卡时间词保持同一措辞。**修复路径**（已有漂移时）：走 Stage 4b 参考帧校色 + 轻 LUT 收口（≤50% 强度只做粘合），不回生成端逐段重投——重投会引入新偏差，两头打架。**验收**：同组段间并排静帧对比，主色块色温/饱和度无肉眼可辨差异；组间换色必须全部有"光的理由"。

37. **台词镜"有词无口型"事故（2026-09-29 用户反馈、多次复现：台词在念但角色嘴唇纹丝不动，台词变画外音）**：事故根因=规范只有台词负向卫生、无正向张嘴锚点（详见「台词口型同步纪律」根因定性）。修复落点即该纪律全部条款——交付前逐台词镜过三件套（情节写开口/面部可读/口型字段正向声明），生成端 QC 把"有台词无口型"列为硬失败，返修优先级：①补口型字段与情节开口动作 → ②升景别把面部拉近 → ③清出台词窗口内的大肢体动作 → ④仍不触发则换路由（拆单镜独立生成或改画外音声明）。

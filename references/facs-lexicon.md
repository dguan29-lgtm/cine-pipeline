# 微表情 FACS 词库（Facial Action Units · 按需加载）

> 来源：2026-09-16 漫剧导演库（short-drama-director）FACS 引擎吸收——Ekman FACS 方法论：**人脸表情由独立动作单元 AU 组成；不写"开心/难过/邪魅"结果词，写哪块肌肉、做什么可见动作、多大幅度、持续多久**。AI 对「颧大肌把一侧嘴角向斜上拉起、幅度极小」的执行，远比对「邪魅一笑」稳定。
> 与既有规则分工：`prompt-frameworks.md` 框架 E（情绪微表情相位法）管**时间结构**（一个镜头内情绪拆相位演进）；本词库管**肌肉内容**（每一拍脸上具体怎么动）——相位法定节奏，FACS 定动作，叠加使用。身体（非面部）表演查 `body-lexicon.md`，不在此重复。

## 触发分级（不是所有文戏都展开）

- **默认（简单文戏）**：表演位用正常影视表演语言（动作+神态+可见生理反应），**不展开 AU 配方**；空泛结果词禁令（禁"开心/难过/邪魅/玩味"）全局有效。
- **满足其一才全量调用本词库**：① 特写/大特写镜头；② 微表情、口是心非、隐忍克制类表演；③ 情绪转折关键拍（台词重音/金句发酵气口）；④ 该角色表情历史易崩、需精细面部控制。
- 判定不清按调用处理。

## 五步工作流

1. **定情绪与潜台词**：这一拍角色真正想表达/想隐藏什么（微表情的核心用途是"口是心非"）。
2. **查配方**：情绪→四区肌肉动作，查下方配方表；易混组合（真假笑/惊讶vs恐惧/厌恶vs轻蔑）必须查，不要凭印象。
3. **逐区拆解**：按「眉区 → 眼区 → 颧颊 → 嘴/下颌」四区写全，缺区=表情发空、模型自由发挥崩脸。
4. **定强度与时序**：强度三档 + "起—hold—落"时间，峰值对齐台词重音字。
5. **翻译进投喂正文**（分层铁律，见下），再过自检清单。

## 分层铁律（最高优先级，违反即返工）

**AU 编号、强度档标记、英文 kernel 是给创作者看的内部标注，禁止出现在投喂正文**——模型不识别 FACS 编码（会当无意义 token 或渲染成画面文字），中英混排会双执行打架。投喂正文只写画面语言：**哪块肌肉 + 做什么可见动作 + 幅度 + 持续秒数**。

- 强度档翻译：〔痕〕→「轻微地/极浅地/一丝/几乎看不出地」；〔显〕→「明显地/清晰地」；〔强〕→「大幅度/剧烈地」。
- 英文 kernel 唯一正当用法：整条提示词本来就全英文时（框架 C YAML 场景）；中英混排一律禁止。
- AU 编号的归属地：内部 FACS cue 表 / 质检意见（明确标注"不进投喂正文"）。

## 强度三档与时序

> 分工（SSOT，2026-10-03 补）：**stage2「表演强度标尺」管整场戏的情绪档位**（2/4/6/8/10，压住>释放——写戏时定"这场到几档"）；**本节三档管单个表情特写的肌肉幅度**（〔痕〕〔显〕〔强〕——写分镜提示词时定"这个镜头脸动多大"）。先由 stage2 定戏档，再由本节把该档翻译成面部动作；戏档 6/10 压制态通常对应〔痕〕~〔显〕，10/10 释放才用〔强〕。

| 档 | 肌肉幅度 | 时长 | 用于 |
|---|---|---|---|
| 〔痕〕trace | 10-25%，仅特写可读 | 起 0.2-0.3s，hold 0.3-0.8s | 藏情绪、日常、克制型角色、微表情 |
| 〔显〕clear | 30-55%，中景可读 | 1-2s | 主要情绪、态度转折 |
| 〔强〕strong | 60-80%，远景可感 | 爆发后 0.5-1.5s 回落 | 爆点、群像、惊恐/大笑 |

- 任何表情都要有"起—hold—落"，不全程绷在峰值；真笑可让嘴角先动、延迟约 0.3s 笑意才到眼（更真实）。
- **表情不能比台词先结束**：峰值对齐重音字、句尾留半拍余韵，防止"话没说完脸先松"。
- **强度宁小勿大**：默认〔痕〕；〔强〕只给爆点且不超过 80%，满格易成鬼脸。
- 与语速校验联动（stage3 台词时长校验）：表情 hold 时长不得侵吞台词预算；金句后 0.3-0.8s 发酵气口正好承载余韵微表情。

## 必记铁律（高频翻车点）

- **真笑 vs 假笑**：杜乡真笑 = 眼轮匝肌参与（眼尾眯、眼下隆起、浅鱼尾纹）+ 嘴角上提——**眼一定参与**；只动嘴角、眼睛不眯 = 社交假笑。要"假笑/职业笑/皮笑肉不笑"时恰恰只给嘴角。
- **情绪靠组合不靠单点**：抬眉+瞪眼 = 惊讶；再叠眉心拧住才是恐惧。单一肌肉常含义中性。
- **提上唇 ≠ 嘴角下垂**：提上唇（鼻唇沟加深）= 轻蔑/厌恶/嫌；嘴角下垂 = 难过/委屈。写反情绪就错。
- **左右要指定、不中途换边**：单侧动作（玩味笑、挑眉、wink）必须写明哪一侧，并与镜头/站位轴线一致；wink 轻柔一次到位、不抽搐。
- **不叠互相矛盾的肌肉**：同侧嘴角同时上扬和下压。
- **遮挡就写看得见的部分**：墨镜/侧脸/背对/阴影遮眼时，眼区拍不出来——改写镜上缘露出的眉与下半张脸、下颌、头部角度；背影、纯物体、字幕卡豁免表情。
- **眼睛禁区不豁免**：本词库的眼区动作只写眼睑（睁/眯/收紧/半垂）、眼尾、眼下——「眼底/眼中/反光/眼神光」仍是 stage3 防坑第 1 条禁区词，光只写在脸上；瞳孔缩放仅限既有击杀链等特写终结写法。

## 常用肌肉动作速查（画面词直译）

- **上半脸**：内眉头上抬（悲伤的八字眉）/ 外眉梢挑起（挑眉）/ 眉整体下压聚拢+眉心竖纹（怒、狠）/ 上眼睑提起（瞪眼、睁大）/ 眼尾眯+眼下隆起（真笑之眼）/ 下眼睑收紧（目光变锐、审视）/ 眼睑半垂（疲惫、傲慢俯视）。
- **下半脸**：上唇提起+鼻唇沟加深（嫌、轻蔑）/ 嘴角向斜上提（笑）/ 嘴角向侧后绷紧·单侧（讥、玩味）/ 嘴角下垂（难过、委屈）/ 嘴角向两侧横拉（隐忍、紧张）/ 上下唇压成一条线（克制、决心）/ 唇微张·下颌松（愣住、惊讶）/ 下巴微上顶皱起（悲、梗着一口气）。
- **非面部自主神经信号（"藏不住的真实"）**：耳尖泛红、喉结/喉部吞咽一动、出汗、呼吸变化、指尖发白、干咽、眨眼变密。

## 情绪配方表（查表即用，投喂前按分层铁律翻译成画面词）

### A. 基本情绪

| 情绪 | 配方（四区） | 要点 |
|---|---|---|
| 快乐（真心） | 眉放松；**眼尾眯、眼下隆起、浅鱼尾纹**；苹果肌上抬；嘴角自然上扬，笑开时露上齿 | 嘴角先动、0.3s 后笑意到眼，对称、回落柔和 |
| 悲伤 | **内眉头上挑同时眉心聚拢（八字眉）**、额头中部浅纹；眼睑沉、眼眶湿润；面颊略垮；嘴角下垂或抿唇强忍 | 核心在内侧眉不是皱成一团；强忍时嘴越紧眼越湿 |
| 愤怒（冷怒） | 眉下压聚拢+眉心竖纹；**上眼睑瞪+下眼睑收紧**成锐利怒目；唇压成线或变薄内收 | 狂怒才加张口；克制型角色用冷怒更高级 |
| 恐惧 | **整条眉抬起却在中心拧住**、额纹扭曲；眼大睁露上方眼白、眼神紧绷游移；嘴角横拉变长、下颌微松 | 配脸发白、后缩；与惊讶的区别=眉心拧不拧 |
| 惊讶 | 整条眉平抬、额头横纹、**眉心不拧**；眼睁大但是"打开"不是紧绷；下颌自然松开嘴轻张 | 真惊讶 0.2-0.5s 起、**1 秒内消退或转情绪**；持续超 1-2s 是演的 |
| 厌恶 | 鼻梁起横褶、鼻翼上提；**上唇整体抬起、鼻唇沟深**；眯眼、视线偏开 | 对称 |
| 轻蔑 | 基本不动；**一侧上唇/嘴角提起或向侧后绷紧**，不对称冷笑；微仰头、半垂睑俯视 | 不对称+优越感；幅度要小，越淡越刺人 |

### B. 笑的家族（最高频，必须分真/假）

| 笑 | 配方 | 用途 |
|---|---|---|
| 杜乡真笑 | 同"快乐"：眼尾眯+眼下隆起+嘴角上扬 | 真心、温暖 |
| 社交假笑/职业笑 | **仅嘴角上提，眼完全不眯**；略不对称、消退偏快或僵住；嘴在笑眼神是冷的 | 皮笑肉不笑、敷衍、强撑场面 |
| 玩味/痞帅单侧笑 | 只有一边嘴角向斜上挑、同侧眉梢极轻一挑，眼睛从容不眯；慢起慢收 | 挑衅、上位者、浪子 |
| 苦笑/无奈笑 | 嘴角一边想上扬一边被向下拉，像笑又像叹气；眼无笑意 | 自嘲、认命 |

### C. 控制与压抑类（克制型/口是心非角色核心弹药）

| 状态 | 配方 | 要点 |
|---|---|---|
| 抿唇决心 | 上下唇压成干净的线、嘴角不外扩、眼神定；前置一次轻吸气/吞咽 | 忍住不说、下定决心 |
| 高度隐忍/发狠前 | 唇变薄内收再压紧、眼睑收窄、眉轻压，像把情绪往里吞 | **爆发前的静止最有压迫感**（时长遵守打斗/文戏定格纪律） |
| 紧张/尴尬 | 嘴角向两侧拉开变扁、唇轻抿又松、笑一下收回；眼神先躲开；配干咽、摸颈摸鼻 | |
| 口是心非 | 嘴角向侧后一绷，嘴上说得轻松，眼神先泄底（眼睑垂、眉心一压） | **嘴与眼方向相反**是核心 |
| 撒谎/心虚泄露 | 嘴角一绷、抿唇、眨眼变密、眼神先移再强行看回、喉结一动 | 全部〔痕〕级，像下意识而非表演 |

### D. 心动与弱势类

| 状态 | 配方 |
|---|---|
| 害羞/心动 | 眉轻抬、眼睑略张像被吸住、嘴角压不住地小扬；先垂眼错开、半秒后又偷看回来；耳尖/脸颊悄悄红 |
| 愣住/被说中 | 唇分一小缝、眉极轻一抬、身体和话都顿住；随后抿唇收回或笑遮 |
| 瞬时吃痛 | 皱眉、眼周挤紧、头本能偏开；只给一拍、不渲染（暴力合规：无血） |
| 哭 | 八字眉死死拧着、眼周挤红、鼻根酸红、嘴角下撇/下巴皱、唇抖微张；无声啜泣幅度小，痛哭加肩起伏与抽气 |
| 疲惫/无奈 | 眼睑半合、眼神乏光、嘴角略垮或抿一下、一口长气、肩垮下 |

### E. 掌控与高光类

| 状态 | 配方 |
|---|---|
| 挑眉 | 一侧眉梢慢挑、hold 半拍、放下，余脸不动；配歪头="说下去？" |
| 来兴致 | 眉抬、睑开、眼睛像被点亮、嘴角跟着扬；要有清晰"点亮"瞬间 |
| 单眼 wink | 一只眼轻柔闭合、另一只保持睁开，同侧嘴角挑；柔、一次到位、不连眨 |
| 傲慢/不怒自威 | 微仰头、半垂睑视线略向下压着对方、一边嘴角极淡一勾；动作越少越有分量，全〔痕〕 |

## 情绪六阶段生理递进（高压对峙/重大冲击的弧线模板）

角色面临重大心理冲击时，表演按生理规律递进，不一步到位：

1. **触发事件**（听到关键秘密/看到致命证据）→ 2. **身体初识反应**（呼吸骤然一窒）→ 3. **社交压抑掩饰**（强行拉紧下颌线条，维持平静）→ 4. **局部生理泄露**（喉结吞咽一动、嘴角肌肉微不可察抽动、指尖发白）→ 5. **控制失效破防**（呼吸粗重急促、眼神闪烁破裂）→ 6. **情绪余韵沉淀**（极痛或极冷后的极静、眼神空洞深邃）。

- 每一阶段落成上面配方表的具体肌肉动作（如阶段 4 = 撒谎泄露类配方〔痕〕档）；
- 与框架 E 相位法配合：六阶段=相位内容的选型库，相位时长=框架 E 的量化纪律。

## 输出前自检清单

- [ ] 触发条件满足才全量展开；无残留"开心/难过/邪魅/玩味"等空泛结果词
- [ ] 眉/眼/颧颊/嘴四区写全，或明确说明某区被遮挡及其替代信号
- [ ] 真笑带眼周动作；假笑刻意只给嘴角；惊讶与恐惧已区分（眉心拧不拧）
- [ ] 提上唇与嘴角下垂没用反；无互相矛盾的肌肉叠加
- [ ] 单侧动作指定了左右且不换边、与轴线一致
- [ ] 强度档已翻译成画面词、峰值对齐台词重音、句尾有余韵、未侵吞台词预算
- [ ] **投喂正文零 FACS 标注**：无 AU 编号、无强度档标记、无英文 kernel（除非全英文稿）
- [ ] 未写「眼底/眼中/反光」禁区词（防坑第 1 条）；遮挡镜头没写拍不到的眼区

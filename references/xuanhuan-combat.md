# 玄幻法术战斗词库（Xuanhuan Combat · 按需加载）

> 来源：2026-09-16 漫剧导演库（short-drama-director）xuanhuan-magic-combat 体系吸收（含实测验证记录）。**玄幻/仙侠法术流打戏的专用语法**——战斗语言从「拳脚兵器+受力链」切换为「法宝媒介+元素术法+术法攻防+能量具象化+对军清场」，**禁止把法术打戏硬套武侠物理打斗**（近景机枪对招、11 环受力链是武侠档的工具，见 fight-lexicon）。
> 与既有规则分工：`fight-lexicon.md` 管物理肉搏；`vfx-lexicon.md` 管单条特效词条（能量/元素描述词）；本文件管**法术流战斗的结构与流程**（媒介、攻防循环、段式模板）。法相/阵法五要素在 `genre-modules.md` 模块 E，不在此重复。泛用打斗纪律（ACT 追尾机位、位移量化、色彩追踪、碰撞分级、镜长呼吸）两边通用。

## 一、法宝/法器媒介体系（施法不靠拳头）

法术流的核心：**攻击/防御经法宝媒介发出**。必须写清法宝本体材质 + 施法动作 + 特效出口，禁止只写"施法"抽象词：

| 法宝类型 | 施法动作范式 | 特效出口 |
|---|---|---|
| 乐器系（笛/琴/箫/铃） | 横挡身前/举笛朝天/拨弦 | 音律波纹层层荡开、礼乐符文、花涡 |
| 扇系（骨扇/羽扇/灵扇） | 扇面展开/抛向空中放大/旋转蓄能/挥扇 | 扇形冲击波、万道金光、雷龙、剑气暴雨 |
| 印/令/玺系 | 结印虚按/抛印悬空 | 法阵铺展、空间镇压、道纹光轮 |
| 拂尘/笔/卷轴系 | 挥洒/凌空书符 | 符纹洪流、墨色剑光、禁制锁链 |

## 二、属性即视觉语言（五行/元素绑定）

每个玄幻角色绑定**主属性 + 双色**，属性决定术法形态与粒子配色，全片贯穿（与 camera-lexicon §十四「色彩追踪」的双色气场同源，法术流按此表选型）：

| 属性 | 术法形态 | 双色粒子 |
|---|---|---|
| 木/花灵 | 荆棘花藤刺穿虚空、花叶飞刃、花罩 | 粉白 + 草木青 |
| 雷 | 雷蛇狂舞、电弧跳跃、雷龙咆哮、电离焦痕 | 蓝白 + 紫电 |
| 金 | 万道金光、能量巨扇、光流镇压 | 亮金 + 暖白 |
| 水/冰 | 寒潮、冰棱、雾气、霜痕 | 冰蓝 + 银白 |
| 火 | 火龙卷、灼核、熔岩地裂 | 赤红 + 暗金 |
| 音 | 音律波纹、古乐锐响、礼乐符文 | 粉金 + 白 |

**属性对冲需叙事解释（2026-10-08 外部《影视AI创作语言库·调用规则》吸收，与 stage3「创作期冲突解决优先级链」同源）**：对冲属性同场（火与冰、佛光与魔气、雷与水）必须有叙事理由（对立阵营/双修设定/主题对照），无理由只保留主属性——否则模型把对冲色粒子混成脏色、术法形态互相吞没。有理由时按阵营分色区（各占画面一侧/各绑一个角色），不写"两种属性在同一团能量里融合"。

## 三、术法攻防循环（法术流的"防守三态"）

替代物理肉搏的攻防，法术流走**术法层**，四步循环：

1. **祭起防御术法**：花罩/护体罡气/禁制升起挡下轰击（写清防御形态与材质感）；
2. **破防临界**：防御被撕裂/炸裂（花罩轰出裂纹、罡气如薄纸被划开）；
3. **爆裂转攻**：防御术法炸裂瞬间化作攻击（花罩爆裂→千万花刃切割四方）——**防守转攻是玄幻高光点，必写**；
4. **瞬移/残影**：原地留残影、真身现于数丈之外（瞬移必须有视觉痕迹：残影/空间涟漪/空气扭曲，禁无来由跳切），规避与进攻一体。

## 四、能量具象化四形态与去水转化（禁裸光效）

玄幻的杀伤出口靠能量具象化，四种高价值形态：

| 形态 | 写法 | 示例 |
|---|---|---|
| 能量洪流/光路 | 从法器/法阵射向目标，标注范围与破坏 | 万道金色光丝如雨瀑坠落、光丝拖曳 |
| 具象生物 | 灵气聚形，标注材质与轨迹 | 雷龙咆哮冲阵、留焦黑轨迹 |
| 巨型化/法相 | 法宝放大或身后法相，标注镇压动作 | 巨扇九天镇压而下（法相五要素见 genre-modules 模块 E） |
| 领域/道域 | 法阵铺展+空间扭曲，标注天地异象 | 音波花涡吞没战场、道纹光轮嵌套 |

**去水转化表（铁律：投喂前逐条扫"光柱"二字，命中即转化）**——裸写"光柱/光路"会被渲染成呆板发光软管/简笔柱子（实测翻车）：

| 原裸表述 | 投喂前必改成 | 原理 |
|---|---|---|
| 音波光柱 | 音律波纹层层荡开 | 波纹是可拍物理现象 |
| 光柱镇压 | 由符文环/能量巨扇/具象生物镇压 | 给镇压一个实体 |
| 天罚光柱 | 天罚雷柱（电弧缠绕的实质雷柱）+ 天幕分野异象 | 电弧给柱体材质感 |
| 金光暴雨 | 万道金色光丝如雨瀑坠落、光丝拖曳 | 雨瀑/光丝是材质比喻 |
| 百丈白光柱 | 百丈光丝螺旋收束成的光流 | 洪流+收束=非实体柱 |

> 安全豁免：**丁达尔光柱/光束**是摄影术语（体积光穿透雾气），真实光线现象，不需转化。
> 通用兜底：拿不准就写「洪流/弧光/波纹/光丝雨」+ 方向 + 材质。同理禁"粒子"二字——改写为材质比喻（火星微观纤维/光丝/冰晶碎屑）。

**能量贴附物理载体（禁悬浮光团）**：一切能量特效必须贴附在物理载体上——刀刃、手臂、服装边缘、运动轨迹、法器结构，禁止无附着物的悬浮光团/光雾。频率分层出"活性"：高频短电弧（贴附刃缘/指尖，细密噼啪）+ 低频脉冲（贯注臂膀/躯干，缓慢鼓胀）。

## 五、冰系/冻结类终结三拍

冻住的画面是死的，禁写"定格成冰雕后结束"。三拍让终结后画面继续动：

1. **冻结**：冰霜自接触点爆发蔓延，目标连同介质被封入半透明冰晶（内部可见姿态）；
2. **崩解**：冰体沿应力纹路龟裂→崩解为亿万冰晶碎屑，碎屑带折射光缓慢悬浮/坠落；
3. **余烬**：细碎冰尘如余烬飘散沉降，接触点残留霜纹地面，角色收招。

## 六、对军清场级战斗（一人对军）

法术流常打大战场，与 1v1 肉搏不同：

- **敌方规模**：军阵如潮水铺天盖地、节节溃散（群像开战写法见 prompt-frameworks 通用打法 11：错落站位、各自战斗动作、表情各异）；
- **群杀方式**：扇形冲击波掀飞数十人、剑气暴雨洗地、能量扇镇压军阵核心；
- **战场破坏反馈**：地面千疮百孔、弹坑、法宝碎片散落、云层撕开缺口（环境反馈随碰撞等级分级，见 camera-lexicon §十四·10）；
- **终结级天罚**：能量具象化成型落地即陨石坑级爆炸、冲击波球形扩散（已过上面的去水转化）。

## 七、玄幻法术战斗 5 段式模板（每段独立生成单元）

```text
【玄幻法术战斗·5段式】（按剧情裁剪段数，段序保持：走位→防守转攻→宏观→蓄力→终结）
画幅：<按用户指定> ｜ 画质声明：<风格基座>，宏大战场，高密度材质光效（铁屑/火星/光丝雨），电影级光影，丁达尔光束

段1 登场/走位+首攻：主角踏<属性步法>鬼魅游走，<法宝>施法，<能量形态>横扫，敌方军阵溃散。
段2 近身/防守转攻：防御术法炸裂，化作<属性飞刃/剑气>暴雨席卷，护体罡气如纸划开，双色光丝/火星交织。
段3 宏观战场全景：拉远，军阵节节溃败，天穹法术光团碰撞，爆炸冲击波扩散，地面弹坑/裂缝/碎片。
段4 大招蓄力：法宝朝天，天地<属性>灵韵汇聚，脚下法阵铺展，头顶能量漩涡成型，镜头脚部上摇至面部再拉远。
段5 终结天罚/道域：<能量具象化>成型（雷柱/法相/花涡），天罚降临/道域镇压，冲击波球形扩散，陨石坑级破坏定格终帧。
```

- 每段独立可投喂，画质声明段段复用保证风格统一；段长与镜长呼吸纪律照常生效（stage3）。
- **蓄力在运动中完成**（段 4 的灵气汇聚嵌在动作拍里，不单独静止站桩——短打戏静止段禁令与 stage3 时长配比纪律两头顶着，拿不准按"边打边蓄"写）。
- 共用负向参考：手部崩坏、手指畸形、人物扭曲、肢体穿模、模糊、低画质、水印、文字、重复人物、僵硬动作、静态画面、多余肢体。

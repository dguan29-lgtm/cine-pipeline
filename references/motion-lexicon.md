## 一、重量感与打击感的物理层（牛顿动力学四原理 → 动作设计）

### 1. 惯性（Inertia）—— 质量感的第一来源

物体保持原有运动状态的倾向 = 观众判断"这东西多重"的依据。

- **大质量写法**（巨人/机甲/重甲/巨石）：启动有延迟（"先蓄一拍才动"）、停止有过冲（"躯体在停止瞬间向前多走半步再回稳"）、转向笨拙（"转身时全身质量整体倾斜跟随"）；
- **小质量写法**（小孩/匕首/飞鸟）：瞬时响应、快起快停、急转无缓冲；
- **惯性外化三件套**：毛发/布料/链条等附属物在主体变速时滞后摆动（"急停瞬间披风惯性前甩盖过角色再回落"）——附属物的延迟=主体质量的证据；
- 翻车点：大质量角色"轻飘飘地瞬移起步"= 重量感瞬间崩塌，提示词里用位移量化+延迟词压住。

### 2. 动量传递（Momentum Transfer）—— 力量链

- **力量链全环**：蹬地 → 腰胯转拧 → 脊柱传导 → 肢体末梢（= fight-lexicon 11 环动力链，动量守恒的具象化），**链上任何一环缺席，打击感就泄**；
- **量级公式**：动量 = 质量 × 速度——大质量慢速（坦克碾压式推进）与 小质量高速（刺客突刺）都能出大动量，但**镜头给法不同**（见第四节）；
- **受击位移 = 动量方向的可视化**：受击方沿受力方向移动，写方向+距离量化（「受力向后 0.3s 内横向滑退 50% 画面」），禁止"被打了但站着不动"（除非霸体设定显式声明）。

### 3. 作用力与反作用力（Action-Reaction）—— 打击感的因果对

- **发力必有反作用**：蹬地发力→地面微尘/碎裂反馈；凌空发力→反冲姿态（后倾/后空翻）；双人对撞→**双向受力**（双方都有位移/形变，不是一方纹丝不动）；
- **受击响应配对**：每个攻击动作必须配受力方的物理响应（头后仰/踉跄/格挡手抬起/躯体弓起），0.1s 内接续（stage3 防坑 18 的物理根源）；
- **环境是第三受力体**：冲击的能量必然有一部分进环境（碎石/尘土/水雾/气浪）——碰撞三级配方的环境反馈分级（camera-lexicon §十四·10）就是反作用力的制度化。

### 4. 加速度与质量感（F = ma）—— 蓄力与爆发的时间形态

- **蓄力段**：低速 + 大压缩（身体收紧、肢体折叠、震颤）= 力量在积蓄；
- **爆发段**：瞬间高加速 = 力量释放——**速度峰值必须落在命中点**，不是过程途中；
- **命中点 = 加速度峰值 + Hit-Stop**（1-2 帧微停顿打破平滑插值，camera-lexicon §十四·15）：没有峰值的命中 = 推搡不是打击；
- **重击减速有成本**：重击后攻方也有减速/停顿/回位过程（过度伸展后的回收），发全力而不付代价 = 塑料打击。

### 打击感七要素装配公式（动作镜头自检的最小完整集）

```text
预备（反向蓄力）→ 动量链（蹬地→腰胯→末梢）
→ 接触点（目标部位明确）→ Hit-Stop（1-2 帧微停顿）
→ 反作用对（受力方位移形变 + 环境反馈）→ 跟随重叠（附属物余韵）
→ 急停/快出（速度差反差收尾，衔接下一击）
```
缺一项，打击感降一档；R1 档可弱化特效但七要素结构不能少。

## 二、迪士尼 12 法则的提示词转写表

> 每条：原理一句话 → **提示词转写句式**（可直接改写入画面情节/段头）→ 强度档边界（R1 写实克制 / R2 商业 / R3 玄幻，定档见 fight-lexicon 第八章）。

### 1. 挤压与拉伸（Squash & Stretch）—— 有弹性的动作，先压扁再拉长
- 原理：形变表现弹性、重量与动态感；体积守恒（压扁的同时横向变宽），形变程度符合物理逻辑。
- 转写：受力瞬间「肌肉凹陷波纹化、躯体被压短横向撑开」；落地「腿部压缩下沉一拍再弹起」；弹射「身体拉长成流线型拖出残影」。
- 边界：R1 只用微形变（肌肉/布料级别）；R2 肢体级；R3 可全身夸张形变。写实真人题材默认 R1 档，大形变=喜剧/CG 专属。

### 2. 预备动作（Anticipation）—— 想往前冲，先往后收
- 原理：主动作前加反向准备，增强可信度与冲击力；预备过长会削弱爆发感。
- 转写：「重心下沉右移、右肩后收、视线锁定目标，随即直线击出」（0.1-0.3s 状态快照写法，防坑 18/22 已定稿）；跳跃前「下蹲蓄力一拍」、投掷前「手臂向后拉满」。
- 边界：预备时长 ≤ 主动作的 1/3；连续对招中预备压缩到极限（机枪对招靠架势隐含预备，不逐击展开）。

### 3. 演出布局（Staging）—— 一镜一个重点，让观众一眼看懂
- 原理：构图/镜头/动作设计清晰传达意图，引导注意力；重要文字信息要给足可读完的停留时间。
- 转写：每镜只声明**一个主体+一个动作事件**（与"单镜信息量与时长匹配"纪律一致）；复杂场景写「背景简化虚化，注意力锁定在 X」；画面内嵌文字停留 ≥2-3s（读完三遍的时间）。
- 边界：与本 skill「一镜一主运镜」「首帧占位锁」同族；混战时靠双实体整套锚定保 staging 不糊（camera-lexicon §十四·13）。

### 4. 连续动作与关键帧（Straight Ahead & Pose to Pose）—— 节奏靠关键帧，流畅靠中间帧
- 原理：可预测的角色表演先定关键姿势，不可预测的流体运动逐帧连续演化。
- 转写（方法论映射）：角色动作走**时间戳状态快照**（每 0.5-4s 一个关键姿态，= 本 skill 时间戳分镜的既有做法）；火焰/烟雾/水流/布料写**连续演化态**（「火焰持续向右上翻卷流动、形态不断变化」），不写关键帧。
- 边界：动作写状态快照不写过程链（防坑 22）与流体写连续演化并不矛盾——刚体定关键姿态，流体定演化方向。

### 5. 跟随与重叠动作（Follow Through & Overlapping）—— 动完了，还有"尾巴"在动
- 原理：主体停止后附属部分继续运动，不同部位运动节奏不同。
- 转写：「急停瞬间，头发/衣摆/披风因惯性继续向前甩出，半拍后自然回落」；「收剑入鞘后，剑穗仍摆动两次」；尾巴/链条各节波浪式依次停止。
- 边界：附属物延迟半拍到一拍即可，拖太长=注意力被尾巴偷走；这也是"死寂帧保留次级运动"（防坑 15）的物理依据。

### 6. 缓入缓出（Slow In & Slow Out）—— 慢启动，快经过，慢收尾
- 原理：动作起始和结束慢、中间快，符合自然加速规律。
- 转写：日常动作「抬手先缓起、中途加速、落位前减速停稳」；情绪戏「缓缓侧过身，视线慢慢抬起」。
- 边界：**打斗段缓入缓出被压缩到帧级**（同节奏连续 ≤5s 纪律优先，缓动只允许出现在蓄力帧与收尾余韵）；匀速运动（全程一个速度）= 机器人感，禁用词「匀速地」。

### 7. 弧线运动（Arcs）—— 生命走曲线，机器走直线
- 原理：自然动作沿弧线轨迹；机械运动才用直线。
- 转写：挥击轨迹写弧线几何（「手臂沿弧线横扫」「上挑划出新月弧」）；跳跃写抛物线（「沿抛物线跃起，在最高点停顿一拍再下落」）；头部转动带轻微弧线起伏。
- 边界：直线留给**发力瞬间的冲刺段**（出拳/蹬地）与机械/枪械——见姿态原则 2「直线曲线搭配」。

### 8. 次要动作（Secondary Action）—— 主动作发力，小动作传情
- 原理：主动作上叠加辅助小动作，丰富表演层次；必须服务主情绪，不喧宾夺主。
- 转写：说话时「手指无意识敲桌面」；落地站稳时「胸口随呼吸起伏一拍」；行走时「顺手把外套下摆向后拨开」。
- 边界：每镜次要动作 ≤2 个，且不得与主动作抢焦点（与 staging 法则互锁）；待机状态的次要动作是防"站桩木偶"的（微动力学待机纪律同源）。

### 9. 时间节奏（Timing）—— 少几帧是爆发，多几帧是重量
- 原理：帧数（时长）控制速度，传达重量、性格与情绪；节奏决定角色"性格"。
- 转写：快=秒数小+速度体感词（「0.1s 内瞬闪」「骤然」）；重=秒数大+阻力词（「缓慢地、带着明显阻力地抬起」）；性格用节奏声明（「动作节奏慵懒拖沓」vs「干净利落的短促节奏」）。
- 边界：与本 skill 位移量化（Xs 内横跨 Y% 画面）是同一纪律的两面——位移量化管打斗，Timing 管一切非打斗动作；不要用时间戳控制频率（sd25 规则）。

### 10. 夸张（Exaggeration）—— 真实是基础，夸张要大要 too much
- 原理：合理范围内放大动作/表情/比例增强表现力；夸张要有依据，不丢角色本质。
- 转写：直接放大物理量——「跃起的高度远超常人」「冲击波把整条街的玻璃同时震碎」；表情用强度档升级（facs-lexicon〔痕〕→〔显〕→〔强〕）。
- 边界：**夸张幅度与强度档绑定**：R1 几乎不夸张（只放大 10-20%）、R2 放大一档、R3 拉满；夸张的制度化形态=碰撞三级配方（冲击帧/负片/鱼眼畸变，camera-lexicon §十四·10）——要夸张就写进配方，不临场即兴。

### 11. 扎实作画（Solid Drawing）—— 脑中有 3D，剪影测僵硬
- 原理：角色需具备三维空间感，掌握透视、解剖与光影；避免平行线和对称。
- 转写：资产与画面声明带体积感（「三维空间感、透视准确、解剖结构正确、有真实光影体积」）；姿态走"动势线"（见姿态原则 1）；多角色同框写前后景纵深与遮挡关系，不写平面并排。
- 边界：二维平贴感=提示词缺体积声明；剪影测试法——把脑中的角色涂黑，剪影认不出动作=姿态太规整，回去打破对称。

### 12. 吸引力（Appeal）—— 让观众一眼认出角色
- 原理：角色要有视觉魅力、鲜明个性与剪影辨识度（different shapes）。
- 转写：角色资产设计阶段执行——轮廓差异化（高瘦/矮壮/佝偻，不同体型比例）、一件标志性道具/服装件、一个标志性动作习惯（stage1 人物档案的"标志性动作习惯"字段就是 Appeal 的剧本层落点）。
- 边界：与本 skill 多角色差异化纪律（G4 设计学词汇：武器/姿势/朝向/服装/配色/特效都不同）同源。

## 三、姿态动势三原则（实战姿态与走位纪律，治"僵硬木偶感"）

### 1. 避免平行线与对称 —— 打破对称，动势自来
- **错误示范**：双臂垂直平行下垂 / 双腿对称站立重心居中 / 肩髋完全水平 / 动作左右镜像；
- **转写句式**：「一肩高一肩低，重心落在单腿呈 S 型站姿」「手臂一前一后呈对角线布局」「转身时头部先动、躯干滞后跟随」；
- 应用：登场站姿、行走循环、惊讶回头、对话姿态——**凡提示词里出现"站立"，默认补一句打破对称的重心声明**。

### 2. 直线与曲线搭配 —— 直线定力量，曲线定流动（直为力，曲为势）
- **直线**用于发力瞬间（出拳伸直、蹬地瞬间的支撑腿）——表现力量；
- **曲线**用于缓冲、蓄力与跟随（收势的腰胯弧线、摆动腿弯曲）——表现流动；
- **转写句式**：「出拳手臂绷直成线，躯干呈 C 型反弓蓄力」「支撑腿蹬直（直线），摆动腿弯曲后甩（曲线），全身呈 S 型张力」；
- 翻车点：所有肢体全直=机器人；所有肢体全曲=软体动物。每个发力画面必须直曲并存。

### 3. 两条曲线错开 —— 先后出动，节奏才活（一波未平一波又起）
- 附属部分严禁同步：头发/披风/尾巴各节给**时间偏移**，波浪式传递；
- **转写句式**：「头部先转、肩部次之、髋部最后，形成波浪式传递」「长发各缕轨迹不重合，后发缕比前发缕慢半拍」「披风边缘比主体延迟摆动，形成层次」；
- 翻车点：附属物像"铁板"一样整体移动=假；各部位独立曲线=活。

## 四、镜头语言与节奏编排映射（动作原理 → 镜头选择）

| 动作物理特征 | 镜头给法 | 依据 |
|---|---|---|
| 大质量启动/碾压 | 低仰角全景 + 慢速推近，地面反馈放大 | 大招模式 A；惯性可视化 |
| 小质量高速突刺 | 贴身高速跟拍 + 轨迹拖尾 | 大招模式 B；速度可视化 |
| 命中瞬间（加速度峰值） | 特写/微距急速推镜至接触点 + Hit-Stop 定格 0.2s | 大招模式 C；碰撞配方 |
| 冲击余波（动量进环境） | 全景急速拉镜，以碰撞点为圆心跟冲击波 | 大招模式 D；反作用力 |
| 蓄力（低速大压缩） | 中近景斜仰慢推，身体压缩特写 | 大招模式 J 第一段 |
| 受力位移（动量方向） | 沿受力方向的跟拍或侧向全景，位移量化 | §十四·12 位移量化 |

**节奏编排 = 动作三幕的时间版**：预备慢（缓入）→ 爆发快（少帧/秒数小）→ 余韵缓（缓出+跟随重叠）。与终结技三幕（破局→绽放→余震）、特效生长三段论、急停弹射法则是同一曲线在不同层级的实例——写打斗段时把三套对齐用，不各自为战。

**双人节奏对位**：攻防双方的节奏必须错开（一方爆发时另一方缓冲/承受），两人同节奏=回合制木偶（与机枪对招三模式、攻防转换纪律联动）。

## 五、动态漫适配（模块 G 联动）

- 动态漫的**微动态**（头发轻飘/呼吸起伏）= 跟随重叠+次要动作的低成本版；**中动态**=缓入缓出的位移；**强动态**=完整七要素装配——三级动态就是原理按预算的裁剪；
- 静态帧之间用"两条曲线错开"制造假动感（披风/发缕错帧摆动提示词），一格当三格用；
- 口型分级之外，表情强度用 facs-lexicon 三档与夸张法则绑定（强动态爽点镜=表情〔显〕档起步）。

## 输出前自检清单

- [ ] 每个攻击动作七要素齐：预备→动量链→接触点→Hit-Stop→反作用对→跟随重叠→速度差收尾
- [ ] 大质量角色有启动延迟/停止过冲；受击方位移有方向与量化；发力有环境反作用反馈
- [ ] 动作轨迹：生物走弧线、发力瞬间给直线、机械走直线；直曲并存
- [ ] 姿态无平行对称（S 型重心声明）；附属物时间错开（头发/披风/尾巴非铁板同步）

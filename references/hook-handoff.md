# 开场钩子阶段交接

本文件解决一件事：当信息流或短视频项目从投放策略进入剧本、分镜和生成时，怎样让最初的点击动机不在下游被换掉。它不重新定义钩子分类。

## 单一事实来源与职责

- `../../feed-ad-video/references/hook-system.md`：定义并选择观看动机、主钩子和最多一个辅助钩子，负责投放目标与测试逻辑。
- `../../screenwriting-craft/references/opening-hooks.md`：把已选动机转成观众问题、第一可见事件、人物/产品动作与兑现位置，负责写成一场戏。
- 本导演流程：保存交接字段，在 Stage 3 把已经锁定的开场戏转成可生成的首段画面、声音与文字；不另选一套动机，不为“更炸”擅自改承诺。

纯剧情短片、电影或温情片若没有停留、点击、进店、咨询、成交等投放目标，只继承编剧 Skill 的叙事型开场，不加载信息流十种机制。

## 路由规则

1. **只要投流脚本**：停在 `feed-ad-video`；需要完整可演脚本时接 `screenwriting-craft`，不启动分镜面板。
2. **投流脚本＋AI 视频制作**：先锁投放简报和钩子选择，再完成剧本；剧本达到本轮可用状态后进入 Stage 3。
3. **已有锁定剧本直接分镜**：读取剧本中的开场钩子合同或从开场事实提取等价字段；不得因为下游更喜欢某种镜头而改写原台词、事件或承诺。
4. **下游确实无法实现**：说明具体生成限制，回到 Stage 2 只调整实现方式；主观看动机、核心承诺和产品关系默认保持，除非用户明确批准重选。

## 交接模板

~~~yaml
开场钩子合同:
  类型: 点击型 | 叙事型
  投放目标: 停留 | 点击 | 进店 | 咨询 | 成交 | 不适用
  主观看动机: ""
  主钩子: ""
  辅助钩子: ""  # 最多一个；没有就留空
  观众问题: ""
  第一可见事件: ""
  主体立即行动: ""
  第一次推进: ""
  核心兑现位置: ""
  主题或产品关系: ""
  禁改项: []
  状态: 草稿 | 已确认 | 已锁定
~~~

Stage 3 不必把这段 YAML 原样展示给用户，但内部必须能逐项回答。首段 Prompt 只负责实现字段：

- 首个可见帧或首个有效声音让“第一可见事件”成立；
- 画面、口播/对白与屏幕文字指向同一个观众问题；
- 若剧本已锁定，不用结果闪回、额外旁白或新促销替换原开场；
- 后续段按“第一次推进”和“核心兑现位置”交付答案，避免只保留噱头、删掉兑现。

## 最小行为案例

### 案例 A：从投流点子到分镜

输入：“做一条 30 秒家用清洁机信息流，从脚本到 AI 视频提示词，目标进店，开头想让人看效果。”

预期：先走 `feed-ad-video`，把主观看动机锁为“看结果”，选定主钩子与最多一个辅助钩子；再由 `screenwriting-craft` 写成有第一可见事件和兑现位置的完整脚本；Stage 3 继承合同做首段，不重新罗列十种机制，也不把“看结果”换成猎奇悬念。

### 案例 B：纯剧情短片

输入：“把这部 90 秒父女温情短片做成分镜，开场要自然，不要广告感。”

预期：不调用信息流钩子系统；继承剧本的关系压力与观看承诺，按正常 Stage 3 制作。不得加入“别划走”、限时优惠、专家背书或结果闪回。

## 自检

- [ ] 信息流项目的观看动机与主/辅钩子来自 `feed-ad-video`，没有在导演流程中另建变体分类
- [ ] 剧本开场来自 `screenwriting-craft` 的可演事件，分镜没有用镜头噱头代替事件
- [ ] 主钩子只有一个，辅助钩子最多一个；画面、声音和文字没有各抢一个任务
- [ ] 首段建立的问题在后续规定位置得到推进和兑现
- [ ] 已确认/已锁定的台词、开场事件和产品关系没有被下游擅改
- [ ] 纯剧情项目没有被强制套用投流公式或固定前三秒指标

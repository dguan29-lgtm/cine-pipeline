# 画面风格库（Style Library）——真人 / 2D / 3D 全谱系选型与转写

> **何时加载**：①用户未提供风格基座（Stage 1「视觉风格」字段或 Stage 3 输入门禁第 1 项空缺）；②用户点名某个具体风格名（如"新海诚风格""爱死机 CG"）；③需要把模糊风格描述（"要电影感"）转写成可投喂基座时。
> **与 prompt-frameworks G6 的分工**：G6 是**质感基座六预设**（胶片/色彩/材质/声景六维，管"画面底子"）；本库是**命名风格全谱**（管"要哪个流派哪个调"）。两者可叠加：先按本库定流派与色卡，再按 G6 补光学/材质/声景维度。
> **素材来源**：2026-09-29 二爷提供的平台风格库截图（真人 73 款 / 2D 92 款 / 3D 52 款，共 217 款，风格名已按截图标签逐格校对），按家族归纳；特征描述为家族级锚点+代表风格一句话，新增风格先入家族再补一句话锚点。

## 使用方法（三步）

1. **定家族**：按「媒介（真人/2D/3D）→ 情绪调性 → 地域/时代」三级收敛到家族；用户描述模糊时推荐 2-3 个候选风格名请用户选（与 G6 选型纪律一致，禁止自行拍板）。
2. **取锚点**：家族核心特征（色彩/光影/质感）+ 该风格一句话锚点，组装进风格基座；**风格基座全片唯一，资产与分镜共用原样继承**（stage3 资产规则不变）。
3. **转写五要素**：任何风格名落进投喂词必须展开为五要素——**色彩影调（60/30/10 真实色名）+ 光影逻辑（主光源性质与方向）+ 材质/颗粒（胶片型号/渲染工艺/纸面）+ 镜头倾向（画幅/焦段/景深习惯）+ 负向排除（该风格最忌讳的跑偏）**。只写风格名裸词 = 模型自由发挥，等于没选。

## 与风格选择组件的对接（2026-09-29 契约）

`视频风格选择组件.html`（风格库 UI：搜索/分类/常用/自定义）的用户确认结果按以下契约回传，管线消费时遵守三条：

1. **载荷格式**：组件确认后生成项目档案「视觉风格」YAML（含 来源/风格名/分类（媒介+家族）/缩略图/画面风格描述提示词/确认时间），并持久化到 localStorage 键 `videoStyleSelection`；收藏夹（手动收藏，悬停卡片点 ★）存于 `styleFavorites`。
2. **免二次询问**：项目档案「视觉风格」字段已有组件回传值时，视为 Stage 3 输入门禁第 2 项**已由用户明示选定**，直接引用、不再索取——组件中的点击确认就是用户确认，重复询问=破坏"无需重复选择"契约。
3. **基座生成**：预设风格按其「风格名+家族」在本库取锚点、按五要素转写法组装基座；自定义风格直接以用户输入的描述文本为基座素材（缺维度时按 G6 补全并标注【自动推导】）。

## 一、真人风格（73 款，9 个家族）

### 1. 主流影视质感族
**成员**：电影感 / 电视剧感 / 短剧风格 / 真人写实
**核心特征**：写实摄影基准族。电影感=浅景深大光圈、电影级调色、2.35:1 倾向；电视剧感=中景深、均匀布光、卫视级亮调；短剧风格=竖屏、人脸优先打亮、高对比、背景简化。
**一句话锚点**：电影感=cinematic film look, shallow depth of field, anamorphic flare；短剧风格=竖屏 9:16、面部主光充足、背景压暗突出人物。

### 2. 华语时代片族

## 五、风格库维护纪律

1. 新风格入库先入家族、补一句话锚点；锚点写法=可投喂的具体措辞（色名/光源/材质词），禁止"很唯美""很高级"类形容。
2. 同一风格在多个项目试产后，把实测有效的完整五要素转写回填到该风格条目（锚点 → 完整转写）。
3. 风格与题材冲突时（如水墨+赛博），以用户明示为准并写进项目档案「视觉风格」字段，不在库里做混合预设。
